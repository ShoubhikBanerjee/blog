Self-learning AI agent with IDE, messaging, and memory

A new 24/7 self-learning AI agent has been introduced, featuring an integrated IDE workspace that runs itself. The system operates without requiring extra API keys, working directly with existing Claude Code or OpenAI Codex subscriptions.

🧩 How it works

The agent manages its own goals, tracks research, and executes a full pipeline involving research, planning, review, and execution. It proposes goals and writes plans, which users can approve from a desktop app or via messaging platforms. The system maintains a persistent memory, remembering decisions, preferences, and context across every session, and supports full-text search over all past conversations.

⚙️ Key details

The agent includes several integrated components for development and automation:

  • IDE Workspace: Features a file explorer with keyboard navigation, a Monaco editor with autosave, a Git panel with ahead/behind status, and a real PTY terminal with tabs, split panes, and diff view.
  • Scheduling & Automation: Supports cron jobs, scheduled pulses, recurring tasks, and iCal RRULE support. It can sync with Apple Calendar, displaying tasks on Apple Watch and iPhone.
  • Communication: Messages users on Telegram and WhatsApp, supporting text, photos, voice, and documents. The same agent context and memory are shared between desktop and messaging sessions.
  • Skills & Extensions: Includes built-in skills for GitHub, email, macOS, PR review, and agent swarms. Users can browse community skills and connect MCP servers via Smithery.
  • Browser Automation: Performs 40+ actions using the user’s real Chrome profile.
  • Multimodal Input: Accepts images, screenshots, and diagrams that the agent can process.

📊 Model Support

The agent is multi-provider, supporting the following models:

🔒 Security & Updates

The application is local-only with no cloud relay. It features auto-update capabilities with signed, notarized, one-click updates.

💡 Why it matters

By integrating a full IDE workspace, persistent memory, and direct messaging capabilities, this agent allows users to delegate complex workflows and research tasks. It leverages existing subscription models to provide a comprehensive development and automation environment that operates autonomously while remaining user-controlled.
