✨ Qwen-Edit Relight: Advanced Image Relighting with LoRA Technology

Welcome to the world of AI-powered image relighting! The Qwen-Edit-2509 Image Fusion LoRA model brings incredible performance to transform your images with sophisticated lighting techniques. 🎨

🚀 What is Qwen-Edit Relight?

The Qwen-Edit Relight model is a powerful LoRA (Low-Rank Adaptation) extension that leverages the Qwen-Edit-2509 framework for advanced image fusion and relighting capabilities. This cutting-edge technology allows users to dramatically alter the lighting conditions of any image while maintaining photorealistic quality.

🛠️ Two Methods to Use the Mode

Method 1: Direct Prompt-Based Editing

Use the prompt words included in the dataset to directly modify image lighting conditions without additional setup.

Method 2: LoRA Integration with Trigger Words

After installing the LoRA model, utilize the Chinese trigger word: 重新照明 (Relighting)

Example Usage:

1

重新照明,使用窗帘透光（柔和漫射）的光线对图片进行重新照明

Translation: “Relighting, using the soft, diffuse light from the curtains to relight the image”

📥 Installation Instructions

Step 1: Download the LoRA File

Download Qwen-Edit-Relight.safetensors and place it in your models/loras folder.

Step 2: Required Dependencies

You must also download and install the companion LoRA from: Qwen-Image-Lightning
