Physical Access Control Controllers Gain AI Features Amid Growing Cybersecurity Gaps

A new global survey of 561 physical security and cyber security professionals shows that controllers are becoming a strategic focus for access control systems, with AI‑driven capabilities and cloud interest outpacing current infrastructure.

🔍 Overview

  • 78% of respondents now consider the controller important or critical to their PACS strategy, up from 72% in 2025.
  • The controller’s role is expanding as it connects more devices, systems and applications across the security environment.
  • Cyber security remains a clear gap: 32% say cyber security features are missing from their current controllers, up from 21% in 2025, while 74% report that cyber security and IT coordination have become more complex.

“Organisations recognise the cyber security risks facing connected access control systems, but the infrastructure in place isn’t always keeping pace,” said Steve Lucas, Vice President, Sales, Mercury Security.

“As they look to modernise, users also want to protect existing investments. That makes interoperability increasingly important and puts more weight on choosing controller platforms that can address current security requirements while providing the flexibility to support what comes next.”

⚙️ Key Findings

  • Interoperability: 69% identify it as a critical factor in controller procurement; 82% value backward and forward compatibility for future planning.
  • Mobile Credentials: 50% of respondents rank mobile credential integration among the trends driving purchases, and half are already using or planning mobile solutions.
  • Cloud Connectivity: Cited by 56% of respondents (up from 50% in 2025), yet only 41% have cloud‑enabled controllers and 26% say cloud enablement is missing.
  • AI‑Enabled Functions:
    • Behavioural analysis and anomaly detection cited by 56% (up from 44% in 2025).
    • Facial recognition mentioned by 60%.
    • Predictive security and threat prevention cited by 50%.
  • Edge Computing & Integration: 39% are exploring or have adopted edge computing; 41% have integrated controller data with building occupancy and utilisation programs.

🤖 AI‑Enabled Capabilities

  • Behavioural analysis & anomaly detection – helping identify out‑of‑norm activities.
  • Facial recognition – enhancing identity verification at entry points.
  • Predictive security & threat prevention – using data trends to anticipate risks.
  • These functions increase demands on processing power, storage, connectivity, cyber security and integration architecture when selecting controllers.

🌐 Connectivity & Interoperability

  • Organizations seek platforms that support current security requirements while remaining flexible for future technologies.
  • Preference for gradual modernisation that protects existing investments and enables new capabilities over time.
  • Growing interest in cloud capabilities outpaces the current availability of cloud‑enabled controllers.

📈 Implications for Infrastructure Strategy

  • Controller selection is shifting from a simple hardware purchase to a long‑term infrastructure strategy.
  • Decision‑makers balance reliability and cyber security with the need to support emerging AI applications, integrate with surrounding systems, and modernise without wholesale replacement.
  • The findings suggest a market moving toward interoperable, cloud‑ready, AI‑capable controllers that can evolve alongside security ecosystems.
