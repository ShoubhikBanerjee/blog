OpenAI Launches ChatGPT Wallet for Dots AI Agents to Make Purchases

OpenAI is launching ChatGPT Wallet, allowing its Dots AI agents platform to make purchases on behalf of users in response to prompts.

🧩 How it works

  • Prompt-based buying: Once a card is added to the wallet, Dots agents can buy items in response to user prompts.
  • User checkout review: Agents check in with the user each time before completing checkout.
  • Biometric verification: OpenAI’s support page states every purchase requires a security check using biometric verification like Face ID or a fingerprint scan.
  • Payment tokenization: OpenAI substitutes actual credit card details with a payment token—similar to tap to pay, Apple Pay, or Google Wallet—so card information is never shared with the Dots agent or the seller.

🚀 Availability

ChatGPT Wallet is rolling out starting today, subject to specific account and card requirements:

  • Eligible users: ChatGPT Pro subscribers in the US who are aged 18 and older and have a US billing address.
  • Supported cards: Eligible US-issued American Express, Chase, Mastercard, and Visa cards.

⚙️ Limitations and future features

  • Retailer blockades: ChatGPT Wallet might not work everywhere because some retailers block or restrict AI agents. Earlier this year, Amazon blocked Meta’s Muse agents.
  • System requirements: OpenAI stated that websites need to ensure agents are not inadvertently blocked and that risk systems recognize legitimate agent transactions.
  • Planned automation: OpenAI expects to eventually allow users to delegate purchases entirely by pre-approving transactions within set parameters, such as spending limits, time periods, or purchase categories.
