FlashVSR: Towards Real-Time Diffusion-Based Streaming Video Super-Resolution

A breakthrough diffusion-based framework achieving real-time video super-resolution at 17 FPS with state-of-the-art performance and up to 12× speedup over existing models.

Oct 28, 2025
4 minute read

⚡ FlashVSR: Towards Real-Time Diffusion-Based Streaming Video Super-Resolution

FlashVSR demonstrates real-time video super-resolution capabilities with state-of-the-art performance

Authors: Junhao Zhuang, Shi Guo, Xin Cai, Xiaohui Li, Yihao Liu, Chun Yuan, Tianfan Xue

🌟 Abstract

Diffusion models have recently advanced video restoration, but applying them to real-world video super-resolution (VSR) remains challenging due to high latency, prohibitive computation, and poor generalization to ultra-high resolutions. Our goal in this work is to make diffusion-based VSR practical by achieving efficiency, scalability, and real-time performance.

To this end, we propose FlashVSR, the first diffusion-based one-step streaming framework towards real-time VSR. FlashVSR runs at ∼17 FPS for 768 × 1408 videos on a single A100 GPU by combining three complementary innovations:

  1. A train-friendly three-stage distillation pipeline that enables streaming super-resolution
  2. Locality-constrained sparse attention that cuts redundant computation while bridging the train–test resolution gap
  3. A tiny conditional decoder that accelerates reconstruction without sacrificing quality

To support large-scale training, we also construct VSR-120K, a new dataset with 120k videos and 180k images. Extensive experiments show that FlashVSR scales reliably to ultra-high resolutions and achieves state-of-the-art performance with up to ∼12× speedup over prior one-step diffusion VSR models.

🚀 Getting Started

Follow these steps to set up and run FlashVSR on your local machine:

1️⃣ Clone the Repositor

1

git clone https://github.com/OpenImagingLab/FlashVSRcd FlashVSR

2️⃣ Set Up the Python Environmen

Create and activate the environment (Python 3.11.13):

1

conda create -n flashvsr python=3.11.13 conda activate flashvsr

Install project dependencies:

1
2

pip install -e .
pip install -r requirements.txt

3️⃣ Install Block-Sparse Attention (Required

FlashVSR relies on the Block-Sparse Attention backend to enable flexible and dynamic attention masking for efficient inference.

1
2
3

git clone https://github.com/mit-han-lab/Block-Sparse-Attentioncd Block-Sparse-Attention
pip install packaging pip install ninja
python setup.py install

⚠️ Note: The Block-Sparse Attention backend currently achieves ideal acceleration only on NVIDIA A100 or A800 GPUs (Ampere architecture). On H100/H800 (Hopper) GPUs, due to differences in hardware scheduling and sparse kernel behavior, the expected speedup may not be realized, and in some cases performance can even be slower than dense attention.

The overview of FlashVSR. This framework features:

  • Three-Stage Distillation Pipeline for streaming VSR training
  • Locality-Constrained Sparse Attention to cut redundant computation and bridge the train–test resolution gap
  • Tiny Conditional Decoder for efficient, high-quality reconstruction
  • VSR-120K Dataset consisting of 120k videos and 180k images, supports joint training on both images and videos

🏁 Conclusion

FlashVSR represents a significant breakthrough in real-time video super-resolution technology by successfully bridging the gap between high-quality diffusion models and practical deployment requirements. The framework’s innovative three-stage distillation pipeline, combined with locality-constrained sparse attention and a tiny conditional decoder, achieves an impressive balance between speed and quality.

Key takeaways include:

  • Real-time Performance: Achieving ∼17 FPS for high-resolution videos on single GPU hardware
  • Scalability: Successfully handling ultra-high resolutions that were previously impractical
  • Efficiency Gains: Up to 12× speedup over existing one-step diffusion VSR models
  • Practical Implementation: Complete inference code and pre-trained models available for immediate use

The upcoming release of the VSR-120K dataset will further accelerate research in this domain, providing the community with valuable resources for large-scale video super-resolution training. FlashVSR sets a new standard for practical diffusion-based video enhancement applications.
