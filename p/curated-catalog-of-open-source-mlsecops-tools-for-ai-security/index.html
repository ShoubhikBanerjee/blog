Curated Catalog of Open-Source MLSecOps Tools for AI Security

A new curated catalog has been released to help security engineers, machine learning practitioners, developers, and AI red teams discover resources for integrating security into the machine learning lifecycle.

🔍 Overview

MLSecOps (Machine Learning Security Operations) is the practice of integrating security throughout the machine learning lifecycle, spanning data collection, model development, deployment, monitoring, and incident response. This catalog compiles open-source tools, adversarial machine learning research, AI security frameworks, threat-modeling resources, and practical learning materials to support these efforts.

🧩 How it works

The catalog applies security testing, threat modeling, supply-chain protection, access controls, and continuous monitoring to machine learning models, MLOps pipelines, LLM applications, and AI agents. The resources are organized into specific functional categories:

CategoryFunction
Model and artifact security toolsDetect unsafe serialization, malicious payloads, integrity failures, and other risks in machine learning model files.
Adversarial machine learning testing toolsEvaluate model robustness against evasion, poisoning, extraction, inversion, and other adversarial techniques.
Embodied AI and robotics ML security toolsTest policies that emit actions rather than text, where a successful attack moves a robot out of its safe envelope rather than changing a prediction.

💡 Why it matters

Open-source MLSecOps tools allow practitioners to test, monitor, and protect machine learning models, data, pipelines, LLM applications, and AI agents. The catalog serves as a central discovery point for these resources, including active projects and proofs of concept.

⚙️ Key details

  • The collection includes a mix of active projects and proofs of concept.
  • Users are advised to evaluate maintenance status, licensing, threat coverage, and deployment suitability before production use.
  • The newsletter for the MLSecOps Hacker focuses on model supply-chain security (serialization, signing, provenance), prompt injection, and agent and MCP security.
