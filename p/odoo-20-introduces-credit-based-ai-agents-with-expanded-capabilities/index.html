Odoo 20 Introduces Credit-Based AI Agents with Expanded Capabilities

Odoo 20’s release notes put AI front‑and‑center, marking the first Odoo version where AI features—including agents, image generation, and the website assistant—run on purchased credits.

📝 Overview

  • AI is the headline of Odoo 20, but it is now a paid feature.
  • Every AI‑related capability in Odoo 20 operates on a credit‑based model according to the official release notes.

⚙️ New Agent Capabilities

  • Agents are no longer simple chatbots; they can directly create and update records on your behalf.
  • While previewing a file, an agent can answer questions about its contents without you describing the file.
  • Agents display live status updates (e.g., pulling data, checking a record, drafting) instead of a generic “AI is thinking” message.
  • They can be triggered by automated or scheduled actions, enabling workflow execution without opening a chat window.
  • Agents can self‑adjust to better serve their use cases, though the mechanics are not detailed.
  • If an agent reaches its maximum tool‑call limit, it prompts the user for confirmation before continuing.
  • Interactive responses let agents request permission or offer suggestions via clickable buttons.
  • Additional functions include:
    • Filtering view data by time periods such as weeks or quarters.
    • Reprocessing sources to use the latest version of a file.
    • Sending and receiving files directly within a chat.

🧩 Terminology Shift

  • The collections of instructions and tools that define an agent’s behavior, previously called “Topics,” are now termed “Skills.”
  • The underlying configuration remains unchanged; existing topic configurations carry over.
  • The rename frames the concept as a specific capability rather than a loose conversation context.

🔌 Technical Integration

  • Odoo now supports connecting to your database via the Model Context Protocol (MCP), an open standard for linking software to external tools and data sources.
  • No pre‑built third‑party MCP integrations are shipped; the feature provides a standardized connection point for IT teams.

🌐 AI Website Assistant Enhancements

  • The assistant can create new webpages from a description.
  • It can edit a site’s menu—creating, renaming, moving, nesting, reordering, or deleting items.
  • It can create or edit webforms.
  • It can draw inspiration from other websites, pull data from your own records (e.g., products, events), and add interactive elements such as counters, toggles, tabs, or animations.
  • For images, the assistant can source from Unsplash or generate them directly.

💡 Why It Matters

  • The shift to a credit‑based model signals Odoo’s move toward monetizing AI functionality.
  • Expanded agent capabilities aim to embed AI more deeply into everyday business processes, reducing the need for manual data entry and enabling richer, context‑aware interactions.
  • The introduction of MCP connectivity lays groundwork for future integrations with external tools, offering a standardized approach rather than custom one‑offs.
  • Renaming “Topics” to “Skills” clarifies the intent of agent configurations as defined capabilities.
