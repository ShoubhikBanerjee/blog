Slack introduces AI-powered Slackforce Surfaces for building interactive tools in chat

Slack is launching a new feature called Slackforce Surfaces that allows users to create interactive reports, dashboards, and other tools directly within a chat using AI.

🧩 How it works

Users can build a tool by describing what they need to Slackbot. The AI then gathers information from connected apps and relevant conversations to create the output.

Key capabilities include the creation of:

  • Interactive reports
  • Polls
  • Dashboards
  • Presentations
  • Microsites

In one example, a user asked Slackbot for an arcade-themed visualization of AI token usage, and the assistant generated an interactive dashboard showing token usage across engineering, design, and sales divisions.

⚙️ Key details

  • Collaboration: Once a Surface is created, it can be pinned to channels and shared with colleagues, who can then interact with it and leave comments.
  • Data Privacy: The feature only pulls information that the user has given its AI tools permission to access.
  • Integration: Slackbot can gather data from connected apps, such as Salesforce or Google Drive.

🚀 Availability

Slackforce Surfaces is available to all customers, including those using the free version, provided Slackbot is enabled in their workspace. Support for live data will begin in October.
