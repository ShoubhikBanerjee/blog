OpenAI cuts ChatGPT thread load time by 94 percent

OpenAI reduced the load time for large ChatGPT conversation threads by 94% in tests, improving performance from 27.6 seconds to 1.7 seconds for a 741-turn thread with 231 MB of data. The improvement is attributed to client-side history handling, not model speed.

⚙️ Key details

  • Test case: 741 turns, 231 MB, 27.6s → 1.7s
  • Cause: Client-side history optimization
