Microsoft releases Windows 11 KB5132057 November optional cumulative update

Microsoft released the KB5132057 November optional cumulative update for Windows 11 versions 25H2 and 26H2, bringing 28 changes including improvements to Windows Search, Windows Hello, and the Run dialog. This preview update allows IT administrators to test improvements, bug fixes, and new features before the next Patch Tuesday release, and it will be the final non-security preview update released this year as operations wind down for the Western holidays.

🔍 Overview

KB5132057 is an optional non-security preview update that provides only quality improvements rather than security fixes. Installing this update will upgrade Windows 11 26H2 and 25H2 devices to builds 26300.10075 and 26200.10075, respectively. Microsoft also noted that a limited number of consumer and business devices might experience one additional restart during installation after a Secure Boot certificate update is applied.

⚙️ Key features and changes

  • Windows Search: Features a new WinUI 3-based Search Box experience that removes promotional content from web results for better resource efficiency and streamlined design. Search from This PC in File Explorer is now indexer-based, and inline actions let users complete common tasks directly from Windows Search.
  • Windows Hello: Includes improved facial recognition enabling sign-in in dark rooms after turning on the “Automatically adjust screen brightness during face recognition” setting.
  • Run Dialog: Adds the new Run dialog with a refreshed design and an almost instant time-to-show of 94 ms.
  • Accessibility: Users can now turn off accidentally triggered keyboard shortcuts for Sticky Keys, Filter Keys, or Toggle Keys directly from the appearing prompt.
  • Enterprise and Security: Web sign-in is now supported on Microsoft Entra hybrid-joined devices, allowing password-free lock screen sign-in via FIDO2 keys, phone passkeys, or Temporary Access Pass.
  • Bug Fixes: Resolves an issue where the File History restore interface might not find backups when a drive is selected as the backup location.

🚀 Availability

  • Users can install the update by opening Windows Settings, clicking Windows Update, and clicking ‘Check for Updates’.
  • Because it is an optional update, users must click the “Download and install” link unless they have the “Get the latest updates as soon as they’re available” option enabled.
  • The preview update can also be manually downloaded and installed from the Microsoft Update Catalog.
