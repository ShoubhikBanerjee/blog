Applus+ Posts IT Infrastructure Technician Job Opening

Applus+, a global testing, inspection, and certification company with presence in more than 70 countries across 5 continents and a team of over 28,000 people, is currently hiring a Systems and Infrastructure Technician for its Automotive Division IT team.

🏢 Role Overview

The position involves administration, support, and maintenance of distributed IT infrastructures. The selected candidate will join the Systems team and provide support to users, work centers, and servers while participating in technology renewal projects, migrations, security, networks, virtualization, databases, backups, and continuous infrastructure improvement.

📋 Requirements

  • Higher education as a network computer systems administrator (ASIR)
  • At least 3 years of experience in a similar role
  • Ability to work autonomously, analyze technical problems, implement controlled changes, and document actions properly

💻 Technical Responsibilities

Windows Administration

  • Windows 11 administration and support
  • Windows Server 2019, 2022, and 2025 administration
  • Server installation, configuration, updating, and maintenance
  • Service management, scheduled tasks, events, and system performance
  • Windows Server update troubleshooting
  • Shared resources and NTFS permissions administration
  • Basic IIS administration
  • PowerShell for administration, diagnosis, and task automation

Active Directory & Domain Services

  • User, group, computer, and service account management
  • Organizational unit administration
  • Group Policy (GPO) creation, application, and troubleshooting
  • Permission and delegation management
  • Domain join and removal of computers
  • Authentication, replication, and resource access troubleshooting
  • DNS and DHCP administration in Microsoft environments
  • Basic knowledge of domain controllers, global catalog, and FSMO roles

Networking

  • Solid TCP/IP knowledge
  • IP addressing, masks, gateways, and routing
  • VLANs, access/trunk ports, and network segmentation
  • DNS, DHCP, NAT, and name resolution
  • Diagnosis using ping, tracert, pathping, nslookup, Test-NetConnection, Wireshark or equivalent tools
  • Switch, firewall, and Wi-Fi incident configuration and resolution
  • User VPN and site-to-site VPN knowledge
  • Ability to interpret network diagrams and documentation
  • Experience with multiple connected centers or offices

Virtualization

  • Practical experience with Hyper-V, Proxmox VE, or equivalent platforms
  • Virtual machine creation and administration
  • CPU, memory, storage, and virtual network configuration
  • Virtual disk, snapshot, and checkpoint management
  • Virtual machine migration, export, import, cloning, and restoration
  • Performance, storage, and connectivity problem diagnosis
  • High availability and replication knowledge at operational level

Databases (SQL Server)

  • Basic SQL Server 2016+ administration
  • SQL Server Management Studio usage
  • Instance and service status verification
  • Connection management and basic access troubleshooting
  • Full, differential, and log backups
  • Database restoration and backup validation
  • SIMPLE and FULL recovery models
  • Backup chain verification
  • Backup history review
  • SQL Server Agent job management and monitoring
  • MDF, NDF, and LDF file location identification
  • Database and log size and growth review
  • Basic action for disk space issues or excessive log growth
  • Basic diagnostic query execution
  • Restoration verification capability

Backup Management

  • Physical and virtual server backup management and monitoring
  • Backup task configuration and review
  • File, virtual machine, and database restoration
  • Periodic backup validity verification
  • Restoration testing
  • Retention policy management
  • Backup task error interpretation and resolution
  • Synology Active Backup
  • Proxmox Backup Server
  • Other equivalent solutions

Hardware & Support

  • Hardware problem diagnosis on servers and workstations
  • Disk, memory, power supply, and other component replacement
  • RAID knowledge
  • Remote management interface usage (iLO, iDRAC)
  • Remote and on-site user and work center support
  • Performance, connectivity, and storage problem diagnosis

Linux Administration

  • Basic Debian or Ubuntu Server administration
  • User, group, and permission management
  • Service administration via systemd
  • systemctl, journalctl, apt, ssh, scp, rsync, and diagnostic tools usage
  • Basic network configuration
  • Log review
  • Firewall management with UFW or equivalent tools
  • Basic web server and other Linux services administration
  • Docker and Docker Compose usage
  • Image, container, network, and volume management
