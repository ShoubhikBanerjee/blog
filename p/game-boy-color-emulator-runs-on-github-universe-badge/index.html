Game Boy Color Emulator Runs on GitHub Universe Badge

I’m at GitHub Universe this week and, similar to last year, the conference badge is a full‑blown color screen computer. After hacking around with it again, I ran into Steve Francia… who worked with Gemini to get a full NES emulator working on it, and then went a step further and deployed an emulator for both the Game Boy and the Game Boy Color.

🔍 Overview

The GitHub Universe conference badge doubles as a tiny color‑screen computer that can run classic video‑game emulators.

🧩 How it works

  • Steve Francia collaborated with Gemini to build a NES emulator that runs on the badge.
  • The same effort produced emulators for the Game Boy and Game Boy Color, allowing the badge to execute games from those platforms.

⚙️ Features

  • Full‑blown color screen computer – the badge’s display is a real color LCD.
  • NES emulator – a complete Nintendo Entertainment System emulator runs on the badge.
  • Game Boy & Game Boy Color emulators – both handheld consoles are supported.
  • Run The Legend of Zelda: Link’s Awakening – if you can obtain the ROM, you can play the game on the badge.
  • Upside‑down mode with touch buttons – you can turn the badge upside down and use game‑controller touch buttons built into the badge body.

🚀 Availability

The badge is being handed out at GitHub Universe this week, so attendees can experiment with the emulators on‑site.
