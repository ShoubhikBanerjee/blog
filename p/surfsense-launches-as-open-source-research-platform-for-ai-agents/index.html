SurfSense Launches as Open-Source Research Platform for AI Agents

SurfSense has launched as an open-source, self-hostable alternative to NotebookLM, designed specifically as a research platform for AI agents. It provides a framework for agents to perform live web research, turning findings into structured briefs and alerts.

🔍 Overview

SurfSense functions as an agent harness that manages the infrastructure for web research, including retries, structured output, and credit metering. It allows users to go from a question to a cited brief without building custom plumbing.

🧩 How it works

Agents access live data through a single REST API or an MCP server. The platform exposes every connector as a native tool, compatible with Claude, Cursor, and other agent frameworks. It also supports external MCP connectors for integration with services like Notion, Slack, and Jira.

🚀 Availability

SurfSense is available as an open-source and self-hosted solution. The platform includes a built-in knowledge base that keeps findings searchable with citations, supporting features such as chat, reports, podcasts, presentations, and automations.
