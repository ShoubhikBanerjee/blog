SeaweedFS Offers Scalable O(1) Object and File Storage

SeaweedFS, a distributed storage system, has released a new iteration that enables scalable object storage and file serving.

🔍 Overview

SeaweedFS is a distributed storage system for object storage (S3), file systems, Iceberg table buckets, and Lance vector buckets, designed to handle billions of files with O(1) disk access and effortless horizontal scaling. SeaweedFS is a simple and highly scalable distributed file system. There are two objectives: 1. to store billions of files! 2. to serve the files fast!

🧩 How it Works

One SeaweedFS cluster serves an S3 object store, a POSIX file system, a lakehouse with S3 Tables and a built-in Iceberg REST Catalog, and vector search with S3 Vector Buckets, all on shared storage. Each blob is one disk read away, capacity grows by starting another volume server, and cloud storage can be cached or tiered transparently. Blob reads and writes have O(1) complexity and can run at the full speed supported by the underlying hardware.

⚙️ Key Details

  • HTTP REST API for the filer, master, and volume servers
  • Download Binaries for different platforms
  • SeaweedFS White Paper and introduction slides: 2025.5, 2021.5, 2019.3
  • Download the latest binary from the releases page and unzip the single weed (or weed.exe) file, or let the install script put it in /usr/local/bin
  • curl -fsSL https://raw.githubusercontent.com/seaweedfs/seaweedfs/master/install.sh | bash
  • For SeaweedFS Enterprise binaries, pass –enterprise to the script: … | bash -s – –enterprise.
  • Community: Slack, Twitter, Telegram, Reddit, Mailing List

🚀 Availability

AWS_ACCESS_KEY_ID=admin AWS_SECRET_ACCESS_KEY=secret S3_BUCKET=my-bucket ./weed mini -dir=./data The S3 endpoint is at http://localhost:8333, my-bucket exists, and admin/secret are valid credentials aws –endpoint-url http://localhost:8333 s3 cp README.md s3://my-bucket/ The same process also runs the master, a volume server, the filer, WebDAV, the Iceberg REST catalog, and the Admin UI. Add S3_TABLE_BUCKET=warehouse to also create an Iceberg table bucket, or warehouse:LANCE for a Lance one. Drop the AWS keys to run without authentication for development. Without Admin authentication or mTLS, weed mini binds the Admin UI/API and its worker gRPC control port to localhost only.

💡 Why It Matters

  • Scales effortlessly by adding volume servers.
  • Provides O(1) disk access for billions of files.
  • Supports multiple interfaces: S3, POSIX, Iceberg, vector search.
  • Easy to deploy with a single binary or install script.
