# AWS Quick Launches Enterprise AI Workspace for Task Automation and Data Analysis

AWS Quick is an AI-powered workspace designed for knowledge workers to automate tasks, analyze data, build web applications, and conduct research using natural language and AI agents.

## 🔍 Overview
AWS Quick provides a professional AI environment built on AWS infrastructure. It allows users to work across connected data sources and applications, with no consumer version of the product.

## 🧩 How it works
Users interact with AI agents that follow the reasoning and acting (ReAct) pattern within a managed agent loop (harness). These agents ground their answers in connected data.

| Component | Description |
| :--- | :--- |
| **Quick (Default Agent)** | A built-in agent with no fixed scope that works with any resources the user has access to. |
| **Custom Agent** | A configurable AI with specific instructions, knowledge sources, and connectors for a particular job. |
| **Space** | A curated collection of documents and AWS Quick resources used as an information source. |
| **Knowledge Base** | An organized, indexed collection of content optimized for retrieval and question answering. |
| **Skill** | A reusable set of instructions that teaches an agent how to perform a specific task. |
| **Dataset** | A prepared collection of data used for analyses and dashboards via AWS Quick Sight. |
| **Dashboard** | A published version of an analysis shared with other users. |

## ⚙️ Key details
*   **Connectivity:** 
    *   **Cloud Connectors:** Connect to services like Slack, Jira, Asana, Salesforce, Microsoft Outlook, and remotely hosted Model Context Protocol (MCP) servers.
    *   **Local Connectors:** Run on the user's machine, such as a self-hosted MCP server.
*   **Capabilities:** 
    *   Generate Word documents, PowerPoint presentations, Excel spreadsheets, or PDFs.
    *   Browse the web, run code, execute deep research, transcribe audio/video, and generate images.
*   **Knowledge Syncing:** Syncs from Google Drive, Microsoft OneDrive, Confluence, Microsoft SharePoint, Amazon S3, web crawlers, or Amazon Bedrock Managed Knowledge Bases.
*   **Security and Compliance:** 
    *   Integrated with AWS IAM, Microsoft Active Directory, and Microsoft Purview.
    *   Compliance certifications include HIPAA, FedRAMP, SOC 2, and ISO 27001.
    *   Provides audit trails through Amazon CloudWatch and AWS CloudTrail.

## 🚀 Availability
AWS Quick is currently being promoted through a brand campaign running across the United Kingdom and the United States via streaming TV, social media, online video, and business publications.
