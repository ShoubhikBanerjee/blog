# 🤖 Florence-2 Vision Models: Official Transformers Demo and Multimodal Capabilities

![Florence-2 Demo Screenshot 1](https://cdn-uploads.huggingface.co/production/uploads/65bb837dbfb878f46c77de4c/lJow1afS23EQEjSfL4Bc_.png)

## 🔍 Overview

The official Florence-2 Transformers-converted demo has been released, showcasing a
comprehensive suite of vision models designed for various computer vision tasks. This
demonstration platform provides access to multiple Florence-2 model variants, each optimized for
 different use cases and performance requirements. ✨

## 🧩 Available Model Variants

The demo features four distinct Florence-2 models, each with specific capabilities and optimization levels:

### Large Models
- **florence-community/Florence-2-large**: The flagship large-scale model offering maximum
accuracy and performance
- **florence-community/Florence-2-large-ft**: Fine-tuned version of the large model for enhanced
 task-specific performance

### Base Models
- **florence-community/Florence-2-base**: Lightweight base model balancing performance and
efficiency
- **florence-community/Florence-2-base-ft**: Fine-tuned base model optimized for specific vision
 tasks

## ⚙️ Supported Vision Tasks

The Florence-2 models excel across a comprehensive range of computer vision applications:

| Task Category | Capabilities |
| --- | --- |
| **Object Detection** | Identify and locate objects within images |
| **Image Captioning** | Generate descriptive text for images |
| **Detailed Captioning** | Provide comprehensive image descriptions |
| **Enhanced Captioning** | Deliver highly detailed visual narratives |
| **Dense Region Captioning** | Caption specific regions within images |
| **Region Proposal** | Suggest areas of interest for further analysis |
| **OCR (Text Recognition)** | Extract text from images |
| **OCR with Region** | Combine text extraction with spatial localization |
