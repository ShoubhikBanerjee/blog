# Pagekin: Open-source AI novel writing app

Pagekin, formerly AI Novel Writer, is a free, open-source AI novel writing app designed for long novels and web fiction. It is local-first, with no model bundled, and available for Windows and macOS. Maintained by EthanYoQ, Pagekin allows users to write and manage their works locally on their own computers.

## 🔍 Overview

- Free, open-source AI novel writing app
- Designed for long novels and web fiction
- Local-first, no model bundled
- Available for Windows and macOS
- Maintained by EthanYoQ

## 🧩 How it works

- Works exist on your own computer
- Software does not bundle models; users can connect their own API Key or use Ollama to run local models
- Supports importing novels in .txt, .md, or .epub formats
- Architecture page is divided into four sections: story premise, character list, world view, and plot outline
- Each character has basic settings, current status, and relationship map
- Character cards can be pasted or imported from files
- Blueprint page lists planned chapters
- Batch creation allows writing up to 10 chapters at a time
- AI uses the chapter's blueprint, relevant characters, world view, summary of previous text, and the full text of the previous chapter
- Text editor supports inserting two full-width spaces as paragraph indentation
- All generation tasks are managed in the running side page, divided into ongoing, history, and diagnostic pages
- Tracks main plot, subplots, and foreshadowing by chapter
- Knowledge base can be imported with reference materials in .txt or .md formats
- Export options include merged Markdown, chaptered Markdown, or TXT
- Works can be saved locally or backed up to a WebDAV cloud service
- Writing skills can be selected from a local folder or single SKILL.md file, or from a GitHub address
- Available in light and dark themes
- Supports Chinese and English interfaces
- Supports OpenAI compatible and Gemini native protocols
- Built-in presets for various service providers: DeepSeek, SiliconFlow, BigModel, OpenAI, xAI, Google Gemini, Ollama, NovelAI, and custom
- Semantic search in the knowledge base requires a separate vector model, configurable in the retrieval model settings
- Upgrades only update the application itself, preserving works, character cards, and settings
- Supports arm64 for Apple Silicon Macs (M1, M2, M3, M4, etc.)

## 🚀 Availability

- Free, open-source
- Windows & macOS
- Supports arm64 for Apple Silicon Macs

## 💡 Why it matters

- Provides a local-first approach to AI novel writing
- Offers flexibility in model usage and integration
- Supports multiple export and backup options
- Allows for detailed character and plot management
- Supports multiple languages and themes
- Offers a range of service provider presets
- Ensures data privacy by keeping works and settings local
- Preserves user data during upgrades
