# Microsoft Releases Semantic Kernel Starters for Multi-Language AI Development

## 📚 Introduction
Microsoft has released a new repository of starter projects for the Semantic Kernel, providing developers with ready-to-use code samples in multiple programming languages to accelerate AI application development.

## 📁 Repository Structure
The starter projects are organized to support different languages and runtimes. Each starter is a self-contained application that demonstrates fundamental Semantic Kernel patterns.

## 💻 Available Language Options

| Starter | Description |
|---------|-------------|
| C# Hello World | The Hello World C# console application starter for the Semantic Kernel |
| C# Console Chat | A console application based chat starter for the Semantic Kernel |
| C# Azure Functions | The Hello World C# Azure Functions starter for the Semantic Kernel |
| C# Azure ChatGPT Plugin | The Joke ChatGPT Plugin starter using C# Azure Functions for the Semantic Kernel |
| Python Hello World | The Hello World Python console application starter for the Semantic Kernel |
| Python Azure Functions | The Hello World Python Azure Functions starter for the Semantic Kernel |
| TypeScript Console Chat | A console application based chat starter for the Semantic Kernel |
| Java Hello World | The Hello World Java console application starter for the Semantic Kernel |
| Python Azure Functions ChatGPT Plugin | The Joke ChatGPT Plugin starter using Python Azure Functions for the Semantic Kernel |
| Python Flask ChatGPT Plugin | The Joke ChatGPT Plugin starter using Python Flask for the Semantic Kernel |

## 🚀 Getting Started
Developers can clone the repository using:
```
git clone https://github.com/microsoft/semantic-kernel-starters
```
Then navigate to any sample folder and open it in their editor:
```
code <any-sample-folder>
```
Individual README files within each sample provide setup and execution instructions.

## 🔧 Development Options
The Visual Studio Code Semantic Kernel Tools extension allows developers to create new applications using the starters through an integrated workflow.
