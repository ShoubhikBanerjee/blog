# Apple Tests Daily Usage Limits for Siri AI and Apple Intelligence Features

Apple released betas of iOS 27.3, iPadOS 27.3, and macOS 27.3, using the updates to test new per-device daily usage limits for select Siri AI and Apple Intelligence features.

## 🧩 How it works

Basic Siri commands and requests remain free and unlimited. However, advanced features relying on cloud-based processing are subject to daily limits. There are four categories of limited usage:

- Using Siri AI for multi-step, personal context requests
- Image generation and editing tools
- Automations in Shortcuts that rely on Apple Foundation Cloud and Cloud Pro Models
- Third-party apps that use those same cloud models

Apple has not specified exactly how many times these features can be used before limits are reached, noting that limits will vary based on the task. The company plans to provide notifications when users are approaching their limit and when they have finally reached it.

## ⚙️ Key details

Frequent users of these features will require an iCloud Plus subscription to avoid limits. Instead of waiting until midnight for usage to reset, most existing iCloud Plus plans (excluding the 50GB option) include higher daily limits at the same price:

| Plan | Monthly Cost | Usage Multiplier |
| :--- | :--- | :--- |
| 200GB | $2.99 | 2x |
| 2TB | $9.99 | 5x |
| 6TB | $29.99 | 10x |
| 12TB | $59.99 | 20x |

Family members sharing an iCloud Plus subscription will have a shared usage pool that is used on a first-come, first-served basis.
