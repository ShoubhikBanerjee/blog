# Chatbox Desktop Client Opens Up Under GPLv3 License

Chatbox has been open-sourced as a Community Edition under the GPLv3 license. The project provides a desktop client for interacting with various large language models across Windows, Mac, and Linux platforms.

## 🔍 Overview
Chatbox is positioned as an ultimate AI copilot on the desktop. It functions as a client that allows users to chat with multiple LLM providers through a unified interface.

## 🧩 Supported Providers
The application supports a variety of cutting-edge language models and local options:
- OpenAI (ChatGPT)
- Azure OpenAI
- Claude
- Google Gemini Pro
- Ollama (enables access to local models such as llama2, Mistral, Mixtral, codellama, vicuna, yi, and solar)
- ChatGLM-6B
- Image generation with DALL-E-3

## ⚙️ Key Details
- **Licensing:** The Chatbox Community Edition is open-sourced under the GPLv3 license.
- **Syncing:** Code is regularly synced from the pro repository to the community repository, and vice versa.
- **Setup:** Users download the appropriate installer for their platform from the releases page, install and launch Chatbox, configure their AI provider in settings, and begin chatting.

## 🚀 Availability
Chatbox is available for Windows, Mac, and Linux. Installation files can be obtained via the releases page.
