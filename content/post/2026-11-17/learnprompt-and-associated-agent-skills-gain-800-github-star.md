# LearnPrompt and associated agent skills gain 800+ GitHub stars

LearnPrompt, described as the account's earliest public project, has been updated with a suite of agent skills and automated tools. The project recently reached a milestone of 800+ stars within one month of launch. The update includes the AI News Radar's '伯乐' skill, which automated the maintenance of the radar tool, and a new collection of 14 installable Agent Skills designed for heavy agent users.

## 🧩 Core Features

The ecosystem now centers on several key tools:

*   **AI News Radar**: Utilizes GitHub Actions, web interfaces, and automated summaries to monitor AI and tech information sources. It determines the value of new sources via a 7-day cooling-off period, checks for content duplication, and identifies stable integration methods. Its first application was upgrading ai-news-radar from v0.6 to v0.7.0, merging 4 PRs in a single dialogue.
*   **Information Monitoring Methodology**: Establishes a public method for monitoring information sources that involves fixed scraping criteria, daily snapshots, historical comparisons, and report generation, with results posted to a GitHub Pages site.
*   **淘金小镇**: Tracks daily AI skill trends starting from ClawHub Top 100, expanding to monitor update logs (e.g., Claude Code) and model leaderboards (e.g., AA Index) with minimal environment dependencies.
*   **Humanize PPT**: Processes over 50 TED speeches to analyze main themes, audience perception, and narrative order before generating PPT content.
