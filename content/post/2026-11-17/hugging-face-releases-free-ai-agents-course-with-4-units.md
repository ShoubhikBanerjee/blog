# Hugging Face Releases Free AI Agents Course with 4 Units

## 📚 Course Introduction

This repository contains the Hugging Face Agents Course, a free educational resource divided into 4 units that take learners from the basics of agents to a final assignment with a benchmark.

## 📖 Course Structure**Unit 1: Foundations**
- Welcome, guidelines, necessary tools, and course overview
- Definition of agents, LLMs, model family tree, and special tokens

**Unit 2: Fine-tuning and Tools**
- Learn how to fine-tune an LLM for Function-Calling
- Overview of `smolagents`, `LangGraph`, and `LlamaIndex`

**Unit 3: Building Agents**
- Learn how to build effective agents using the `smolagents` library
- Learn how to build LLM-powered agents over your data using indexes and workflows with `LlamaIndex`
- Learn how to build production-ready applications using `LangGraph`

**Unit 4: Evaluation and Applications**
- Learn how to trace and evaluate your agents
- Learn how to use Agentic RAG to help agents respond to different use cases
- Automated evaluation of agents and leaderboard with student results
- Explore the exciting intersection of AI Agents and games

## 🔐 Prerequisites**Basic knowledge required:**
- Python programming
- Understanding of LLMs and their concepts

- `smolagents`: Lightweight framework for creating capable AI agents
- `LangGraph`: Production-ready applications with flow control
- `LlamaIndex`: Building agents over data with indexes and workflows
