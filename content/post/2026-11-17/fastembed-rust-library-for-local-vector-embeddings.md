# FastEmbed: Rust Library for Local Vector Embeddings

FastEmbed is a Rust library for generating vector embeddings and reranking locally. It supports synchronous usage without requiring a Tokio runtime and uses ONNX inference and fast encodings for performance.

## 🔍 Overview
- FastEmbed is a Rust library for generating vector embeddings and reranking locally.
- It supports synchronous usage without requiring a Tokio runtime.
- Uses ONNX inference and fast encodings for performance.

## ⚙️ Key Details
- Uses [@pykeio/ort](https://github.com/pykeio/ort) for performant ONNX inference.
- Uses [@huggingface/tokenizers](https://github.com/huggingface/tokenizers) for fast encodings.

## 🚀 Availability
- Python: [fastembed](https://github.com/qdrant/fastembed)
- Go: [fastembed-go](https://github.com/Anush008/fastembed-go)
- JavaScript: [fastembed-js](https://github.com/Anush008/fastembed-js)

## 💡 Why it matters
- FastEmbed provides a local solution for generating vector embeddings and reranking, which can be useful for applications that require offline processing or have strict latency requirements.
