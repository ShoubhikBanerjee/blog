# Langfuse Chart v2.0.0 and v2.2.0 Introduce ClickHouse 26.8, New Deployment Model

The Langfuse Helm chart has been updated to version 2.0.0, which ships Langfuse v4 by default, and version 2.2.0, which bumps the bundled ClickHouse server and Keeper images to 26.8.36.3. These releases replace the previous Bitnami-based approach with OSS-licensed alternatives and introduce several operational changes for deployments.
