# Stability Matrix: Multi-Platform Package Manager and Inference UI for Stable Diffusion

Stability Matrix is a multi-platform package manager and inference interface designed for Stable Diffusion. It provides one-click installation and updates for various Stable Diffusion Web UI packages and includes a built-in Inference interface.

## 🧩 How it Works
*   **Package Management**: Manages plugins and extensions for supported packages, including Automatic1111, Comfy UI, SD Web UI-UX, and SD.Next.
*   **Dependency Handling**: Easily installs or updates Python dependencies for each package without requiring global installation of Git or Python.
*   **Portability**: The application is fully portable; users can move Stability Matrix's Data Directory to a new drive or computer at any time.

## ⚙️ Key Details
*   **Version Channels**: The software is available in Latest Stable, Latest Preview, and Latest Dev versions.
*   **Inference Interface**: A reimagined interface built into Stability Matrix featuring:
    *   Powerful auto-completion and syntax highlighting using a formal language grammar.
    *   Workspaces that open in tabs and save/load from `.smproj` project files.
    *   Customizable dockable and float panels.
    *   Generated images that contain Inference Project, ComfyUI Nodes, and A1111-compatible data.
*   **Documentation**: Users can refer to the documentation index for installation, package management, model, and Inference guides. Recommended starting points include generating a first image, importing local models, or managing installed packages.

## 🚀 Availability
The application supports the following operating systems:
*   Windows 10 and 11
*   Linux (AppImage)
*   Arch Linux (AUR)
*   macOS (Apple Silicon)
