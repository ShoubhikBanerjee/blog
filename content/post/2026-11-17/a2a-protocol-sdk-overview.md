# A2A Protocol SDK Overview

The A2A Protocol SDK is a TypeScript/JavaScript SDK for the A2A Protocol Specification v1.0.0. It provides a single `DefaultRequestHandler` for three transports — JSON-RPC, HTTP+JSON/REST, and gRPC (Node-only). The SDK also supports persistent stores using PostgreSQL, MySQL, SQLite, or Cloudflare D1, with the `a2a-db` CLI for migrations.
