# A 21-Lesson Generative AI Course Offers a Faster Clone Option

## 🔍 Course structure

- Each lesson covers its own topic, so learners can start wherever they like.
- “Learn” lessons explain a Generative AI concept.
- “Build” lessons explain a concept and include code examples in Python and TypeScript when possible.
