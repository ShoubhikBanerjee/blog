# Meta Releases Llama 2 Open Foundation and Fine-Tuned Chat Models

Meta has announced the release of Llama 2, a collection of open foundation and fine-tuned chat models. This development, made public on July 18, 2023, includes the availability of these models on Hugging Face and builds upon previous research into efficient foundation language models.

## 🔍 Overview
Llama 2 is categorized as a set of open foundation and fine-tuned chat models. It follows the development of the initial LLaMA models, which were designed as open and efficient foundation systems. These models are part of a broader ecosystem of public projects encompassing large language models, vision foundation models, and AI-generated content.

## ⚙️ Key details
| Model | Source/Publisher | Key Attributes |
| :--- | :--- | :--- |
| LLaMA | Meta | Open and efficient foundation language models. |
| Llama 2 | Meta | Open foundation and fine-tuned chat models. |
| Llama 3 | Meta | Official GitHub implementation. |
| GPT-4 | OpenAI | Advanced system featuring vision and Mixture of Experts (MoE) architecture. |
| Gemma | Google | Official PyTorch implementation of models. |

## 🚀 Availability
- Llama 2 was released on July 18, 2023, and is available on Hugging Face.
- Inference code is available for the original LLaMA models.
- Meta has established an official GitHub site for Llama 3.
- Google's Gemma models are available via a PyTorch implementation.

## 💡 Why it matters
The release of Llama 2 is part of a progression in language model capabilities documented since 2018, including:
- Generative pre-training for improved language understanding (GPT-1).
- Unsupervised multitask learning (GPT-2).
- Few-shot learning capabilities (GPT-3).
- Instruction following and alignment through human feedback.
- Dialogue optimization for chat applications.
