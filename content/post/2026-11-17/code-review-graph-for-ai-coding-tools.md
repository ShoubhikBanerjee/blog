# Code Review Graph for AI Coding Tools

## 🔍 Overview

Code Review Graph is an AI development tool that builds a persistent map of your codebase to give AI coding tools precise review context over MCP.

## 🧩 How it works

* Builds a local-first code intelligence graph for MCP and CLI.
* Creates a local code knowledge graph that gives AI coding tools precise review context over MCP.
* Uses Tree-sitter to build a structural map of the code and serves compact context over MCP.

## ⚙️ Key details

* Requires Python 3.10+.
* Installs hooks and skills where the tool supports them.
* Uses a SQLite file for storage.
* Cloud embeddings are opt-in.

## 🚀 Availability

* Available for installation.
* Can be installed using the `install` command.

## 💡 Why it matters

* Reduces the amount of code that AI coding tools need to read.
* Improves the accuracy of AI coding tools.
* Enhances the overall coding experience.
