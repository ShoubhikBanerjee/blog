# Microsoft Agent Framework 1.0 Released as Production-Ready Successor to Semantic Kernel

Semantic Kernel is now Microsoft Agent Framework (MAF), the enterprise-ready successor designed for building AI agents and multi-agent systems. MAF is now available at version 1.0 as a production-ready release, featuring stable APIs and a commitment to long-term support.

## 🧩 Core Capabilities

Microsoft Agent Framework is a model-agnostic SDK that empowers developers to build, orchestrate, and deploy AI agents. Key features include:

*   **Multi-Agent Orchestration:** Orchestrate complex workflows with collaborating specialist agents, suitable for both single assistants and fleets of specialized agents.
*   **Model Support:** Connect to any LLM with built-in support for OpenAI, Azure OpenAI, Hugging Face, and NVidia.
*   **Modular Design:** Build modular AI agents with access to tools/plugins, memory, and planning capabilities.
*   **Input Processing:** Process text, vision, and audio inputs.
*   **Local Execution:** Run with Ollama, LMStudio, or ONNX.
*   **Workflow Modeling:** Model complex business processes with a structured workflow approach.

## ⚙️ Integration and Extensibility

The framework supports cross-runtime interoperability via the Agent-to-Agent (A2A) protocol and Model Context Protocol (MCP). Developers can extend agents using:

*   Native code functions
*   Prompt templates
*   OpenAPI specifications
*   Model Context Protocol (MCP)

It offers seamless integration with Azure AI Search, Elasticsearch, Chroma, and other data sources.

## 🚀 Platform Requirements

Microsoft Agent Framework 1.0 is built for observability, security, and stable APIs, with the following platform support:

| Language/Platform | Version Requirement |
| :--- | :--- |
| Python | 3.11 through 3.14 |
| .NET | .NET 10.0+ |
| Java | JDK 17+ |
| Operating Systems | Windows, macOS, Linux |
