# New drf-haystack library integrates Haystack with Django REST Framework

A new Python library, drf-haystack, has been released to simplify the integration of Haystack with Django REST Framework.

## 🧩 How it works
The library is implemented as a small package that bridges Haystack and Django REST Framework, enabling developers to more easily create API endpoints that leverage Haystack's search capabilities.

## ⚙️ Key details
The project has specific version requirements:

- Python >=3.11, <3.15
- Django >=5.2, <6.2
- Haystack >=3.3.0, <4
- Django REST Framework >=3.16
- Elasticsearch >=7.0.0, <8

## 🚀 Availability
The package can be installed via pip:

```
pip install drf-haystack
```

The library is designed to work with Elasticsearch versions 7.x.

## 💡 Features
The library supports several search features including:

- Autocomplete
- Boost (Experimental)
- Faceting
- Geo Spatial Search
- Highlighting
- More Like This
