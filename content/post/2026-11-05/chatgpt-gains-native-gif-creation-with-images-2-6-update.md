# ChatGPT gains native GIF creation with Images 2.6 update

OpenAI has rolled out an update to ChatGPT that adds native animated GIF generation.

## 🔍 Overview
- ChatGPT can now create GIFs from a text prompt or an uploaded photo.
- The capability is part of the new Images 2.6 model.
- Before this update, ChatGPT could not generate GIFs in a single step.

## 🧩 How it works
- Users provide a prompt such as “can you make a gif of a cat dancing?” or upload an image.
- The model returns an animated GIF and also offers controls to:
  * Adjust the animation speed.
  * Edit individual frames.
  * View the GIF frame by frame.
  * Share the result.

## ⚙️ Key details
- Images 2.6 also speeds up regular image generation.
- OpenAI reports that users now generate over 4 billion images per week across ChatGPT and its API, up from 3 billion in September.
- New API variants introduced with the rollout:

| Model Variant | Capability |
|---------------|------------|
| Images 2.6 | Native GIF creation and faster image generation |
| GPT‑Image‑2.6 Flare | Faster image generation |
| GPT‑Image‑2.6 Sunburst | Higher‑quality image generation |

## 🚀 Availability
- Images 2.6 is rolling out to all ChatGPT and Codex users on web, desktop, and mobile apps.

## 💡 Why it matters
- The update turns GIF creation into a native, single‑step operation within ChatGPT, expanding the range of media users can produce directly from text.
