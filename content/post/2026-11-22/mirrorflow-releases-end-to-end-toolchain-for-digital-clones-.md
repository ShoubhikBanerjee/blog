# MirrorFlow Releases End-to-End Toolchain for Digital Clones and Data Distillation

MirrorFlow has released version v0.1.6-dev of its end-to-end toolchain, currently in active development under the Apache-2.0 license. The project provides tools to process dialogue data, clean it, train models, and evaluate the results.

## 🧩 How it works

MirrorFlow offers a complete end-to-end pipeline that handles the following stages:

* Dialog data collection
* Cleaning and extraction
* Creating trainable samples
* Fine-tuning or distillation
* Model usage and evaluation

The toolchain currently supports two primary routes:

* **Digital Clone (数字分身)**: Uses your chat records for fine-tuning to recreate your personal expression habits.
* **Data Distillation (数据蒸馏)**: Focuses on aligning output structure, clarification methods, refusal habits, and tool-calling behaviors.

## ⚙️ Key details

The repository contains a complete workflow and tutorial for creating digital clones, which includes:

* QQ and TG (Telegram) data extraction
* Chat data cleaning and conversion
* The LlamaFactory fine-tuning process
* Testing and utilizing the fine-tuned models

Part of the codebase references Weclone. The project accepts contributions via Issues and Pull Requests, with a warning that contributors should only submit data they are authorized to share and must avoid sharing any private or sensitive information.
