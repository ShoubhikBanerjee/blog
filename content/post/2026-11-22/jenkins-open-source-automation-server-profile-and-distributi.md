# Jenkins open-source automation server profile and distribution methods

Jenkins is an open-source automation server built with Java that provides official distributions and source code for users and developers.

## 🔍 Overview
- It is described as the leading open-source automation server.
- It is built with Java.
- It provides over 2,000 plugins to support automating virtually anything.
- It is licensed under the MIT License.

## 🚀 Availability
Jenkins is trusted by millions of users and adopted by thousands of companies, from startups to enterprises.

- **Distributions:** The project provides official distributions as WAR files, Docker images, native packages, and installers.
- **Supported Platforms:** Installers are available for platforms including several Linux distributions and Windows.
- **Source Code:** The latest source can be found on GitHub.

## ⚙️ Release Management
- **Frequent Releases:** These include new features, improvements, and bug fixes.
- **Older Release Line:** Periodically updated via bug fix backports.
