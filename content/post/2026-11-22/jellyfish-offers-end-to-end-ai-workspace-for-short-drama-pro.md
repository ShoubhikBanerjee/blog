# Jellyfish offers end-to-end AI workspace for short drama production

Jellyfish is a new end-to-end production workspace designed specifically for AI-generated short dramas. It connects the full production flow, moving from script input to structured storyboarding, consistency management, shot preparation, video generation, and export within a single environment.

## 🧩 How it works
The system is structured to treat AI capability as infrastructure rather than a single utility. Key operational components include:
*   **Script Processing:** Splits chapter scripts into shots and extracts characters, scenes, props, costumes, and dialogue.
*   **Analysis & Optimization:** Runs script optimization, simplification, and consistency checks, supporting targeted analysis such as character portraits or scene details.
*   **Asset Management:** Facilitates extracting and refreshing shot candidates, accepting or ignoring asset and dialogue candidates, and linking existing characters, scenes, props, and costumes.
*   **Shot Preparation:** Corrects shot-level basic information, manages keyframes and reference images, and uses a unified readiness state to determine if a shot is prepared.
*   **Generation & Output:** Executes image and video generation tasks, performs single-shot and batch pre-checks, and writes generation outputs back into the shot and media system.

## ⚙️ Key details
Jellyfish addresses specific challenges in AI video production by integrating several core features:

| Feature | Description |
| :--- | :--- |
| **Consistency Management** | Centralized character, scene, prop, and costume management reduces drift across shots. |
| **Task Tracking** | Text, image, and video jobs go through a unified async task system with status, cancel, and recovery options. |
| **Asset Reusability** | Shots, candidate assets, dialogue, prompts, and generation tasks can be reviewed and reused as production assets. |
| **Extensibility** | Model management, prompt templates, files, and OpenAPI-based collaboration make the system extensible. |

## 💡 Why it matters
By treating consistency as a first-class problem and handling long-running generation as trackable tasks, Jellyfish allows teams to manage the complexity of multi-shot video generation. It transforms ephemeral AI outputs into structured, reusable production assets, enabling a more controlled workflow for short-form drama creation.
