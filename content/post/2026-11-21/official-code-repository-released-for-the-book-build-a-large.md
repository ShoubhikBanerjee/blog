# Official code repository released for the book 'Build a Large Language Model (From Scratch)'

An official code repository has been released for the book *Build a Large Language Model (From Scratch)*. The repository contains the code required for developing, pretraining, and finetuning a GPT-like large language model (LLM).

## 🔍 Overview
The book is designed to teach readers how large language models work from the inside out by coding them from the ground up, step by step. The method described for training a small-but-functional model for educational purposes mirrors the approach used in creating large-scale foundational models such as those behind ChatGPT. The guide includes clear text, diagrams, and examples to explain each stage of the process.

## ⚙️ Key details
- Includes code for loading the weights of larger pretrained models for finetuning.
- The `README.md` file is a Markdown file; if downloaded from the Manning website, users are recommended to use a Markdown editor or previewer for proper viewing.
- Ghostwriter is suggested as a free option for a Markdown editor.
- Users can view the files directly on GitHub in a browser, which renders Markdown automatically.
- Guidance on installing Python, Python packages, and setting up the code environment is available in the `setup/README.md` file within the `setup` directory.

## 🚀 Availability
The code repository is available on GitHub at `https://github.com/rasbt/LLMs-from-scratch`. Users can download a copy by clicking the Download ZIP button or by executing a terminal command to download the archive. Those who downloaded the code bundle from the Manning website are advised to visit the official GitHub repository for the latest updates.
