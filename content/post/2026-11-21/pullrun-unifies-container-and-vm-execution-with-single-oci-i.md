# Pullrun Unifies Container and VM Execution with Single OCI Image Support

Pullrun is a new AI development that collapses multiple execution engines into a single runtime, enabling the same OCI image to run as a container, Firecracker microVM, Apple Silicon VM, Kubernetes workload, or AI agent task. Modern infrastructure relies on disparate tools—Docker for development, containerd for production, Firecracker for isolation, and MCP agents for AI—each with separate image formats and storage models. Pullrun eliminates this fragmentation with a unified approach.
