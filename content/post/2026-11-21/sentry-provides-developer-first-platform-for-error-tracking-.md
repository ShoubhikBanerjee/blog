# Sentry Provides Developer-First Platform for Error Tracking and Performance Monitoring

Sentry provides a developer-first platform for error tracking and performance monitoring. The system is designed to assist every developer in detecting, tracing, and fixing issues to ensure code is repaired faster.

## 🔍 Overview
Sentry functions as a debugging platform for developers. It is built to address instances where code breaks, offering tools to streamline the identification and resolution of software problems.

## 🧩 How it works
The platform helps developers move from identifying symptoms to finding solutions by providing answers where logs only provide clues.

| Source | Function |
| :--- | :--- |
| Users and logs | Provide clues |
| Sentry | Provides answers |

## ⚙️ Key details
* Developer-first error tracking
* Performance monitoring
* Issue detection, tracing, and fixing
* Tools to fix broken code faster
