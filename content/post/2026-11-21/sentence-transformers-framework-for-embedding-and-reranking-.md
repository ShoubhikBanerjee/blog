# Sentence Transformers Framework for Embedding and Reranking Models

The Sentence Transformers framework provides an easy method to compute embeddings for accessing, using, and training state-of-the-art embedding and reranker models.

## 🔍 Overview
- The framework can be used to compute embeddings using Sentence Transformer models, calculate similarity scores using Cross-Encoder models, generate sparse embeddings using Sparse Encoder models, or compute token-level embeddings for ColBERT-style late-interaction retrieval using Multi-Vector Encoder models.
- It unlocks a wide range of applications, including semantic search, semantic textual similarity, and paraphrase mining.

## 🧩 How it works
- The framework provides over 15,000 pre-trained Sentence Transformers models available for immediate use on Hugging Face, including many state-of-the-art models from the Massive Text Embeddings Benchmark (MTEB) leaderboard.
- It is easy to train or finetune your own embedding models, reranker models, sparse encoder models, or multi-vector encoder models using Sentence Transformers, enabling you to create custom models for your specific use cases.

## ⚙️ Key details
- The framework is available for Python 3.10+, PyTorch 2.2+, and transformers v5.0+.
- Installation can be done via pip with `pip install -U sentence-transformers`.
- For higher Hugging Face Hub rate limits and access to private or gated models, log in with `hf auth login`.

## 🚀 Availability
- The full documentation is available at [www.SBERT.net](https://www.sbert.net).

## 💡 Why it matters
- The Sentence Transformers framework simplifies the process of computing embeddings and using reranker models, making it accessible for a wide range of applications in natural language processing and information retrieval.
