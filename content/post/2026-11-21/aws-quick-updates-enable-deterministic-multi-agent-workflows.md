# AWS Quick Updates Enable Deterministic Multi-Agent Workflows and Desktop Integration

AWS has released updates to AWS Quick, an AI workspace built specifically for work. These updates are designed to help teams complete everyday tasks by allowing users to describe a process in chat, which Quick then builds into a flow that orchestrates agents, skills, and tools with access to structured data, knowledge, and apps.

## 🧩 How it works

Users can now build, run, and refine flows entirely in chat. The system introduces new deterministic steps to make workflows consistent and verifiable, supporting longer-running processes and large data volumes. With multi-agent orchestration, several specialized agents work on a request simultaneously, and Quick combines their findings into a single response.

### Example Workflow: Financial Reporting

The update demonstrates a workflow for Maya, a financial planning and analysis manager, who prepares monthly reports for her VP of Finance. Previously, this process lived in her memory and a personal checklist, meaning teammates had to rebuild the report from scratch when she was out. Quick builds the flow from her description, allowing her to test and refine it in the same conversation. A diagram beside the chat displays each step for verification. The flow performs the following actions:
*   Pulls last month’s results from the team’s monthly results dashboard in Quick.
*   Compares each region to the annual plan in a budget spreadsheet using set formulas to ensure consistent calculations.
*   Flags regions that moved significantly from plan based on user-set thresholds and drafts commentary using a team-specific skill.
*   Drafts a Microsoft Excel summary to a shared Space and report email, and notifies the team in Slack that the draft is ready.

Jordan, an analyst on Maya's team, can run this flow from the Quick desktop app. The flow can utilize local resources, such as a spreadsheet of regional adjustments saved on his computer. Before the report is finalized, Jordan reviews the draft, asks for changes in chat, and approves it for the VP of Finance.

## ⚙️ Key details

The updated web app places items needing attention and a daily briefing on the home screen, adds agents and skills used on desktop, and keeps work running after the tab is closed. Quick also supports connections to external tools like Meta ads and Amplitude, allowing users to ask questions in natural language and combine answers with other sources. Language support has expanded to include Japanese, German, Chinese (Simplified and Traditional), and Vietnamese.

## 💡 Why it matters

AWS Quick Flows helps teams automate and standardize business processes. For organizations, this allows data teams to focus on complex, high-impact work. One retailer reported that without growing its team, nearly four times as many people now work with data each month. A single use case already saves 80 hours of work per month, shifting the culture from a few people building solutions to an organization where everyone can create, experiment, and change how they work.
