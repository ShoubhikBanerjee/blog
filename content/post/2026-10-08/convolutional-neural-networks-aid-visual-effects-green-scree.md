# Convolutional Neural Networks Aid Visual Effects Green‑Screen Workflows

On 7 October 2026, developers discussed how convolutional neural networks are being applied in visual‑effects pipelines to automate tasks like green‑screen removal.

## 🔍 Overview
- The visual effects workflow has included machine learning for many years.
- Convolutional neural networks (CNNs) are described as “the sort of precursors to what the transformer can do, which is just much more computation simultaneously.”

## 🧩 How it works
- Images are converted into **tensors**, which are a numerical translation of a visual image. A tensor includes the batch number, frame number, and the red, green, and blue values of each pixel in each frame.
- A CNN processes the tensor to **identify patterns** such as edge detection or feature extraction.
- These patterns allow the system to locate elements like a window ledge, making it easier to remove a green‑screen background and replace it with another image.
