# Google Launches Universal Gemini AI Agent for Enterprise Work Tasks

Google has announced a "universal" Gemini AI agent designed to work across apps and devices in the background to handle enterprise work tasks. Revealed during the Gemini at Work event on Thursday, the agent allows users to assign tasks and chat from a single interface within the Gemini Enterprise app.

## 🧩 How it works

The new Gemini agent is built to streamline workflows by operating across various environments:

* **Cross-app and device integration:** The agent runs directly inside Google Workspace apps like Gmail, Drive, Docs, Sheets, and Calendar. Users can also interact with it via mobile devices, desktop computers, the web, and third-party platforms such as Slack and Microsoft 365.
* **Cloud-based context:** Because it runs in the cloud, Gemini maintains the same context across all connected devices.
* **Smart model selection:** Gemini automatically performs tasks using whichever AI model best fits the specific job.
* **Collaborative capabilities:** The agent can work alongside job-specific sub-agents to complete tasks, or operate as a "coworker agent" with its own dedicated identity and a custom "@agents.company.com" email address.

## 🚀 Availability

Currently, the enterprise-focused Gemini agent is only available to enterprise customers in a private preview. It offers an early look at Google's broader vision of an AI assistant capable of answering questions and executing work from a single window.

This development follows Google's May launch of the consumer-facing Gemini Spark agent, which subscribers can use to complete tasks across Workspace and the web via a separate interface within the Gemini app.
