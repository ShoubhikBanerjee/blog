# Microsoft adds local file access to Copilot via Hybrid Intelligence

At the Windows and Surface event, Microsoft unveiled an upgrade to its Copilot AI system that lets the assistant read local files on a PC and act across the operating system.

## 🔍 Overview
Microsoft calls the new approach **Hybrid Intelligence** – a mix of local and cloud AI models that lets apps and tools complete tasks efficiently.

## 🧩 How it works
* Hybrid Intelligence gives Copilot permission to scan folders on the Windows PC, locate files, rename them, zip them, and draft emails.
* During the demo, Jacob Andreou, Microsoft’s EVP of Copilot, asked the Autopilot agent to help file taxes. The agent used Hybrid Intelligence to find the accountant’s needed documents, package them, and prepare a message with the zip file attached.
* The same technology powers a refreshed Windows search experience that lets users perform quick actions directly from the search bar.

## ⚙️ Key features
- **Local file access** – Copilot can browse the user’s folders and use the contents to carry out tasks.
- **Cross‑OS actions** – The assistant can rename files, create zip archives, and send emails without leaving the AI chat.
- **Quick‑action search** – The new Windows search bar includes in‑line controls such as a dark‑mode toggle, a microphone‑volume slider, and a one‑click option to send a text.

## 🚀 Availability
- Features powered by Hybrid Intelligence will roll out over the “next couple months,” according to Jacob Andreou.
- The new Windows search experience ships this fall on Windows 11 PCs, announced by Windows and Surface boss Pavan Davuluri.
