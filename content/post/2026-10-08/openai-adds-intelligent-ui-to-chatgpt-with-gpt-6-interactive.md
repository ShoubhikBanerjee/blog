# OpenAI adds Intelligent UI to ChatGPT with GPT‑6 interactive visuals

OpenAI is rolling out an **Intelligent UI** feature in ChatGPT that pairs text responses with interactive visuals such as diagrams, charts, forms, and tappable buttons. The update launches alongside the new GPT‑6 models.

## 🔍 Overview
- ChatGPT can now combine a text reply with interactive visuals.
- The feature is part of the GPT‑6 rollout and works for all users.
- Responses may include diagrams, charts, forms, and buttons that users can interact with directly in the chat.

## 🧩 How it works
OpenAI explained that it trained GPT‑6 on *when* to generate interactive visuals over plain text and on *how* to format those visuals within its response. This training enables the model to decide the appropriate moment to insert a diagram or button and to render it correctly in‑line.

## ⚙️ Key features
- **Interactive diagrams** – e.g., a seven‑speed bicycle design with buttons that highlight each part.
- **Scrollable visual categories** – e.g., Mahjong tiles displayed as scrollable groups.
- **In‑line tool generation** – ChatGPT can create a retirement‑savings calculator, a retro‑game, or a bill‑splitting tool directly within the conversation.
- **Better web searches** – GPT‑6 improves web search performance and delivers quicker, partial answers while gathering information.
- **Enhanced safety** – GPT‑6 showed stronger resistance to attempts to bypass its safety training.

## 📦 Model variants
| Tier | GPT‑6 Model |
|------|------------|
| Plus / Pro / Business / Enterprise | Sol (mid‑range) |
| Go / Free | Luna (more efficient) |

## 🚀 Availability
- Rolling out globally today to ChatGPT **Plus**, **Pro**, **Business**, and **Enterprise** users.
- Access for **Go** and **free** tiers will begin on Thursday.
