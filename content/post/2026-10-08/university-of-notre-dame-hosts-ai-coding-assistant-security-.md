# University of Notre Dame Hosts AI Coding Assistant Security Workshop

On Thursday, October 8, 2026, the AI Collaborative Programming group offered a virtual, hands‑on workshop where participants put AI coding assistants to the test in a web‑application security sandbox.

## 🔍 Overview
- **Date & Time:** Thursday, October 8, 2026, 1:00 pm – 2:00 pm
- **Format:** Virtual (250I Hesburgh Library link)
- **Goal:** Identify and patch common security flaws using AI‑assisted tools while maintaining strict human oversight.

## 🛠️ Workshop Content
- Work with AI tools such as **GitHub Copilot** or **VS Code** alongside an **OWASP Juice Shop** instance.
- Follow a human‑in‑the‑loop workflow:
  - Isolate a vulnerability.
  - Create a Git branch.
  - Prompt the AI for a secure fix.
  - Verify the patch against insecure defaults.
  - Write clean PR documentation.
- Learn to:
  - Critique AI‑generated code.
  - Spot dangerous hallucinations.
  - Maintain rigorous developer oversight.

- **Open to:** Undergraduate and graduate students, faculty, staff, and postdocs.

## 📅 Details
- Part of a series offered by the **AI Collaborative Programming** group, a partnership between **Hesburgh Libraries**, **ND Learning**, and the **Office of Information Technology**.
- Location for the virtual session: **250I Hesburgh Library**.

## 💡 Why It Matters
- Demonstrates practical ways to integrate AI coding assistants into secure software development.
- Emphasizes the importance of human review to mitigate AI‑generated errors.
- Provides a reproducible sandbox for learning secure coding practices.
