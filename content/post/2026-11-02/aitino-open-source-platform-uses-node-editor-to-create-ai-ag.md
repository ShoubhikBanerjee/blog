# Aitino Open-Source Platform Uses Node Editor to Create AI Agent Teams

Aitino is an open-source platform designed for creating teams of AI Agents to automate high-level tasks and solve complex problems without lengthy and complicated setups.

## 🔍 Overview
The platform aims to go from a prompt to a solution in a matter of minutes. Users need to provide only required information, such as API keys, context, and specific task details, taking just seconds to configure.

## 🧩 How it works
- **Node Editor**: Aitino features a visual node editor interface, designed to remain simple for small use cases while scaling for highly complex agent teams.
- **Autogen Framework**: The platform is built on top of the Autogen Framework.
- **System Integration**: Aitino plans to merge principles from other multi-agent projects, such as ChatDev and CrewAI, to support features that are out of reach using Autogen alone.

## ⚙️ Key details
Source code for the platform is publicly available, and the project actively welcomes contributions and suggestions. Developers interested in paid development opportunities can reach out to join the project. The technology stack powering Aitino includes:

- **Framework**: SvelteKit
- **Styling**: TailwindCSS
- **Components**: shacn-svelte
- **Database**: Supabase
- **Payment Processing**: Stripe
- **Hosting**: Vercel

Aitino Web serves as the cloud-hosted version of the platform. A free plan is coming soon to allow users to test the platform's capabilities.
