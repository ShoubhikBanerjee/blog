# Battle Drones browser RTS developed using AI coding agents and vibe coding

Battle Drones is a new Command & Conquer style Real Time Strategy (RTS) game developed as a "vibe coded" experiment. Built using AI coding agents, the browser-based game works on both mobile and desktop, featuring multiple play modes and support for both online and local audio-based multiplayer.

## 🔍 Overview

The project was built primarily using Claude Code, which contributed 321 commits across 12 major iterations. Development began in July using Claude Fable 5 and the Phaser 2D game framework, with later versions utilizing Claude Opus to regenerate sprites and improve visuals. The developer practiced "vibe coding," reviewing almost none of the source code and building the game in TypeScript, a language they have rarely used.

## ⚙️ Key details

The game includes a variety of units and environmental features designed for strategic play. Units and structures are rendered as 3D models and include:

*   9 buildings
*   7 ground vehicles
*   6 aerial vehicles
*   3 infantry units
*   The Goliath: A giant mech equipped with laser eyes and arm cannons that can establish new bases

Gameplay mechanics include fog of war, specialized weapons for targeting ground or aerial units, crate drops with bonus resources, and in-game music that increases in intensity during combat. Players can progress through ranks and earn medals for achievements.

## 🧩 How it works

Battle Drones features several distinct modes of play and environmental variety:

| Mode | Description |
| :--- | :--- |
| Skirmish | Red vs. blue combat on a rotationally symmetrical map |
| Last Stand | A survival mode holding out against waves of enemies |
| AI vs. AI | A spectator mode to watch different computer personalities compete |
| Agent vs. Agent | A mode where two LLMs play the game against each other |
| Daily Op | A recurring daily challenge |

The game offers six maps across five biomes: temperate, desert, arctic, volcanic, and tropical. A random map generator is also included to provide new layouts. Players can select from different AI personalities, including Balanced, Rush, Air Swarm, Boom, Skyforce, and Ironclad. 

## 🚀 Availability

Battle Drones is accessible via browser on mobile and desktop platforms. It supports online multiplayer and a unique local multiplayer system where two nearby devices use audio messages to synchronize game state. The game also includes "Mutators" that allow players to add extra rules or twists to their sessions.
