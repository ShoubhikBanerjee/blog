# Battle Drones released, French fork 'Panache' adds steampunk reskin

On 20 October 2026 the game **Battle Drones** was released under an Apache 2.0 license.

## 🔍 Overview
- Battle Drones is a vibe‑coded RTS with audio‑based multiplayer.
- It was released on 20th October 2026.
- The source code is available under an Apache 2.0 License.

## 🎨 French Fork “Panache”
- A community‑maintained French language fork called **Panache** reskins the game to take place in steampunk 1900s France.
- The fork adds an animated intro.
- Changes are mostly aesthetic rather than gameplay‑related.
- The music has been given a French twist.

| Feature | Description |
|---|---|
| Setting | Steampunk 1900s France (Belle Époque) |
| Visuals | Reskinned graphics, animated intro |
| Gameplay | Primarily aesthetic updates, no major gameplay changes |
| Audio | French‑style music added |

## ⚙️ Technical Details
- The original game is released under an Apache 2.0 License, enabling forks such as Panache.
- Panache is a French language fork that builds on the original code base.

## 🚀 Availability
- Battle Drones: released 20 October 2026, open‑source under Apache 2.0.
- Panache fork: available in French, includes the described aesthetic enhancements.

## 💡 Why it matters
- The open‑source license permits community members to create language‑specific forks.
- The French fork demonstrates how the community can customize the look, feel, and audio of an RTS without altering core gameplay.
