# Trovata adds autonomous AI agents to its treasury operating system

Trovata has upgraded its AI‑native cash and liquidity management platform with autonomous agents that can act on behalf of treasury teams.

## 🔍 Overview
- AI‑native cash and liquidity management platform with direct connections to **over 10,000 banks** from a single cloud‑based system.
- In **2023**, Trovata launched the **first generative AI built specifically for treasury**.
- Latest AI‑native updates shift from delivering static insights to **deploying autonomous agents** that operate continuously for treasury teams.
- The AI is **embedded directly into the treasury operating system**, not a generic chatbot layered on top.

## 🧩 How it works
- Autonomous treasury agents run on **schedules, triggers, or rules** to monitor activity, explain variance, detect anomalies, and deliver updates automatically.
- Agents are built on **Amazon Bedrock AgentCore**, a secure, isolated environment purpose‑built for enterprise AI.
- When a user asks a question, the AI retrieves data through **Trovata’s verified API layer**, analyzes it, and returns the response within the same secure infrastructure.
- Users can query bank data in **plain English** via natural‑language querying.

## ⚙️ Architecture
| Component | Role |
|---|---|
| Amazon Bedrock AgentCore | Secure, isolated environment for autonomous agents |
| AI Insights | Automated anomaly detection, variance explanation, and trend analysis |
| Agent Builder‑Configurator | Management console for building and configuring treasury agents |
| Enterprise RBAC | Role‑based access control that keeps agents within the same permission boundaries as human users |
| Direct bank connections | Provides cash reporting, forecasting, analysis, and money movement across **10,000+ banks** |

## 💡 Impact
- **$1M+** in annualized cost savings for customers.
- **>5 hours per day** saved per accounting team.
- **77 % reduction** in annual Treasury Management System (TMS) costs.
- Treasury reporting time reduced from **hours or days to under a minute**.
- Cash forecasting is now **automated across multi‑bank environments** with scenario modeling, replacing manual spreadsheet‑based projections.
- Real‑time **anomaly detection** identifies unusual transactions, balance changes, or cash‑flow patterns that could indicate errors, fraud, or operational issues.
