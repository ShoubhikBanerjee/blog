# Experimental Tool Created with GPT-6 Astra to Automatically Blur Faces

An experimental tool has been developed using GPT-6 Astra that identifies faces and automatically blurs them out.

## 🧩 How it works

The tool utilizes the following components:

| Component | Detail |
| :--- | :--- |
| Library | Google's MediaPipe C++ library |
| Compilation | WebAssembly via @mediapipe/tasks-vision |
| Model | BlazeFace face detection model |
