# OpenAI Launches Dots Always-On AI Assistants Powered by GPT-6 Astra

OpenAI has announced Dots, always-on AI assistants designed to perform tasks across connected apps in the background while learning user preferences over time.

## 🔍 Overview
Dots are described by OpenAI as assistants that can "do nearly anything" by utilizing a cloud computer and connected apps. 

## 🧩 How it works
Dots are powered by the GPT-6 Astra model and operate using their own cloud computer to access a web browser and over 4,000 supported apps. Users can interact with Dots via:

* A text-message-like interface similar to Muse
* Voice calls via ChatGPT on mobile, desktop, or the web
* Text messages (coming soon)

Users can monitor a Dot's progress by accessing its cloud computer. Additionally, Dots can connect to Slack and Microsoft Teams, carrying over context from other devices and apps.

## ⚙️ Key details
Dots include several management and safety features:

* **Custom Rules:** While Dots have built-in rules for independent action, users can set custom rules to block specific actions or require permission.
* **Auto-Review:** This feature verifies if actions comply with safety requirements and custom rules, and determines which tasks (such as changing a password) must be handed off to the user.
* **Collaboration:** Users and colleagues can work with a Dot within ChatGPT Space, a new collaborative workspace.
* **Personalization:** Dots learn while working to personalize output and identify tasks to complete "before you even think to ask," according to OpenAI.

| User Role | Example Task |
| :--- | :--- |
| Developer | Use customer feedback to build and test updates and provide a video of changes |
| Content Creator | Review interview transcripts, find clips, create show notes, and write social posts |

## 🚀 Availability
OpenAI is rolling out Dots today to the following user groups:

* ChatGPT Pro
* Business Premium
* Enterprise

Conversations with Dots do not count toward ChatGPT usage limits. Currently, users can only create one Dot, though OpenAI plans to allow multiple agents and the ability to scale speed or monthly workload in the future. OpenAI is also testing "specialist" Dots for specific organizational roles.
