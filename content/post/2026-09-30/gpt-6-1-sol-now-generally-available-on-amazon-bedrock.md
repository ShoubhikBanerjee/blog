# GPT-6.1 Sol Now Generally Available on Amazon Bedrock

GPT-6.1 Sol is now generally available on Amazon Bedrock, providing an upgrade to GPT-6 Sol with enhanced reasoning for coding, computer use, and professional workloads.

## 💡 Why it matters

For AI agents, the cost and success of a task are influenced by token prices and reasoning quality. A wrong turn in decision-making can increase latency, model interactions, tool calls, and the need for human intervention. GPT-6.1 Sol aims to reduce these frictions by bringing stronger reasoning to agentic work at a fraction of the cost per task, allowing agents to reach results in fewer steps.

## ⚙️ Key details

According to OpenAI, GPT-6.1 Sol offers the following performance improvements:

* **Efficiency:** Matches GPT-6 Astra on DeepSWE v1.1 at roughly one-fifth the cost per task.
* **Reasoning:** Exceeds the best score from GPT-6 Sol by 6.4 percentage points while using lower reasoning effort than that specific GPT-6 Sol result.
* **Intelligence:** Brings near-Astra intelligence to everyday workflows and approaches GPT-6 Astra on complex document analysis.
* **Workflows:** Improves on GPT-6 Sol when completing multistep workflows across business tools and in evaluations of user intent, transparency, and explicit restrictions.

## 🧩 How it works

Users can leverage GPT-6.1 Sol through several interfaces and tools:

| Tool | Capabilities |
| :--- | :--- |
| **Codex** | Configurable to use GPT-6.1 Sol for investigation, implementation, and testing; works with repositories, local files, terminals, and development tools. |
| **ChatGPT Work** | Gathers information across files and applications in the desktop app to create finished deliverables. |
| **Agent Toolkit for AWS** | Connects Codex to AWS documentation, APIs, and services via a single terminal command. |
| **Amazon Bedrock APIs** | Used to build internal tools for document synthesis, coordinating agents across systems, and customer-facing applications. |

## 🛡️ Security and Governance

Amazon Bedrock provides the infrastructure to run GPT-6.1 Sol in production with the following controls:

* **Access & Audit:** Model access is governed via AWS Identity and Access Management (IAM) policies, with invocations audited through AWS CloudTrail.
* **Networking:** Virtual private cloud (VPC) endpoints powered by AWS PrivateLink help keep traffic within network boundaries.
* **Privacy:** Inference runs on hardware-isolated infrastructure with zero-operator access. Inference data is not used for model training, and users are not required to opt into sharing data with OpenAI.
* **Data Retention:** Classifier-flagged traffic for automated abuse detection is retained by AWS for up to 30 days; zero data retention can be requested through AWS account teams.

## 🚀 Availability

GPT-6.1 Sol is available through the Amazon Bedrock console or programmatically via supported Amazon Bedrock APIs. Codex can be accessed via CLI, the desktop app, and supported IDEs.
