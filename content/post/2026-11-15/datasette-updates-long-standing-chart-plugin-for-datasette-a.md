# Datasette Updates Long-Standing Chart Plugin for Datasette Alpha and Lite Compatibility

On 14th November 2026, a new release was issued for Datasette's longest untouched plugin, which enables chart rendering using Vega-Lite against table data or custom queries. This update marks the first release for the plugin since July 2018.

## ⚙️ Key details

*   **Compatibility:** The plugin has been updated to work with the latest Datasette alphas.
*   **Cosmetic Tweaks:** The release includes visual adjustments to improve the user experience within Datasette Lite.
*   **JavaScript Support:** Datasette Lite recently gained the capability to execute JavaScript plugins such as this one.

## 🧩 How it works

The plugin allows users to visualize data stored in Datasette tables or retrieved through custom queries. It utilizes the Vega-Lite framework to render these charts directly within the interface.

## 🚀 Availability

Because the plugin is now compatible with Datasette Lite, the live demo previously hosted in the project's README has been updated to link to a new demo running on Datasette Lite.
