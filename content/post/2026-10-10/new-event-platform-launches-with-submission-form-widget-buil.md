# New Event Platform Launches with Submission Form, Widget Builder, and Digest Emailer

A new event‑management platform was announced that lets organizers quickly add events, embed them on any site, and receive personalized email digests.

## 🔍 Overview
- Users can **submit their own event using a simple event submission form**. 
- The process **only takes a minute**.
- Events can be **embedded anywhere on the web with a Widget builder**.
- A **personalized list of events can be sent to an inbox with a Digest emailer**.

## 🛠️ Features
- Simple one‑minute event submission form
- Web‑embeddable widget for displaying events
- Automated email digest with custom event lists

## 🚀 Getting Started
- **Submit** an event through the online form (takes about a minute).
- **Build** a widget to embed the event list on any web page.
- **Subscribe** to the digest emailer to receive a personalized schedule.

*All features are available immediately upon launch.*
