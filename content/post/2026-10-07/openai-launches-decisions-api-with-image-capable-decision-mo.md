# OpenAI launches Decisions API with image‑capable decision model

OpenAI released its new Decisions API, a Jev‑style service announced at last week’s DevDay.

## 🔍 Overview
- The Decisions API follows the same conceptual shape as the existing Jev service.
- Announced during OpenAI’s DevDay.

## 🧩 How it works
- Supports three question types: yes/no, multiple‑choice, and scoring.
- Accepts text input; the gpt‑6‑luna decision model also accepts image input.
- Charges are applied only to input tokens.

## ⚙️ Key details
- Pricing: 10 ¢ per million input tokens for OpenAI; Jev charges 4.2 ¢ per million input tokens.
- No fee for output tokens.
- A plugin (llm‑openai‑decisions) can be installed; the README shows the install command.
- The README includes an example query against an image attachment and the corresponding example output.

## 🚀 Availability
- The service was announced at last week’s DevDay and is available via the new plugin.
