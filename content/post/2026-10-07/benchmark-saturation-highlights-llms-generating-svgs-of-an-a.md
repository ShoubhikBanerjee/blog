# Benchmark Saturation Highlights LLMs Generating SVGs of an Armadillo on Mars

On 6 October 2026, the community observed that a leading benchmark had become saturated, leading researchers to test frontier models with a whimsical prompt: an armadillo in fishnet tights jaywalking on Mars.

## 🔍 Overview
- The benchmark is saturated. (Quoted by wren6991)
- Frontier models are being evaluated using the prompt “Generate an SVG of an armadillo in fishnet tights jaywalking on Mars.”

## 🧩 Models Tested
| Model | Prompt Command |
|-------|----------------|
| claude‑opus‑5.5 | `llm -m claude-opus-5.5 'Generate an SVG of an armadillo in fishnet tights jaywalking on Mars'` |
| gpt‑6.1‑sol | `llm -m gpt-6.1-sol 'Generate an SVG of an armadillo in fishnet tights jaywalking on Mars'` |
| gemini‑3.8‑flash | `llm -m gemini-3.8-flash 'Generate an SVG of an armadillo in fishnet tights jaywalking on Mars'` |
| mistral‑large‑4 | `llm -m mistral/mistral-large-4 'Generate an SVG of an armadillo in fishnet tights jaywalking on Mars'` |

## ⚙️ Prompt and Output
- The same natural‑language prompt was issued to each model.
- Each model returned an SVG representation of the requested scene.
- Default reasoning levels for each model are documented at: https://tools.simonwillison.net/markdown-svg-renderer?url=ht...

## 📊 Benchmark Note
- The observation “The benchmark is saturated.” signals that current evaluation metrics no longer differentiate model performance, prompting creative stress tests like the armadillo SVG task.
