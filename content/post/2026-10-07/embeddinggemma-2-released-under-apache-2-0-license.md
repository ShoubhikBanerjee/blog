# EmbeddingGemma 2 released under Apache 2.0 license

EmbeddingGemma 2, an embedding model, was announced on 6 October 2026 and is licensed under Apache 2.0.

## 🔍 Overview
- The model is designed for generating embedding vectors, which are commonly calculated in the thousands or millions and stored for later similarity comparison.
- Its open‑source Apache 2.0 license means the weights are publicly available for anyone to download and run.

## 💡 Why it matters
- Embedding models are often used at scale, so relying on a closed, proprietary, hosted‑only model can create vendor lock‑in risk.
- If a provider stops offering a proprietary model, users may have to re‑embed all stored vectors, incurring additional cost.
- An open‑license model lets users switch providers or self‑host later, avoiding that risk.

## ⚙️ Key details
- **License:** Apache 2.0 (open source, permissive).
- **Target use‑case:** Large‑scale embedding generation where millions of vectors are stored for later comparison.
- **User preference expressed:** Pay a provider for hosted inference while retaining the ability to run the open‑weights version themselves if hosting ends.

## 🚀 Availability
- The model’s weights are publicly available under the Apache 2.0 license, allowing anyone to download and run the model independently.
- Users can still choose a hosted service for convenience, knowing they have a fallback option.
