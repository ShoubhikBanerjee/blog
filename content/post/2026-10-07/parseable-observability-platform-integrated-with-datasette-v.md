# Parseable Observability Platform Integrated with Datasette via Codex

On 6 October 2026 a new observability platform called **Parseable** was highlighted on Show HN.

## 🔍 Overview
- Parseable is an observability platform with:
  - An open‑source implementation licensed under AGPL, written in Rust, packaged as a single ~180 MB binary.
  - An *Enterprise* version that adds extra features.
  - A cloud‑hosted option.

## 🧩 How it works
- Datasette 1.0a41 added OpenTelemetry support.
- Using Codex, the author figured out how to run Parseable and feed it traces generated by Datasette.
- The resulting trace was displayed in the Parseable localhost web application.

![Parseable trace screenshot](https://s3.amazonaws.com/til.simonwillison.net/e9a57965786659e60073c5d26b83d268.jpg)

## ⚙️ Key details
- **Open‑source binary**: AGPL, Rust, ~180 MB.
- **Enterprise version**: includes additional features (unspecified). 
- **Cloud option**: available as a hosted service.
- **Integration steps**:
  - Enable OpenTelemetry in Datasette 1.0a41.
  - Use Codex to determine the commands needed to start Parseable and ingest the traces.
  - View the trace in Parseable's web UI.

## 🚀 Availability
- The open‑source binary and its documentation are publicly available as of 6 October 2026.
- Enterprise and cloud offerings are announced alongside the open‑source release.

## 💡 Why it matters
- The combination shows a practical workflow for connecting a data‑exploration tool (Datasette) with an observability platform (Parseable) using AI assistance (Codex).
