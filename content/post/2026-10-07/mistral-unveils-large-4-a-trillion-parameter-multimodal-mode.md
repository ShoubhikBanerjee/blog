# Mistral unveils Large 4, a trillion‑parameter multimodal model in API preview

Mistral AI announced a public API preview of Large 4, a trillion‑parameter multimodal model, with the model weights slated for release later this month.

## 🔍 Overview
- Large 4, also dubbed **Le Chonk**, is Mistral’s newest large‑scale model offering native multimodal capabilities.
- The model is being made available first through an API preview, allowing developers to experiment before the full weight release.

## 🧩 Features
- **1 trillion parameters** – provides a large capacity for diverse tasks.
- **Native multimodal support** – can process multiple data types without external adapters.
- **49 billion active parameters** – a substantial active portion of the architecture.
- **Benchmark leadership** – described as the best open‑weights model from the US or Europe on aggregated benchmarks.
- **State‑of‑the‑art performance** on critical workloads such as cyber defence, manufacturing and finance, surpassing prior Mistral offerings.

## ⚙️ Availability
- An API preview is currently live for developers to test the model.
- Full model weights will be released later this month; they are not yet publicly downloadable.

## 💡 Why it matters
- By delivering a trillion‑parameter multimodal model as an open‑weights option, Mistral aims to broaden access to high‑capacity AI for research and industry.
- Superior performance on security‑related, industrial, and financial tasks positions Large 4 as a competitive choice for enterprises needing advanced AI capabilities without relying on proprietary closed models.
