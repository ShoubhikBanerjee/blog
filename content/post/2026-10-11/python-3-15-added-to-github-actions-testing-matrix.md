# Python 3.15 Added to GitHub Actions Testing Matrix

On 10 October 2026 a blog post announced that Python 3.15.0 has been added to the **actions/python-versions** repository, making the new interpreter available for GitHub Actions workflows.

## 🚀 Availability
- Python 3.15.0 added to `actions/python-versions` (10 Oct 2026).
- The release enables you to add `"3.15"` to a GitHub Actions testing matrix to run tests against the new Python release.

## 🛠️ How to use
- In your workflow YAML, include `"3.15"` as a value in the `python-version` matrix entry.
