# inMusic Opens Up Gear for Community Modding with Open‑Source Toolkits

inMusic, the parent company behind Akai, Moog, Native Instruments and others, announced that it will actively support the music‑gear modding community by releasing source code and development tools for several of its products.

## 🔍 Overview
- inMusic decided to embrace the modding community.
- The move follows a broader industry shift where companies are opening hardware for user‑driven innovation.

## 🛠️ Toolbox Details
- In an interview with *The Verge*, inMusic CEO Jack O’Donnell said, “We’re going to provide a toolbox to the community, we’re going to provide the inner workings of, say, an MPC or Sample so that people can do what they want.”
- The toolbox includes:
  - Open‑sourcing the code for the recently teased **MPC Sample Key**.
  - Providing an SDK that makes modifications easier and reduces the risk of “bricking your beloved sampler.”
- O’Donnell added, “We’ll try to give them a reset button,” so that “They can experiment with it, and then not lose what they have.”

## 🎹 Products Being Open‑Sourced
| Company | Device | Open‑Source Status |
|---------|--------|--------------------|
| inMusic (Akai) | MPC Sample Key | Code released, SDK provided |
| Erica Synths | LXR‑02 drum machine | Source code released |
| Polyend | Tracker grooveboxes | Open‑sourced |
| Behringer | Kick (MPC One clone) | Announced open‑source |
| Behringer | E‑mu SP‑1200 clone | Announced open‑source |
| Behringer | Anima DJ controller | Announced open‑source |
| Behringer | Ignite sequencer | Announced open‑source |
| Behringer | Polykeys 61 MIDI controller | Announced open‑source |

## 📅 Upcoming Events
- inMusic plans a major presence at **NAMM**, the annual music‑manufacturer convention in Anaheim.
- The company will host a **Creator Lab** where technically curious musicians can get hands‑on time hacking **22 new products** from across its brands, including Moog devices.
- O’Donnell noted that even analog‑centric Moog gear can be opened “if we open it up correctly,” which will involve “building a platform for devs to work around the analog parts of the circuit.”

## 🤝 Industry Context
- Other companies have also embraced the modding community: Erica Synths, Polyend and Behringer have released source code or announced open‑source devices.
- inMusic’s forums currently ban linking to hacks or modified firmware, warning that such changes could “brick” devices, prevent updates, or affect warranty coverage.
- Elektron, while expressing mixed feelings, does not actively block the community.
- O’Donnell explained, “you can try to wall them off, which is just a losing battle one … and so we want to embrace them.”
- The consensus among manufacturers is that “there’s no going back now that vibe coding has upended the music gear world, and trying to stand in the way would be a mistake.”
