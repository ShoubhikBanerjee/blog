# xAI launches Grok Bot: persistent AI agents for multi-step tasks

xAI recently launched Grok Bot, a system of always-on AI agents that run on dedicated cloud computers instead of a user’s laptop.

## 🔍 Overview
Grok Bot is not a chat window. Each Bot runs on its own persistent cloud computer with a real browser, file system, and terminal, plus its own logins to the tools it needs. You assign a role—email, LinkedIn outreach, research, scheduling—and the Bot keeps working after you close the app. Multiple Bots can coordinate on the same task, sharing files, browser sessions, and context through the same cloud infrastructure.

## 🧩 How it works
- Each Bot gets a dedicated cloud machine with a browser, file system, and terminal, plus tool logins.
- Bots continue running after you close the app or laptop lid because they run on cloud infrastructure.
- You can create 2–6 Bots in a group chat and @-mention new ones mid-conversation; they message each other, pass tasks, and share context without manual relay.
- A Bot operates its browser and terminal like a person: clicking, typing, navigating, and running commands in the same apps a human would use.
- Grok Bot connects to structured tools through connectors, plugins, and MCP servers, so it is not limited to xAI’s native integrations.
- You can record a browser workflow once in screen-recording mode; the Bot learns the sequence from the recording and can replay it later.

## ⚙️ Key details
- **Roles and tasks**: Assign a role and task the same way you would brief a new hire; the Bot uses its cloud machine to complete the work.
- **Hand-offs and coordination**: Multiple Bots can work together on the same task, sharing files, browser sessions, and context through the shared cloud infrastructure.
- **Approval gates**: Require explicit approval before a Bot sends a message, publishes content, deletes data, makes a purchase, or changes a production system.
- **Recurring routines**: Use a routines panel to schedule daily or weekly runs of a task so the Bot checks something without re-prompting.
- **Reusable skills**: A process that worked once can be saved as a reusable skill with steps, decision rules, output requirements, and approval boundaries.

## 🚀 Availability
- **Platforms**: Download the app for macOS, Windows, Linux, or iOS and complete the sign-in flow.
- **Account access**: Before creating a Bot, pick which accounts it can reach from a list including Google Workspace, Slack, Notion, Salesforce, Microsoft 365, LinkedIn, Zoom, GitHub, Jira, Figma, HubSpot, Canva, and more.
- **Templates**: Grok Bot suggests ready-made templates such as a feedback-clustering Bot, an overnight Bot that preps a morning digest, or an inbox-triage Bot.
- **Pricing**: Three paths are available—
  - Free trial (card required to start; not charged unless you subscribe),
  - Pro+ at $60/month,
  - Link an existing SuperGrok Heavy or SuperGrok Plus subscription (included at no extra charge once linked).

## 💡 Why it matters
Grok Bot shifts AI from chat-based assistants to persistent, multi-step agents that can operate continuously and coordinate across tools without constant supervision. Because each Bot runs on dedicated cloud infrastructure, it can handle long jobs, share context with teammates, and respect approval boundaries before taking sensitive actions.
