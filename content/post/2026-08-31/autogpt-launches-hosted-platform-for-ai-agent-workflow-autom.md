# AutoGPT Launches Hosted Platform for AI Agent Workflow Automation

AutoGPT has publicly launched its hosted platform, enabling users to build, deploy, and run AI agents that complete entire workflows. The platform is described as a vision for accessible AI for everyone, aiming to provide tools so users can focus on what matters.

## 🧩 How it works
AutoGPT allows you to describe an outcome in plain English or build step-by-step in a visual builder. The agent can then run on demand, on a schedule, or from a trigger.

## ⚙️ Key details
The platform includes several core components:
- **AutoPilot:** Describe a job in plain English to create a working agent.
- **Agents:** View every agent, its run history, cost, and actions needing attention.
- **Marketplace:** Start with proven agents, add them to your library, and customize.
- **Build:** A visual builder to drag, connect, branch, and inspect blocks for precise control.

Key technical specifications include:
- 45+ connected platforms and hundreds of AI models.
- No need for model API keys or infrastructure setup.
- The platform manages infrastructure, model access, credentials, reliability, and updates.

## 🚀 Availability
The hosted platform is a publicly available paid service with usage-based agent runs. A free path is available via self-hosting, where you provide the infrastructure.

## 💡 Why it matters
The project has garnered significant community interest, with over 185,000 GitHub stars. Several industry figures have commented on its potential. Andrej Karpathy, a founding member of OpenAI, noted that "AutoGPTs" represent a next frontier in prompt engineering. Amjad Masad, co-founder & CEO of Replit, stated that "If you have a phone you can run AutoGPT. You don't even need to learn how to code." Lior Alexander, CEO of AlphaSignal, suggested that "AutoGPT might be the next big step in AI."
