# n8n launches fair-code AI workflow automation platform

n8n has introduced a fair-code workflow automation platform with native AI capabilities, enabling users to build and deploy AI agents and workflows. The platform combines visual building with custom code, supports self-hosting or cloud deployment, and offers 1500+ integrations.

## 🔍 Overview
- Fair-code platform for building and deploying AI agents and workflows.
- Combines a visual canvas with custom code (JavaScript, Python, npm packages).
- AI automation designed for real-world use, from prototype to production.

## 🧩 How it works
- Design multi-step AI workflows with logic, tool use, human approvals, and full observability.
- Connect to OpenAI, Anthropic, Google, or open-source models and switch providers without changing architecture.
- Build and operationalize AI workflows and multi-step agents using your own data, models, and tools.

## ⚙️ Key details
- Self-hostable or deployable in the cloud with role-based access, audit trails, and support for sensitive data.
- 1500+ integrations and 9,000+ workflow templates to connect AI with existing systems.
- Source-available under the Sustainable Use License and n8n Enterprise License.
- Pronounced as "n-eight-n" (derived from "nodemation").

## 🚀 Availability
- Try n8n instantly with Docker using the install script:
  ```bash
  curl -fsSL https://get.n8n.io | sh
  docker volume create n8n_data
  docker run -it --rm --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n
  ```
- Access the editor at `http://localhost:5678`.
- Enterprise licenses available for additional features and support.
