# OpenCode launches open source AI coding agent with desktop app

OpenCode, an open source coding agent, has released a new AI-powered development tool alongside a desktop application.

## 🔍 Overview
OpenCode is an open source AI coding agent designed to assist developers with coding tasks. It is available as both a command-line tool and a desktop application.

## 🧩 How it works
OpenCode includes two built-in agents that can be toggled with the `Tab` key:
- **build** – A full-access agent for development work.
- **plan** – A read-only agent for analysis and code exploration, which denies file edits by default and requests permission before running bash commands.

Additionally, OpenCode features a general subagent for complex searches and multistep tasks, invoked using `@general` in messages.

## ⚙️ Key details
- Installation paths follow this priority order:
  1. `$OPENCODE_INSTALL_DIR` – Custom installation directory
  2. `$XDG_BIN_DIR` – XDG Base Directory Specification compliant path
  3. `$HOME/bin` – Standard user binary directory (if it exists or can be created)
  4. `$HOME/.opencode/bin` – Default fallback

- Remove versions older than 0.1.x before installing.

- Download options:
  - Directly from the [releases page](https://github.com/opencode-ai/opencode/releases)
  - Via the official website: [opencode.ai/download](https://opencode.ai/download)

## 🚀 Availability
- OpenCode is available as an open source project.
- Contributions are welcome; see the contributing docs for guidelines.
- Users are asked to clarify in their project READMEs if their project name includes "opencode" but is not affiliated with the OpenCode team.

## 💡 Why it matters
OpenCode provides developers with an accessible, open source tool for AI-assisted coding, offering both development and analysis agents to streamline workflows.
