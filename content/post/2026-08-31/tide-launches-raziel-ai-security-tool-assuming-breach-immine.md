# Tide Launches Raziel AI Security Tool Assuming Breach Imminence

Tide launched Raziel, an AI security tool designed under the assumption that hackers already exist within networks. This release addresses escalating risks from AI-generated code vulnerabilities and advanced attack models.

## 🔍 Overview
Tide's Raziel operates on the principle that **"hackers are inside"**, acknowledging systemic flaws in traditional security paradigms. Co-founder Michael Loewy asserts the industry was losing ground to attackers even before AI, noting: 
> *Before AI, a developer needed to be perfect all the time—perfectly patched, free of errors—while an attacker only needed one mistake to breach. It’s virtually impossible, which is why breaches are daily news.*
AI exacerbates this by enabling rapid production of error-prone code alongside sophisticated vulnerability exploitation.

## 🧩 How it works
Raziel implements **emergent authority**, where access permissions dynamically materialize only when identity, policy, context, and intent align—then dissolve. This replaces static credential storage with cryptographic fragmentation, ensuring no single point of failure exists. As Loewy states: 
> *The problem is authority always lives somewhere, and someone always has access. We distribute it architecturally so nothing is inheritable.*

## ⚙️ Key details
- **Raziel MCP Server**: Named after the archangel of secrets, it educates AI agents on Tide's authentication, threshold cryptography, and governance.
- **Blast Radius Mapping**: Identifies post-breach risks like impersonation opportunities and unauthorized access pathways.
- **Verified Playbooks**: Generates integration guides for self-hosted/managed deployments.
- **TideCloak Integration**: Handles authentication/authorization via Tide's Cybersecurity Fabric, keeping authority distributed.

## 🚀 Availability
Raziel launched Monday with open-source implementation via Tide's GitHub. Resources include:
- AI-generated white paper explaining emergent authority cryptography
- TideCloak quickstart for greenfield projects

## 💡 Why it matters
Traditional security centralizes secrets—creating irresistible targets. Raziel's model neutralizes this by making persistent authority impossible. Even with root access, attackers find nothing to inherit. As Loewy warns: 
> *AI agents now create software and perform privileged actions. We must assume breaches will happen and architect accordingly.*
