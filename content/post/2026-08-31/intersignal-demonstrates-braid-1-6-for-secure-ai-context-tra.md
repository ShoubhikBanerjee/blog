# Intersignal Demonstrates Braid 1.6 for Secure AI Context Transfer

Intersignal LLC announced a successful physical demonstration of Braid 1.6, a local-first system for moving authenticated situational context between independent AI models.

## 🔍 Overview
In a controlled "Kestrel" test, a local language model on a remote Linux node initially reached the wrong decision when asked about an invented operating protocol it had never seen. After receiving missing facts and rules via Braid's authenticated public relay, the same model later answered newly phrased questions correctly and explained its reasoning.

## 🧩 How it works
- Braid does not transfer model weights, hidden activations, native internal model state, or KV cache.
- It packages selected facts, rules, observations, constraints, or project state into a signed Semantic Capsule with provenance.
- The receiving node independently verifies, accepts, commits, and stores the state.
- After receiver-controlled commitment, the second node can reconstruct the context for later local reasoning.

## ⚙️ Key details
- The current Braid 1.6 release candidate supports user-supplied text and text files for technical users.
- Core Braid LAN software remains free.

## 🚀 Availability
- Braid Founding Membership is available at $99 per year, including:
  - Experimental Braid Managed Relay access for approved devices
  - Guided onboarding
  - Supported upgrades
  - Release guidance
  - Best-effort setup support
- The public Kestrel proof record and current software releases are available at https://intersignal.org.

## 💡 Why it matters
Potential applications include transferring project state between a laptop and workstation, coordinating specialized local models, and preserving useful context across offices, laboratories, or field locations.
