# CrewAI introduces open-source multi-agent framework and AMP Suite

CrewAI has launched an open-source Python framework for building production-ready multi-agent workflows, alongside the CrewAI AMP Suite for enterprise-grade deployment and management.

## 🔍 Overview
CrewAI is an open-source Python framework designed to enable autonomous agent collaboration through Crews and precise, event-driven control through Flows. It fosters collaborative intelligence, allowing agents to work together seamlessly on complex tasks.

## 🧩 How it works
- **Crews**: Optimize for autonomy and collaborative intelligence with role-based AI agents.
- **Flows**: Build event-driven automations combining precise workflow control, single LLM calls, and native support for Crews.
- **High-level abstractions and low-level APIs**: Provides flexibility for developers to build production-ready multi-agent systems.

## ⚙️ Key details
CrewAI offers:
- Role-based AI agents with defined goals, backstories, and tools.
- Structured task descriptions and dependencies for workflow automation.
- Community-driven learning with over 100,000 developers certified through courses at learn.crewai.com.

The CrewAI AMP Suite adds:
- Managed deployment, observability, governance, security, and enterprise support.
- **Crew Control Plane** with key features:
  - Tracing & Observability: Real-time monitoring of agents and workflows, including metrics, logs, and traces.
  - Unified Control Plane: Centralized platform for managing, monitoring, and scaling AI agents and workflows.
  - Seamless Integrations: Connectivity with existing enterprise systems, data sources, and cloud infrastructure.
  - Advanced Security: Robust security and compliance measures.
  - Actionable Insights: Real-time analytics and reporting.
  - 24/7 Support: Dedicated enterprise support.
  - On-premise and Cloud Deployment Options: Flexible deployment based on security and compliance requirements.

## 🚀 Availability
- The CrewAI framework is open-source and available for developers.
- The Crew Control Plane, part of the AMP Suite, is available for free trial.
- CrewAI AMP Suite is designed for enterprises seeking scalable, intelligent automation solutions.

## 💡 Why it matters
CrewAI is rapidly becoming the standard for production-ready agentic automation, offering both a flexible open-source framework and an enterprise-grade suite for managed deployment and control.
