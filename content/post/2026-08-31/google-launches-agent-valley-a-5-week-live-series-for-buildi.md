# Google launches Agent Valley, a 5‑week live series for building AI agents

Google announced a new learning resource called **Agent Valley** in the latest *What’s New in Google SecOps* update (August 24 – 31, 2026). The program is a 5‑week live series designed to teach anyone how to build production agent systems.

## 📚 Overview
- Agent Valley is a new resource that helps anyone, regardless of technical background, learn how to build AI agents through hands‑on experience.
- The series is live and runs for five weeks.

## 🗓️ Schedule & Format
- The program is presented as a 5‑week live series.
- A complementary 5‑day course is offered by Google DevRel Engineers.

## 👥 Who Can Attend
- The initiative is explicitly aimed at **anyone** who wants to learn agent building, even without prior technical expertise.

## 🛠️ What You’ll Build
- Participants will learn to build **production agent systems**.

## 🚀 Availability
- The announcement appears in the *What’s New in Google SecOps* release for the interval August 24th through August 31st, 2026, marking it as a **NEW** development.
