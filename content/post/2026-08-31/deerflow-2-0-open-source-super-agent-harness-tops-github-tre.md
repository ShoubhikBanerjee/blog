# DeerFlow 2.0 open-source super agent harness tops GitHub Trending

On February 28th, 2026, DeerFlow claimed the 🏆 #1 spot on GitHub Trending following the launch of version 2.

## 🔍 Overview
DeerFlow (Deep Exploration and Efficient Research Flow) is an open-source super agent harness that orchestrates sub-agents, memory, and sandboxes to perform long-horizon tasks such as research, coding, and creation.

## 🧩 How it works
DeerFlow handles different levels of tasks—spanning minutes to hours—using:
- Sandboxes for isolated execution
- Memory systems for state retention
- Tools and skills for specialized operations
- Subagents for modular task delegation
- A message gateway for inter-agent communication

A desktop tool accompanies DeerFlow to prototype agent ideas, inspect each harness step, replay failures, and benchmark performance.

## ⚙️ Key details
DeerFlow 2.0 is a ground-up rewrite with no shared code with v1.

**Supported models for running DeerFlow:**
- Doubao-Seed-2.0-Code
- DeepSeek v3.2
- Kimi 2.5

**New integrations:**
- BytePlus--InfoQuest intelligent search and crawling toolset (supports free online experience)

**Development status:**
- Active development has moved to 2.0
- Original Deep Research framework maintained on the `1.x` branch
- Contributions to `1.x` are still welcome
