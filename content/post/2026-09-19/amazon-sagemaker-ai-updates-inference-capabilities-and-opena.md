# Amazon SageMaker AI Updates Inference Capabilities and OpenAI Compatibility

Amazon SageMaker AI has introduced new capabilities for deploying and consuming AI models, offering users paths for managed infrastructure or Kubernetes-native control with Amazon SageMaker HyperPod Inference. In 2026, the platform delivered 13 new features to improve model deployment and optimization.

## 🔍 Overview
SageMaker AI now supports two primary deployment paths:
* Managed endpoints: AWS handles infrastructure, operations, GPU provisioning, scaling, and monitoring.
* Amazon SageMaker HyperPod Inference: Provides Kubernetes-native control for dedicated GPU clusters.

## 🧩 How it works
Inference recommendations automate the process of optimizing models based on performance goals such as cost, latency, or throughput. The system performs a three-step process:
* Narrow: Filters instance types by analyzing model architecture and requirements.
* Optimize: Applies techniques such as EAGLE 3.0 speculative decoding, kernel tuning, and tensor parallelism.
* Benchmark: Runs NVIDIA AIPerf on real GPU infrastructure with multi-run confidence reporting.

## ⚙️ Key details
SageMaker now exposes an /openai/v1 path supporting Chat Completions with streaming, allowing for migration by simply updating the endpoint URL. Other technical improvements include:
* Heterogeneous fleets: Customers can prioritize up to five instance types, with SageMaker automatically handling fallback and scaling based on capacity.
* Optimized configurations: Each pool entry can reference unique configurations like quantization or speculative decoding generated by inference recommendations.
* Metrics: Output includes validated metrics such as time to first token (TTFT), inter-token latency (ITL), and throughput.

## 🚀 Availability
These features are supported for single-model, inference component, and async endpoints in all commercial AWS Regions. There is no additional cost for generating recommendations, and customers with ML Reservations can benchmark on reserved capacity at no extra charge.

## 💡 Comparison of Inference Paths
| Feature | Managed SageMaker Inference | SageMaker HyperPod Inference |
| :--- | :--- | :--- |
| Infrastructure | Fully managed by AWS | Managed Kubernetes stack |
| Deploy target | Console, SDK, CLI | kubectl, Terraform, Console, CLI, SDK |
| Scaling | Managed auto scaling | Auto scaling with Karpenter, KEDA, CloudWatch |
| API protocol | OpenAI compatible | HTTP, gRPC and custom load balancer |
