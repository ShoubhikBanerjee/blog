# Open Source AI Application Development and Interview Guide for Backend Developers

An open-source guide and platform for AI application development and interview preparation for backend developers has been released, covering core technologies and engineering practices.

## 🔍 Overview

The project provides resources for AI application development, AI programming practice, and interview guidance. It includes an AI intelligent interview assistance platform and a RAG knowledge base.

## ⚙️ Key Details

### Technical Stack
The AI intelligent interview assistance platform and RAG knowledge base are built using:
* Spring Boot 4.0
* Java 21
* Spring AI 2.0

### Covered Technologies
The open-source content covers the following core technologies and engineering practices:
* LLM
* Agent
* RAG
* MCP
* Claude Code
* Codex
