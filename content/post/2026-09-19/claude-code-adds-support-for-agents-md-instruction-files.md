# Claude Code adds support for AGENTS.md instruction files

Claude Code has introduced support for AGENTS.md, a new method for providing project-specific instructions to the coding assistant. This functionality allows for greater customization of the tool's behavior.

## ⚙️ Key details

*   Starting in version 2.1.277, Claude Code will automatically check for an AGENTS.md file if no CLAUDE.md file is present in a folder.
*   This feature is built upon Claude Code mods, a new system for customizing the tool's harness.
*   While AGENTS.md is a built-in mod, users will be able to create their own custom versions of project instructions.
