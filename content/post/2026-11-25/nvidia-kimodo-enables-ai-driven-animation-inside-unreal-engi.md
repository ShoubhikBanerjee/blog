# NVIDIA Kimodo Enables AI‑Driven Animation Inside Unreal Engine 5.9 Preview

NVIDIA has introduced Kimodo, the first AI motion‑generation model integrated into Unreal Engine 5.9 Preview’s new guided animation framework.

## 🔍 Overview
Kimodo brings NVIDIA's animation research into Unreal Engine 5.9 Preview, allowing animators to generate character motion directly inside Sequencer.

## 🧩 How it Works
The guided animation framework lets creators combine three kinds of input:
- **Text prompt** – describe the desired motion in natural language.
- **Spline path** – draw a path the character should follow.
- **Target poses** – set explicit poses at specific frames.
Kimodo processes these constraints and outputs motion that respects all of them, giving teams creative control over where characters move and how they pose at key moments.

## ⚙️ Key Details
| Feature | Description |
|---|---|
| Text prompt | Describe motion with natural language |
| Spline path | Draw a path for the character to follow |
| Target poses | Define specific poses at chosen frames |
| Constraint‑aware generation | Motion follows the combined constraints |

## 🚀 Availability
Kimodo is available as the first model in Unreal Engine 5.9 Preview’s guided animation framework and can be used inside the Sequencer tools.
