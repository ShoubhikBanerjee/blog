# AWS Achieves NATO Restricted and Difusión Limitada Accreditation in Spain

Amazon Web Services (AWS) has achieved Spain’s national Limited Distribution (“Difusión Limitada”) and NATO Restricted accreditation for the AWS Europe (Spain) Region, marking a significant milestone in cloud security compliance for sensitive government workloads.
