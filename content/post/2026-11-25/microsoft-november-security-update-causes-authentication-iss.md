# Microsoft November Security Update Causes Authentication Issues Due to NTLM Message-Signing Changes

Microsoft has confirmed that customers may experience authentication issues after installing November security updates that address a high-severity remote code execution vulnerability. Tracked as CVE-2026-118737, this security flaw was found in the Windows Remote Procedure Call Runtime and stems from a timing-dependent authentication weakness that unauthenticated attackers can exploit to remotely execute code without user interaction on unpatched systems.
