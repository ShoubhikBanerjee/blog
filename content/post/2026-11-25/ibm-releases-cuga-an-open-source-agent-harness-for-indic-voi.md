# IBM releases CUGA, an open-source agent harness for Indic voice

IBM Research has released CUGA (ConfigUrable Generalist Agent), an open-source agent harness designed as a text-in, text-out brain. The system is built to handle Indic languages, addressing the challenge that default English-only embedding models turn Hindi or Tamil input into vectors that carry almost no meaning, resulting in incorrect retrieval.
