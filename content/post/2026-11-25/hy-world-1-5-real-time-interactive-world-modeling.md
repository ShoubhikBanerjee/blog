# HY-World 1.5: Real-Time Interactive World Modeling

We are excited to announce the release of HY-World 1.5 (WorldPlay), the first open-source, real-time interactive, and long-term geometrically consistent world model. This breakthrough bridges the gap between immersive 3D world generation and real-time interaction, resolving the trade-off between speed and memory that limits current methods.

## 🔍 Overview
- HY-World 1.5 is a state-of-the-art 3D world model.
- It enables real-time, interactive world modeling with long-term geometric consistency.
- The model is based on a streaming video diffusion model, WorldPlay.

## 🧩 How it works
- HY-World 1.5 draws power from four key designs.
- It uses a Dual Action Representation to enable robust interaction.

## ⚙️ Key details
- HY-World 1.5 resolves the trade-off between speed and memory.
- It is the first open-source, real-time interactive, and long-term geometrically consistent world model.

## 🚀 Availability
- We release the training code for WorldPlay-8B model, enabling the community to train and fine-tune their own world models.
- We release the RL post-training code WorldCompass for WorldPlay-8B model.
- We open-source WorldPlay-5B model, a new lightweight model that fits into small-VRAM GPUs.
- We update the inference code with quantization and engineering optimization for even faster inference speeds.
- We present the technical report and research paper of HY-World 1.5 (WorldPlay).

## 💡 Why it matters
- HY-World 1.5 bridges the gap between immersive 3D world generation and real-time interaction.
- It resolves the trade-off between speed and memory that limits current methods.
- It enables robust interaction with the generated 3D worlds.
