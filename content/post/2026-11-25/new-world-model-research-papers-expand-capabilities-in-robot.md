# New World Model Research Papers Expand Capabilities in Robotics and Autonomous Systems

Researchers have released multiple new papers advancing world models for robotics, autonomous driving, and video generation. These developments focus on creating more robust and versatile models that can handle complex real-world scenarios through semantic understanding, temporal reasoning, and closed-loop simulation capabilities.

## 📚 New Papers Introduced

Multiple research groups have published papers on advanced world models across different applications:

- ST-WAM: Semantic-Temporal World Action Model for Robust Manipulation under Visual Distribution Shifts
- NVIDIA OmniDreams: Real-Time Generative World Model for Closed-Loop Autonomous Vehicle Simulation
- Cosmos 3: Omnimodal World Models for Physical AI
- X Square Robot WALL-WM: Carving World Action Modeling at the Event Joints
- GE-Sim 2.0: A Roadmap Towards Comprehensive Closed-loop Video World Simulators for Robotic Manipulation
- Xiaomi EV World Model: A Joint World Model Integrating Reconstruction and Generation for Autonomous Driving
- Coowa: The DAWN of World-Action Interactive Models
- Being-H0.7: A Latent World-Action Model from Egocentric Videos
- MotuBrain: An Advanced World Action Model for Robot Control
- Cortex 2.0: Grounding World Models in Real-World Industrial Deployment
- HY-World 2.0: A Multi-Modal World Model for Reconstructing, Generating, and Simulating 3D World
- Helios: Real Real-Time Long Video Generation Model
- Seedance 2.0: Advancing Video Generation for World Complexity
- Matrix-Game 3.0: Real-Time and Streaming Interactive World Model with Long-Horizon Memory
- HY-Embodied-0.5: Embodied Foundation Models for Real-World Agents
- OpenWorldLib: A Unified Codebase and Definition of Advanced World Models
- ABot-PhysWorld: Interactive World Foundation Model for Robotic Manipulation with Physics Alignment
- GigaWorld-Policy: An Efficient Action-Centered World--Action Model
- GigaBrain-0.5M*: a VLA That Learns From World Model-Based Reinforcement Learning
