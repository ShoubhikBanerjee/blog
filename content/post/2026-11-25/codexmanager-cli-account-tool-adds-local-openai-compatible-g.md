# CodexManager CLI Account Tool Adds Local OpenAI-Compatible Gateway

A new utility called **CodexManager** provides account pool management for the Codex CLI and a local gateway that mimics OpenAI's API.

## 🔧 Overview
- Manages Codex CLI account pools.
- Offers a desktop application and a browser‑based Service edition.
- Acts as a local OpenAI‑compatible gateway for Codex CLI.

## 🛠️ Features
- Supports Chinese, English, Russian, and Korean languages.
- New installations default to **Auto‑detect** based on the desktop WebView or browser language.
- Users can set a fixed language in the header or Settings; the choice is saved.
- Unsupported or unavailable language information falls back to **English**.
- Built under the author's direction using AI: Codex (98%) and Gemini (2%).
- Only the Windows desktop build is guaranteed; other platforms require thorough testing before reporting issues.
