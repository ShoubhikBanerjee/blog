# Skales Releases Scout as Personal AI Agent Harness Leaves Beta

Skales has updated its personal AI agent harness, officially bringing Skales Scout out of beta. The application installs locally to execute multi-step tasks directly on a user's computer across desktop and mobile platforms.

## 🔍 Overview
- **Platform Support**: Available for macOS, Windows, Linux, Android, and iOS.
- **Installation & Local Privacy**: Features a one-click install that runs like a standard application without requiring Docker or a terminal. User files remain stored on their local machine.
- **Target Audience**: Built to be accessible for non-developers and users from ages 6 to 60+.
- **Model Support**: Offers Skales IQ as a free built-in trial needing no API key. Users can also run fully offline with local LLMs via Ollama, or bring their own keys (BYOK) across 15+ to 26 providers, including endpoints supporting Chat Completions, Anthropic Messages, or OpenAI Responses.

## 🧩 Scout and Agent Capabilities
- **Skales Scout**: Lasting AI agents operating with their own thread, memory, and rhythm, each optionally housed in its own virtual machine. Scout features a three-card setup, a control setting for execution freedom, a calm thread with a Log, password-sealed API key backups, and a lighter mobile app.
- **Multi-Step Goals**: Commands like `/goal build me a trading bot` run background tasks across multiple steps and resume where left off. Agents maintain rounds, offer suggestions, and ask before taking risky actions.
- **Skales Code**: Using `/code` binds a selected folder to a chat, enabling inline diffs and one-click undo.
- **Core Capabilities**: Covers chat, coding, Flow, automations, computer use, browser, voice, Model Context Protocol (MCP), and local file, calendar, and email access.
- **Integrations & Cross-Device**: Functions as an Office task pane and a Chrome side panel (configured via Settings → Extensions), and communicates via WhatsApp and Telegram. Mobile devices can pair via QR code to drive the desktop's tool set or operate standalone.

## ⚙️ Interface and Migration Settings

| Feature | Description |
| --- | --- |
| Migration Importer | Built-in importer located at Settings > Import from Another Tool for migrating from OpenClaw, Hermes Agent, or ChatGPT |
| Visual Customization | Offers three themes (Skales X, Classic, Flat), light and dark modes, accent gradients, and background choices (Circles, Honeycomb, Waves, Dots, Contours, Plain, Desert Day/Night, or custom images with dim, blur, and overlay tint) |
| Dashboard & Controls | Allows a quieter dashboard or displaying all widgets at once, plus an effort dial for models that think longer |
| Sentence Completion | Text composer offers sentence completions as you type, which are accepted by pressing Tab |
