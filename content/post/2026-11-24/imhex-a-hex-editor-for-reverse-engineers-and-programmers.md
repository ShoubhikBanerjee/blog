# ImHex: A Hex Editor for Reverse Engineers and Programmers

ImHex is a powerful hex editor designed for reverse engineers, programmers, and anyone who values their retinas when working at 3 AM. It offers a range of features to enhance the user experience and productivity.

- Byte patching
- Patch management
- Infinite Undo/Redo
- Copy bytes as...
- Simple string and hex search
- Goto from start, end and current cursor position
- Colorful highlighting
