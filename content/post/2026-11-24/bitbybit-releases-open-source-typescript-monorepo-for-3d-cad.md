# Bitbybit Releases Open-Source TypeScript Monorepo for 3D CAD Algorithms with AI Integration

Bitbybit has released a new open-source monorepo that provides TypeScript implementations of 3D CAD algorithms for browser-based geometry programming. The repository contains all Bitbybit NPM packages along with example applications under MIT license, enabling developers to work with 3D algorithms using popular frameworks like ThreeJS, BabylonJS, and PlayCanvas. The monorepo supports both direct algorithm execution in NodeJS and custom core integrations, making it a versatile foundation for 3D geometry development. The project includes three CAD kernels (OCCT, JSCAD, Manifold) and offers a CLI that generates Vite + TypeScript projects pre-configured with these kernels, allowing developers to choose between different game engines and backend templates while keeping API keys secure on the server side.
