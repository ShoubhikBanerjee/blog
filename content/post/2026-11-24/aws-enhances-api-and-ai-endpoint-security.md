# AWS Enhances API and AI Endpoint Security

AWS has launched new capabilities to discover and protect APIs and AI endpoints, addressing the evolving landscape of digital business and AI agent interactions.

## 🔍 Overview
- AWS has introduced new features to help discover and protect APIs and AI endpoints.
- This includes API Portal in Amazon API Gateway, API Security, and AI Security managed rule groups in AWS WAF.

## 🧩 How it works
- API Portal discovers APIs and AI endpoints from configuration and live traffic.
- API Security protects against broken object level authorization, authentication attacks, and reconnaissance.
- AI Security identifies AI traffic, validates requests, and checks prompts and responses through Amazon Bedrock Guardrails.

## ⚙️ Key details
- API Portal is available in the Amazon API Gateway console.
- API Security and AI Security are available in the AWS WAF console.
- The new features work with Amazon CloudFront, Amazon API Gateway REST APIs, and Application Load Balancer.

## 🚀 Availability
- API Portal, API Security, and AI Security are generally available today.

## 💡 Why it matters
- APIs have run digital businesses for over a decade.
- In 2026, AI endpoints joined them, leading to a need for new security measures.
- AI agents now act on behalf of users, requiring robust protection of APIs and AI endpoints.
