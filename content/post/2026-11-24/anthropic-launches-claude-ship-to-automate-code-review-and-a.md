# Anthropic launches Claude Ship to automate code review and approvals

Anthropic has launched Claude Ship, a new product that enables AI to review, fix, and approve pull requests to help software engineers ship code.

## 🧩 How it works
Claude Ship introduces two new agents, PR Steward and Claude Approvals, which are launching in beta. These agents build upon the previously released Code Review feature, which was announced in March and became generally available in October.

* **PR Steward**: Jumps in on failing CI checks, merge conflicts, and review feedback from Code Review, other review tools, or team members, and leaves comments on what it changed.
* **Claude Approvals**: Can approve routine changes if an organization’s policy allows it.

Teams can have Claude Approvals consider a variety of signals in its decision-making process, including Code Review findings or their own classifiers using natural language.

## ⚙️ Key details
| Feature | Function |
| :--- | :--- |
| PR Steward | Addresses failing CI checks, merge conflicts, and review feedback |
| Claude Approvals | Approves routine changes based on organizational policy |
| Decision Inputs | Considers Code Review findings or custom classifiers using natural language |

## 🚀 Availability
Claude Ship is now available for Claude Team and Enterprise customers and works with repositories on GitHub.
