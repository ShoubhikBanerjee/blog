# Datasette Agent Gains Charting Integration

Datasette Agent has gained integration with a new charting plugin for Datasette. This allows users to request charts through chat, with the agent generating them using the same underlying chart suggestion and generation tools.

## 🧩 How it works

*   Users can ask the chat interface to create a chart.
*   The system utilizes the same underlying chart suggestion and generation tools used by the standalone plugin.
*   This integration was part of the `datasette-charts 0.2a0` release.

## ⚙️ Key details

*   A related improvement to Datasette Agent allows chat sessions to open an iframe side panel.
*   This panel can navigate to different pages.
*   The version improves navigation by fragment hashes.
*   This feature enables deeper integration with other Datasette plugins that update fragment hashes when users interact with the plugin in ways that change state.

## 🚀 Availability

*   A demo video is available showing the integration on `agent.datasette.io`.
*   Users can sign in with GitHub to try the plugin themselves.
*   A Markdown export of the chat from the demo video is provided.
