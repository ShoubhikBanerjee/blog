# Researchers Develop COMPACTIONBENCH and APEC to Reduce AI Coding Costs

A new study reveals that while fewer than 8% of coding sessions require context compaction, these sessions account for 44% of total AI processing costs. To address this, researchers have introduced tools to optimize long-running coding tasks.

## 🧩 How it works

Researchers developed two primary solutions to manage context compaction more efficiently:

* COMPACTIONBENCH: A benchmark designed to evaluate context compaction during long-running coding tasks.
* APEC: A method that prepares summaries in the background, preventing the interruption of an agent’s work.

## ⚙️ Key details

Evaluations of the APEC method demonstrate measurable improvements in efficiency for coding agents:

| Metric | Improvement |
| :--- | :--- |
| Coding Performance | Improved |
| Costs | Reduced by up to 25.4% |
| Execution Time | Reduced by 9.6% |
