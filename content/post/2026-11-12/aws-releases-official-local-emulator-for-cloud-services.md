# AWS releases official local emulator for cloud services

On 11 November 2026 AWS released an official emulator that lets developers run a local clone of many AWS services without needing a paid API key.

## 🔍 Overview
- Official emulator from AWS.
- Provides a local clone of many different services.
- Eliminates the need for a paid API key during testing.

## 🧩 How it works
- Implemented in Rust.
- Distributed as a Docker image; currently requires Docker on macOS or Windows.
- Runs services locally, enabling tests against the emulator.

## ⚙️ Key details
- 29,684 commits in the first three weeks of the project.
- Developed by a huge swarm of agents.
- Swaminathan (Swami) Sivasubramanian described its origin in a guest post on Werner Vogels' blog.

## 🚀 Availability
- Announced 11 November 2026 (Link Blog).
- Requires Docker; a single‑binary distribution is hoped for in the future.

## 💡 Why it matters
- Allows testing without provisioning paid AWS resources.
- Can speed development cycles and reduce costs.
