# Tag‑cloud browsing added to tools.simonwillison.net for vibe‑coded tools

The tools.simonwillison.net site now lets users browse its growing collection of vibe‑coded tools using tag clouds.

## 🔍 Overview
- The author has been looking for a better way to explore a collection of **244 and counting** vibe‑coded tools.
- The site now supports browsing by tag.

## 🧩 How it works
- A few **Fable 5.2** credits were used before the weekly reset.
- **tree‑sitter** was run on each tool’s code to extract:
  - JavaScript APIs
  - Libraries
  - Web API hosts
- The extracted terms form the basis of the tag clouds.

## ⚙️ Key details
- The homepage now displays **tag clouds** for browsing by each of the three tag categories (APIs, libraries, hosts).
