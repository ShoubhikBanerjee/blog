# AWS re:Invent 2024 features extensive AI and machine learning learning sessions

From November 30th to December 4th, Amazon Web Services (AWS) will host its annual learning event, re:Invent. The conference provides attendees with over 2,000 learning sessions, including an AI/ML track featuring more than 140 unique sessions to assist developers in navigating AWS cloud services.

## 🔍 Overview of AWS AI Portfolio
AWS provides a comprehensive AI portfolio designed to support workloads ranging from infrastructure to agentic solutions. The stack consists of the following layers:

* Global Infrastructure: Data centers optimized for the power, cooling, and networking demands of AI training and inference.
* AI Chips: Compute options including AWS Trainium for AI training/inference and NVIDIA GPUs.
* AWS Context: Connects data across storage, databases, analytics, and search services.
* Model Management: Managed access to models via Amazon Bedrock and custom model deployment through Amazon SageMaker AI.
* Agent Development: Tools for building and deploying AI agents.

## ⚙️ Learning Session Types
Attendees can participate in various session formats to maximize their learning:

| Session Type | Description |
| :--- | :--- |
| Breakout | 60-minute informative lecture by experts, customers, and partners. |
| Chalk talk | Interactive session with Q&A and whiteboard usage. |
| Builder session | One-hour session focused on building a specific project. |
| Workshop | Two-hour team-based session solving real problems using AWS services. |
| Code talk | Expert-led live coding session. |

## 🧩 Agent Development Capabilities
Amazon Bedrock AgentCore serves as the environment for building, deploying, and managing AI agents. It supports a mix of models and providers, including those from Amazon Bedrock and SageMaker AI, allowing teams to design agents without being locked into a single provider. Additionally, ready-to-use agentic solutions like AWS Quick connect applications, tools, and data into a personal knowledge graph.
