# Corey Haines Releases Library of AI Agent Skills for Marketing Tasks

Corey Haines has released a collection of AI agent skills designed to support technical marketers and founders with conversion optimization, copywriting, SEO, analytics, and growth engineering.

## 🧩 How it works

Skills are markdown files that provide AI agents with specialized knowledge and frameworks. When added to a project, these skills allow an agent to recognize marketing tasks and apply best practices. The skills are designed to reference each other, with the product-marketing skill serving as the foundation for product, audience, and positioning context.

## ⚙️ Key details

*   **Compatibility:** Works with Claude Code, OpenAI Codex, Cursor, Windsurf, and any agent supporting the Agent Skills spec.
*   **Integration:** Supports CLI and MCP (Model Context Protocol) for connectivity.
*   **Licensing:** The library is free and MIT-licensed.
*   **Contribution:** The project welcomes contributions via pull requests and issue reporting.
*   **Partnerships:** Verified partners fund the work through disclosed tool integrations, which are listed alongside neutral options without influencing skill recommendations.

## 🚀 Availability

*   **Deployment:** The library is available for developers and marketers to integrate into their existing AI agent workflows.
*   **Support Resources:** Companion materials include the "Coding for Marketers" guide, "Swipe Files" for marketing learning, and "AI Marketing Training."
*   **Services:** Further hands-on support is provided through the Conversion Factory agency, while the Magister project is available for those seeking an autonomous AI CMO agent.
