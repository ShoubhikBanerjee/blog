# AWS Frontier AI Engineering & Services Releases 23 Production-Ready Generative AI Assets

The AWS Generative AI Innovation Center, now part of AWS Frontier AI Engineering & Services, has released a curated catalog of 23 production-ready assets. These reusable building blocks are designed to reduce development time from months to weeks, incorporating feedback from real-world deployments at companies such as DoorDash, Lyft, and Ricoh.

## 🔍 Overview
Since 2023, the AWS Generative AI Innovation Center has published open-source reusable assets. These production-grade, composable building blocks implement discrete generative AI capabilities and are validated for quality and security before publication. Each asset includes deployment guides and instrumentation to track adoption across customer engagements.

## 🧩 How it works
The assets are tested in production environments and reviewed for security compliance. A primary example is the Contact Center GenAI Agent, which employs a Retrieval-Augmented Generation (RAG) architecture to maintain context during multi-turn conversations. This specific asset integrates with Amazon Connect and utilizes Amazon Bedrock Knowledge Bases for hybrid search and metadata filtering.

## ⚙️ Key details
The catalog includes various components designed to address common development challenges:

| Asset Category | Examples |
| :--- | :--- |
| Core Architecture | RAG pipeline components, document ingestion modules |
| Agent Frameworks | Agent scaffolding templates |
| Management Tools | Prompt management patterns, evaluation frameworks |
| Specialized Agents | Contact Center GenAI Agent |
| Document Processing | Accelerated Intelligent Document Processing on AWS |

## 💡 Why it matters
Customer implementations have demonstrated measurable improvements in deployment speed and operational efficiency:

*   **DoorDash:** Reached live testing readiness in 2 months for a voice-operated contact center solution. The system handles over 100,000 calls per day with 2.5-second response latency and a 50x increase in testing capacity.
*   **Ricoh:** Using the document processing asset, the company reduced engineering hours per deployment by over 90 percent (from 80 hours to under 5). Document throughput increased 7-fold, from 10,000 to 70,000 documents monthly.
*   **Lyft:** Utilized the Contact Center GenAI Agent to implement agentic AI for both riders and drivers across text and voice channels.
*   **General Performance:** Assets have contributed to 90 percent reductions in engineering hours and compressed deployment timelines across various customer solutions.
