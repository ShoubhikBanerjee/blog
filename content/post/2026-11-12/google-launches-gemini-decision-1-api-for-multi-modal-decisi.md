# Google Launches Gemini Decision 1 API for Multi-Modal Decision Models

Google released the "Gemini Decision 1" API on November 11, 2026, entering the decision model category alongside Jev and OpenAI. The new model supports the same three types of questions as its competitors—yes/no, choice, and rubric-scoring—and even reuses the term "Noul" for yes/no questions.

## 🧩 Overview

| Model | Capabilities |
| :--- | :--- |
| **Jev** | Text, JSON |
| **OpenAI** | Text, Images |
| **Gemini Decision 1** | Text, Images, Audio, Video, PDFs |

## 💰 Pricing

*   **Gemini Decision 1:** 10 cents per million input tokens; output is free.
*   **GPT-6 Luna:** 10 cents per million input tokens; output is free.
*   **Jev:** 4.2 cents per million (the cheapest of the three).

## 🧪 Testing

The model was tested against a Yonkers stomping robot video file. The following questions were passed to it:

*   dragon: Does this video have a dragon in it?
*   robot: Does this video have a robot in it?
*   france: Is this video set in France?
*   usa: Is this video set in the USA?

Jev and OpenAI both return 1.0 or 0.0 for yes/no questions. In contrast, Gemini Decision 1 returns probabilities, such as 0.04976021841520312 for "dragon" and 0.9234055387792485 for "robot".
