# New Repository Offers UiPath Integration SDKs and UI Widgets

A new repository of skills for interfacing UiPath capabilities to external developers is now available. The repository includes a collection of reusable React UI widgets designed for building UiPath-powered applications. These widgets are built with uipath-typescript and apollo-wind, providing a ready-made front‑end component set for developers.

In addition to the UI widgets, the repository provides a Python SDK that enables developers to build and deploy LangGraph agents to the UiPath Cloud Platform. A comprehensive Typescript SDK is also included, offering methods for interacting with UiPath's Automation Platform. Together, these tools give developers multiple language options and pre‑built components for creating and managing UiPath automation workflows.

These resources are intended to streamline the development process for anyone looking to integrate UiPath capabilities into their applications, whether they prefer front‑end development with React, automation scripting with Python, or platform interaction via Typescript.
