# Nvidia Introduces Integrated System for End-to-End Agentic Workloads

Nvidia announced that it is moving beyond pure GPU performance to market complete systems aimed at running agentic workloads from start to finish. The new offering combines the company's Rubin graphics processors with a Vera central processing unit and additional supporting units. By tightly coupling the GPU and CPU, Nvidia says the design reduces the need for data to travel between separate components, which it expects will lower latency and speed the orchestration of multi‑step AI agents. The system is positioned as a solution for developers who need to run complex, multi‑phase agent pipelines without the overhead of moving data across a traditional compute stack. Nvidia’s description emphasizes that the integrated architecture targets end‑to‑end execution, allowing agents to operate more efficiently than when built on loosely connected GPU and CPU resources. The supporting units include memory and interconnect technologies that further streamline the flow of information between the Rubin GPUs and the Vera CPU, creating a more cohesive pipeline for AI agents that require rapid context switching and coordinated processing. Nvidia positions the bundle as an alternative to assembling separate GPUs, CPUs and networking components, which can introduce bottlenecks in high‑frequency agent communication. The integration is intended to reduce data movement and speed orchestration for multi‑step agents.
