# Google Introduces Agentic Video Understanding Across Gemini Models

Google has launched agentic video understanding for its latest models, including Gemini 3.7 Flash, 3.6 Flash, and 3.5 Flash-Lite. This capability improves analysis accuracy while reducing token consumption and costs.

## 🔍 Overview
Agentic video understanding enhances how Gemini models process video content. By enabling this feature, users can achieve higher accuracy and efficiency for both video uploads and YouTube videos.

## ⚙️ Key Details
Across standard benchmarks, this feature provides the following improvements:
* Up to 66% reduction in analysis costs.
* Up to 88% reduction in token consumption.
* Up to 7% improvement in accuracy.

Gemini 3.7 Flash offers the best quality and efficiency combination, reaching the accuracy-to-cost pareto frontier. This feature uses standard Gemini API token pricing with no additional fee.

## 🧩 Capabilities
| Capability | Function |
| :--- | :--- |
| Sub-second moment retrieval | Identifies split-second state changes and cut boundaries |
| Long-form search | Answers complex queries across multi-hour videos |
| Anomaly detection | Resamples time windows at higher FPS for visual inspection |
| Action & object counting | Tracks repeated movements and objects over time |

## 🚀 Availability
* Currently available via the Gemini API in Google AI Studio and the Gemini Enterprise Agent Platform.
* To enable, set processing to "agentic" in the API configuration.
* The feature will roll out to all users in the Gemini app for Flash and Flash-Lite models soon.
* In the coming months, it will power the ‘Ask YouTube’ feature on YouTube’s video watch page.
