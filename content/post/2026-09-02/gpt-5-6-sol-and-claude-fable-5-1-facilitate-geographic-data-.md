# GPT-5.6-Sol and Claude Fable 5.1 facilitate geographic data mapping

On 1st September 2026, developers leveraged multiple AI tools to create a utility for mapping local political boundaries, including the Granada Community Services District and the Midcoast Community Council.

## ⚙️ Key details

* GPT-5.6-Sol: Proactively built a tool for displaying GeoJSON files on a map and exporting them as PNGs after being asked for tool suggestions.
* Claude Fable 5.1: Utilized for iterations on the tool and created an animated pelican.
* ChatGPT Work: Capable of extracting and combining files from various Government data sources to provide boundary data for specific requests.
* Claude Code: Employed for web development iterations.

## 🧩 How it works

| Tool | Function |
| :--- | :--- |
| GPT-5.6-Sol | Proactively generated a GeoJSON-to-PNG mapping tool |
| ChatGPT Work | Extracts and combines government boundary files |
| Claude Fable 5.1 | Assists in tool development and animation creation |
| Claude Code | Facilitates web development iterations |
