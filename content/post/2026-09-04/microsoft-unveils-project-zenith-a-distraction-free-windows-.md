# Microsoft unveils Project Zenith: a distraction‑free Windows for developers

Microsoft has named its developer‑optimized Windows experience **Project Zenith**, positioning it as a distraction‑free Windows environment built specifically for developers.

## 🔍 Overview
- Project Zenith is described as a “distraction‑free Windows experience” for developers.
- It follows a developer‑focused Windows effort announced earlier at Build, but now targets devices with **64 GB or more of unified memory**.
- Microsoft frames the effort as the developer‑side of its broader mission to improve Windows 11.

## 🛠️ Core Features
- Pre‑configured Windows setup for development with a curated toolset.
- Included developer tools: **Visual Studio Code, GitHub Copilot, PowerToys, WinAppCLI, Windows Dev Skills**.
- File Explorer is configured to show file extensions, hidden files, and the full path in the title bar.
- Recently used files/folders and sync‑provider tips are disabled.
- Long‑path support is enabled.
- Start‑menu tips and account notifications are turned off.
- PowerToys Command Palette is enabled by default.

## 🤖 AI‑ready Capabilities
- Devices can run **30 B+‑parameter models locally and unmetered**, allowing developers to experiment without relying on cloud tokens.

## 📦 Devices & Hardware
- The first Project Zenith devices ship with **AMD’s Ryzen AI Halo chips**.
- AMD announced a miniature PC powered by Ryzen AI Halo chips on stage at IFA.
- Additional Project Zenith devices are slated for release in the coming months, including variants with **different silicon**.

## 🚀 Availability
- The initial devices are already shipping.
- Microsoft says more devices will arrive in the coming months.

## 💡 Why It Matters
- The OS tweaks remove many of the “annoying distractions” typical in a default Windows 11 install, aligning the platform more closely with developer workflows.
- By enabling local execution of large AI models, Project Zenith aims to reduce dependence on metered cloud resources.
- Microsoft emphasizes that the offering is the result of listening to developers and that it will continue evolving alongside the development community.
