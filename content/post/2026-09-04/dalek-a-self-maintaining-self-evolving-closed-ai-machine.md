# Dalek: A Self‑Maintaining, Self‑Evolving Closed AI Machine

Dalek is a newly introduced closed machine for agents that can self‑maintain, self‑evolve, self‑reproduce, and self‑organize on any substrate that satisfies a general host contract.

## 🔍 Overview
- Realizes **self‑maintenance**, **self‑evolution**, **self‑reproduction**, and **self‑organization**.
- Operates on any substrate that meets a **general host contract**.

## 🧩 How it works
- Built from three primitives: **actors**, **messages**, and **channels**.
- Governed by four obligations that give the machine structural boundary, identity, and closure:
  - **Host boundary**
  - **Construction language**
  - **Admissible transitions**
  - **Rule heredity**
- Incorporates von Neumann’s 1948 self‑reproducing automaton as a hereditary construction core, providing a **self‑description**, a **constructor**, a **copier**, and a **controller**.
- Combines the hereditary core with the four obligations and rederives its medium for a text‑and‑message agent substrate, adding explicit structures for boundary, identity, history, and growth.

## ⚙️ Key details
| Component | Role |
|-----------|------|
| Actors, Messages, Channels | Primitives that compose the machine |
| Host Boundary | Defines the machine’s external limit |
| Construction Language | Supplies the syntax for building the machine |
| Admissible Transitions | Restricts permissible state changes |
| Rule Heredity | Preserves identity and closure across generations |
| Self‑description, Constructor, Copier, Controller | Hereditary construction core from von Neumann |

## 🚀 Capabilities
- A **large language model** and a **compiler** occupy the payload position, forming a **general capability producer**.
- New capabilities are **authored**, **compiled**, **installed** into the machine’s description, and **inherited by descendants**.
- The same process creates the machine’s own organs and even its runtime, thereby **closing heredity and evolution within the machine**.

## 💡 Why it matters
- By embedding both the construction core and the evolution mechanisms inside the machine, Dalet demonstrates a self‑contained path for agents to extend, reproduce, and maintain themselves without external intervention.
