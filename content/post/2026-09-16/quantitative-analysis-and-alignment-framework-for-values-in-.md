# Quantitative Analysis and Alignment Framework for Values in Large Language Models

A new study titled "Do LLMs Have Values? A Quantitative Analysis and Alignment Framework for Values in Large Language Models" explores the existence of intrinsic value systems in LLMs and proposes a method for more precise alignment.

## 🔍 Overview
Researchers addressed a behavioral paradox where LLMs exhibit both "swing" (unpredictable fluctuations based on minor wording changes) and "rigidity" (ignoring instructions to correct biases). The study sought to answer three questions:
* Do LLMs possess an intrinsic value system?
* How can these values be quantified?
* How can LLMs' values be aligned toward a desired target?

## 🧩 How it works
To analyze value systems, the researchers projected responses from 106 LLMs (150,000 queries per model) and 95,000 human survey profiles into a shared sociological space. The results confirmed that LLMs possess an intrinsic value system, though it crystallizes into a concentrated, idealized value core rather than mirroring human diversity.

## ⚙️ Key details
The study introduces the Prior-Environment-Cognition (PEC) framework to mathematically define value expression as the joint outcome of three factors:

| Component | Definition |
| :--- | :--- |
| Prior | Inherent dispositions such as parameter weights |
| Environment | External contexts such as user prompts |
| Cognition | Internal reasoning processes like Chain-of-Thought |

## 💡 Why it matters
Using PEC diagnostics, the researchers developed an "Alignment Prescription" to steer LLM values. This approach identifies the minimum effective intervention required for each dimension, which may range from zero-cost prompts to targeted parameter updates. Empirical validation indicates this method is more efficient and precise than conventional blind training and does not degrade general capabilities.
