# Firecrawl Launches Web Context API for AI Agents and Data Extraction

Firecrawl has released a web context API designed to search, scrape, and interact with the web at scale to provide LLM-ready data for AI agents and dynamic applications.

## 🔍 Overview
Firecrawl allows users to find sources, extract content, and convert web data into formats such as clean Markdown or structured data. The service covers 96% of the web, including JS-heavy pages, and supports the extraction of content from web-hosted PDFs and DOCX files.

## ⚙️ Key Details

| Feature | Capability |
| :--- | :--- |
| Output Formats | Markdown, structured JSON, HTML, and screenshots |
| Performance | P95 latency of 3.4s across millions of pages |
| Web Interaction | Click, scroll, write, wait, and press before extraction |
| Discovery | Discover all URLs on a website instantly or scrape all URLs with one request |
| Automation | Automated data gathering based on descriptions of what is needed |
| Scale | Asynchronous scraping of thousands of URLs |

## 🧩 How it works
Firecrawl handles several technical requirements with zero configuration, including:
* Rotating proxies
* Orchestration
* Rate limits
* JS-blocked content

Users can search the web to get full page content from results, convert any URL to various formats, or scrape a page and then interact with it using code or AI prompts.

## 🚀 Availability
Firecrawl is open source and available as a hosted service. It can be connected to any MCP client or AI agent with a single command. Users can sign up at firecrawl.dev for an API key or test the tool via a playground.
