# AI Edge Gallery Adds Support for Gemma 4 and On-Device Features

AI Edge Gallery is a destination for running open-source Large Language Models (LLMs) directly on mobile hardware. The latest version introduces official support for the Gemma 4 family of models, enabling high-performance Generative AI to run fully offline and private.

## 🔍 Overview
All model inferences occur directly on the device hardware without requiring internet, which ensures privacy for images, prompts, and sensitive data. The platform utilizes Google AI Edge for core APIs and tools, along with LiteRT for optimized model execution.

## ⚙️ Key Details

| Feature | Description |
| :--- | :--- |
| Thinking Mode | Allows users to see the model's step-by-step reasoning process; currently supported by the Gemma 4 family. |
| Agent Skills | Augments capabilities with tools such as interactive maps, Wikipedia for fact-grounding, and visual summary cards. |
| Multimodal Power | Uses the photo gallery or camera to solve visual puzzles, identify objects, or generate detailed descriptions. |
| Voice Capabilities | Real-time transcription and translation of voice recordings into text via on-device models. |
| Dedicated Workspace | Provides granular control over model parameters like top-k and temperature for testing prompts and single-turn use cases. |
| Model Management | Includes the ability to download models from a list, load custom models, and run benchmark tests on specific hardware. |

## 🧩 Specialized Capabilities
Certain tasks are powered by a finetune of FunctionGemma 270m:
* Offline device controls and automated tasks.
* An experimental mini-game where natural language is used to harvest and plant a virtual garden.

Users can also load modular skills via GitHub Discussions community contributions or from a URL.

## 🚀 Availability
* **OS Requirements:** Android 12 and up; iOS 17 and up.
* **Installation:** Available via the App Store, Google Play, or as an apk from the latest release for users without Google Play access.
