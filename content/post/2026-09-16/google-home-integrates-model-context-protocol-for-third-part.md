# Google Home integrates Model Context Protocol for third-party AI agents

Google is opening its smart home ecosystem to third-party AI agents through the standardized Model Context Protocol (MCP). This integration allows external agents to access and control connected devices and analyze home data.

## 🔍 Overview

Home MCP integration connects chosen AI agents to real-world events, allowing them to act on a user's behalf. This adds a layer of control that lets third-party agents interact directly with Google Home devices through their own interfaces. This does not replace Gemini for Home, which remains Google's interface for the Home app and Google Nest smart speakers.

## 🧩 How it works

According to Taylor Lehman, group product manager at Google Home & Nest, the integration "allows any AI agents that support MCP, including Google Antigravity, Claude, Hermes or Open Claw, to securely work with all of the devices and event history in your Google Home ecosystem."

Capabilities include:
* **Data Analysis:** Using device state history to determine how many loads of laundry were done in a week or how long lights remained on.
* **Cross-Camera Analysis:** Asking an agent what a child did when arriving home from school.
* **Direct Interaction:** Agents can send audio messages over Google Home speakers upon completing a task.
* **Customization:** Agents can create custom dashboards to control the Google Home.

## ⚙️ Key details

| Feature | Description |
| :--- | :--- |
| Security | Enforces rate limits and safety protections, such as preventing agents from unlocking doors |
| Setup | Requires creating and configuring a Google Cloud project to use Home MCP |
| Developer Tools | Google provides the Antigravity coding tool to build custom AI agents |

## 🚀 Availability

At launch, availability is limited to Google Home Premium Advanced users in the US, costing $20 per month or $200 per year. Access is rolling out in the coming weeks.
