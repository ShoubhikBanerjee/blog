# OpenDesign Launches Local-First Open-Source Alternative to Claude Design

OpenDesign has launched as an open-source, local-first desktop application for macOS and Windows that serves as an alternative to Claude Design.

## 🔍 Overview
OpenDesign is a native desktop app used to create and refine various digital assets within a project's Studio. Users can start with a brief, utilize reusable skills in Plugins, and convert brand references into a design system via brand-grade `DESIGN.md` files.

## 🧩 How it works
OpenDesign operates as a local-first app that supports a wide range of runtimes and endpoints:

* **Native Runtimes:** Supports DeepSeek Harness (`dsh`), Claude Code, OpenClaw, Codex, Cursor, OpenCode, Qwen, Copilot, Amp, Hermes, Kimi, Antigravity, and 26 distinct local CLI executables.
* **BYOK:** Supports any OpenAI-compatible endpoint via Bring Your Own Key (BYOK).
* **DeepSeek Integration:** The official `dsh` agent harness connects as a native runtime providing model discovery, tool calls, structured thinking, session resume, and cancellation.

## ⚙️ Key details
Users can utilize a single recharge to access both agent and image models within the application:

| Model Type | Supported Models |
| :--- | :--- |
| **Agents** | GPT, Claude, DeepSeek |
| **Images** | GPT Image 2.0, Seedream 5.0 Pro, Nano Banana 2.0 |

**Capabilities and Exports:**
* **Generates:** Web, desktop, and mobile prototypes; live dashboards/artifacts; decks; images; video; and HyperFrames motion graphics.
* **Artifacts:** Delivers single-page artifacts using real CSS, real fonts, and real components.
* **Preview & Export:** Features a sandboxed iframe preview with exports available in HTML, PDF, PPTX, and MP4 formats.
* **Workflow:** Generated files remain in the OpenDesign workflow for delivery and live preview.

## 🚀 Availability
DeepSeek V4 Flash and V4 Pro are now available. OpenDesign members can use both of these models without limits for two weeks directly inside the app.
