# Google Introduces Gemini 3.8 Live and Gemini 3.8 Live Extended Thinking Models

Google has introduced two new AI models, Gemini 3.8 Live and Gemini 3.8 Live Extended Thinking, designed to bring advancements in near real-time reasoning to voice agents. These models make speaking with Gemini across the Gemini app, Google Workspace, and Search more fluid and collaborative, while providing developers and enterprises with the building blocks for reliable, production-ready voice applications.

## 🔍 Overview
The new models are built to support cost-effective, scalable, and high-performance voice-driven interfaces. Gemini 3.8 Live focuses on high user preference and efficiency, while Gemini 3.8 Live Extended Thinking delivers enterprise-grade task completion and advanced reasoning capabilities.

## 🧩 Key Capabilities
The models introduce several features designed to optimize real-time conversational experiences:
* **Near Real-Time Visual Processing:** Gemini 3.8 Live processes visual inputs dynamically to enrich conversations with context for more helpful responses.
* **Multilingual Detection:** The models automatically detect and transition between 97 supported languages mid-conversation.
* **Background Tool Execution:** The systems execute tools and API calls in the background while continuing the conversation, allowing the model to acknowledge requests and keep chatting while tasks finish.
* **Simultaneous Reasoning and Speaking:** Gemini 3.8 Live Extended Thinking handles complex tasks with an uninterrupted conversational flow, utilizing early verbal cues like "Let me check that..." and live progress narration to walk users through background tasks.
* **Watermarked Audio:** All audio generated by these AI products is watermarked directly into the output with SynthID to ensure AI-generated content remains detectable.

## 📊 Benchmark Performance
Both models have demonstrated strong performance across several industry evaluations, balancing accuracy and conversational quality:

| Benchmark / Index | Model | Achievement / Score |
| :--- | :--- | :--- |
| Artificial Analysis' Speech to Speech Quality Index | Gemini 3.8 Live Extended Thinking | #1 overall spot (82.6) |
| Big Bench Audio | Gemini 3.8 Live Extended Thinking | 97.7% |
| τ-Voice (agentic task completion) | Gemini 3.8 Live Extended Thinking | 68.6% |
| Sierra’s τ-Voice-banking | Gemini 3.8 Live Extended Thinking | 35.1% |
| Speech Agent Arena | Gemini 3.8 Live | Second place (user preference) |
| ServiceNow’s EVA‑Bench | Gemini 3.8 Live & Extended Thinking | Pushed the Pareto Frontier for complex workflows |

*Note: Benchmarks were run on the Live API on Gemini Enterprise Agent Platform.*

## 🚀 Integration and Partnerships
By using the Gemini Live API, developer platforms manage complex real-time media streaming infrastructure behind the scenes. This allows developers to easily build and deploy high-performance voice-driven interfaces using platforms such as:
* Agora
* Fishjam
* LangChain
* LiveKit
* Pipecat
* Vercel
* Vision Agents

Additionally, companies including Salesforce, Genspark, and Lumeris are partnering to deploy Gemini 3.8 Live and Gemini 3.8 Live Extended Thinking, highlighting the models' latency, fluidity, and tool-calling capabilities.
