# Langfuse joins ClickHouse to provide open source LLM engineering platform

Langfuse, an open source LLM engineering platform, has become part of ClickHouse as of January 2026. The platform is designed to help teams collaboratively develop, monitor, evaluate, and debug AI applications.

## 🔍 Overview
Langfuse is a battle-tested platform that can be self-hosted in minutes. It is built using the ClickHouse open source database.

## 🧩 How it works
Users instrument their applications to ingest traces into Langfuse, which allows for the tracking of:
* LLM calls
* Retrieval logic
* Embedding
* Agent actions

## ⚙️ Key details
Langfuse includes several specialized tools for LLM application management:

| Feature | Capability |
| :--- | :--- |
| Prompt Management | Central management, version control, and collaborative iteration on prompts with server and client side caching to avoid latency. |
| Datasets | Test sets and benchmarks for pre-deployment testing, structured experiments, and continuous improvement. |
| Debugging | Inspection of complex logs and user sessions. |

Evaluation capabilities include:
* LLM-as-a-judge
* Code evaluators
* User feedback collection
* Manual labeling
* Custom evaluation pipelines via APIs/SDKs

The platform also integrates with frameworks such as LlamaIndex and LangChain.

## 🚀 Availability
Since joining ClickHouse in January 2026, Langfuse is hiring hybrid engineering roles across the EU.
