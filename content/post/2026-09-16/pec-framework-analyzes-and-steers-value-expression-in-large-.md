# PEC Framework Analyzes and Steers Value Expression in Large Language Models

Researchers have developed the Prior-Environment-Cognition (PEC) framework to verify and steer the values expressed by Large Language Models (LLMs).

## 🔍 Overview
By projecting 150,000 queries per model from 106 LLMs and 95,000 human survey profiles into a shared sociological space, researchers empirically confirmed that LLMs possess values. However, these values do not mirror human diversity and instead crystallize into a highly concentrated, idealized value core.

## 🧩 How it works
The PEC framework mathematically defines value expression as the joint outcome of three factors:

| Dimension | Description |
| :--- | :--- |
| Prior | Inherent dispositions such as parameter weights |
| Environment | External contexts such as user prompts |
| Cognition | Internal reasoning processes like Chain-of-Thought |

## 💡 Why it matters
Using PEC diagnostics, researchers established an "Alignment Prescription" to move away from resource-intensive blind training. This approach offers several advantages:

* Identifies the minimum effective intervention for each dimension, ranging from zero-cost prompts to targeted parameter updates.
* Achieves more efficient and precise steering than conventional blind training.
* Verifies the presence of LLM values and accurately quantifies their shifts.
* Maintains general capabilities without degradation.
