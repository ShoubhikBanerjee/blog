# DeerFlow 2.0 Open-Source SuperAgent Harness Launched

DeerFlow (Deep Exploration and Efficient Research Flow) is an open-source super agent harness designed to research, code, and create. On February 28th, 2026, the project claimed the #1 spot on GitHub Trending following the launch of version 2.

## 🔍 Overview
DeerFlow 2.0 is a ground-up rewrite that shares no code with v1. It is an open-source harness that orchestrates sub-agents, memory, and sandboxes to perform tasks using extensible skills.

## 🧩 How it works
To handle tasks that can take minutes to hours, the system utilizes the following components:
* Sandboxes
* Memories
* Tools
* Skills
* Subagents
* Message gateway

Additionally, the system integrates InfoQuest, an intelligent search and crawling toolset developed by BytePlus. The InfoQuest reader, web search, and image search features use a 30-second HTTP connect/read inactivity timeout.

## ⚙️ Key details
**Technical Requirements:**
* Python-3.12+
* Node.js-22+
* License: MIT

**Recommended LLMs:**
* Doubao-Seed-2.0-Code
* DeepSeek v3.2
* Kimi 2.5

**Developer Tools:**
DeerFlow includes LLM Space, a desktop tool used to prototype agent ideas, inspect harness steps, replay failures, and benchmark performance.
