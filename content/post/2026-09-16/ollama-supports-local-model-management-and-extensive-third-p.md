# Ollama Supports Local Model Management and Extensive Third-Party Integrations

Ollama provides a framework for running and managing AI models locally, offering a REST API and support for various model families and external applications.

## ⚙️ Key details

Ollama allows users to run and chat with several models, including:
* Gemma 4
* Kimi
* GLM
* MiniMax
* DeepSeek
* gpt-oss
* Qwen
* Gemma

Development and deployment options include:
* An official Docker image (`ollama/ollama`) available on Docker Hub
* `ollama-python`
* `ollama-js`
* Foundation based on the llama.cpp project founded by Georgi Gerganov

## 🚀 Availability

Ollama integrates with various agents and applications, including:
* Claude Code
* Codex
* Copilot CLI
* DeepSeek Harness
* Droid
* OpenCode
* OpenClaw (used to turn Ollama into a personal AI assistant across WhatsApp, Telegram, Slack, and Discord)
