# Executable Ground‑Truth Framework Improves Evaluation of Data‑Science Agents

A new framework introduces “ground‑truth‑as‑code” to evaluate data‑science agents on live, continuously updated data.

## 🔍 Overview
- Presents a framework for evaluating data‑science agents on live, continuously updated data using executable ground truth and format‑agnostic factoid scoring.
- Targets agents whose expected outputs can be expressed as executable data computations.
- Emphasizes that multi‑source data integration and computation over non‑stationary data are common in industry.

## 🧩 How it works
- **Ground‑truth‑as‑code** encodes each expected answer as an executable reference function that recomputes the answer directly from live data at evaluation time, keeping the reference consistent with the system.
- A **format‑agnostic judge** decomposes both the agent’s response and the computed ground truth into atomic claims and scores precision, recall, and accuracy, regardless of response format (prose, list, table, HTML, etc.).
- The approach is applicable wherever the expected output can be generated by a computation over the data.

## 📊 Validation
- Validated through a human‑LLM agreement study on an internally developed machine‑learning skill deployed in production, using a synthetic database that reproduces production schemas and entity relationships.
- Compared to a natural‑language ground‑truth baseline, the method achieved:

| Metric | Improvement |
|--------|-------------|
| Matthews Correlation Coefficient (MCC) | +29% |
| Token consumption per test case | –16% |

- A self‑directed baseline lacking explicit ground truth was found to be anti‑correlated with human judgment.

## 💡 Why it matters
- Provides a practical methodology for evaluating agents that perform multi‑source data integration and computation over evolving data.
- Improves alignment between automated evaluation and human expert judgment.
- Reduces evaluation token costs while increasing class‑balanced agreement metrics.
