# OpenHuman Open Source Agent Harness Launched with Local-First Memory

OpenHuman has launched as an open source agent harness featuring agent orchestration, workflows, and local-first memory. Within one week of its launch, the project became the number one trending repository on GitHub for nine consecutive days.

## 🔍 Overview
OpenHuman is described as a personal AI super intelligence that functions as a deep researcher, an orchestrator, and a brain that remembers everything. It is not AGI.

## 🧩 How it works
OpenHuman provides three primary capabilities:

| Feature | Description |
| :--- | :--- |
| Brain | Builds a persistent, local memory of your world |
| Orchestrator | Runs fleets of agents on durable graphs |
| Deep Researcher | Sweeps data and the web before a user finishes asking |

## ⚙️ Key details
* **Memory Tree + Obsidian Wiki**: Data is compressed into scored Markdown trees in SQLite on the user's machine and mirrored as an Obsidian vault for opening and editing.
* **Integrations**: The system includes 100+ OAuth integrations, 5,000+ MCP servers, and 90,000+ Skills for one-click access to tools such as GitHub, Slack, Notion, and Gmail.
* **Auto-fetch**: A feature that feeds the brain every 20 minutes to provide updated context.

## 🚀 Availability
Installers are available via the GitHub Releases page or at tinyhumans.ai/openhuman.
