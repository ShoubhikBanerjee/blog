# Langflow Released for Building and Deploying AI Agents and Workflows

Langflow is an open source tool designed for the construction and deployment of AI-powered agents and workflows, supporting all major LLMs and vector databases.

## 🔍 Overview
Langflow provides a visual authoring experience combined with built-in API and MCP servers. This allows developers to turn workflows into tools that can be integrated into applications across any framework or stack.

## ⚙️ Key details
- **Visual Builder:** Interface for quick starting and iteration.
- **Customization:** Source code access allows components to be customized using Python.
- **Interactive Playground:** Testing and refining flows with step-by-step control.
- **Orchestration:** Multi-agent orchestration featuring retrieval and conversation management.
- **Observability:** Integrations with LangFuse, LangSmith, and others.
- **Security:** Enterprise-ready scalability and security.

## 🧩 How it works
Developers can deploy their work through various methods:

| Deployment Method | Result/Output |
| :--- | :--- |
| API | Deploy as an API |
| JSON | Export for Python apps |
| MCP Server | Turn flows into tools for MCP clients |

## 🚀 Availability
Langflow is open source and can be deployed to all major deployment clouds. It is available via:

- **Langflow Desktop:** Available for macOS and Windows; includes all dependencies to remove the need for manual package installation or Python environment management.
- **Docker:** Can be started via `docker run -p 7860:7860 langflowai/langflow:latest`.
- **Manual Installation:** Requires Python 3.10–3.14 and the recommended package manager `uv`. Installation is performed via `uv pip install langflow -U` and started with `uv run langflow run` (running at http://127.0.0.1:7860).
- **Contribution:** Those who have cloned the repository can use `make run_cli` from the root.
