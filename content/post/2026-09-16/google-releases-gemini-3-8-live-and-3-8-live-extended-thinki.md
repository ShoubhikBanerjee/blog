# Google Releases Gemini 3.8 Live and 3.8 Live Extended Thinking Models

Google has released two new speech-to-speech models, Gemini 3.8 Live and 3.8 Live Extended Thinking, which are a similar shape to OpenAI's GPT-Live family.

## ⚙️ Key details

| Model | Description |
| :--- | :--- |
| Gemini 3.8 Live | Speech-to-speech model |
| Gemini 3.8 Live Extended Thinking | Speech-to-speech model |

## 🧩 How it works

* The implementation uses no libraries.
* It utilizes a Web Audio API AudioContext for playback and capture.
* It connects to the following WebSocket endpoint:
`wss://generativelanguage.googleapis.com/ws/google.ai.generativelanguage.v1alpha.GenerativeService.BidiGenerateContent?key=...`
