# Anthropic Launches Claude Docs and Slides in Beta

Anthropic is introducing two new productivity tools, Claude Docs and Claude Slides, which allow users to create, edit, and share documents and presentations directly from Claude chats.

## 🧩 How it works

Users can generate documents and presentations from any chat and make changes by asking Claude to modify them or by editing manually. 

* **Collaboration:** Docs start as private but can be shared with other editors for real-time collaboration.
* **Commenting:** Collaborators and Claude can leave comments on documents.
* **Accessibility:** Content created with Docs, Slides, or Claude Design is hosted at one shareable link accessible via phone.

## ⚙️ Key details

Anthropic is implementing an update called "one Claude," which merges regular chats and Cowork into a single interface. This allows the AI to determine what a task needs, making the skills and connectors of Cowork and Design available from any conversation.

| Tool | Functionality |
| :--- | :--- |
| Claude Docs | Create, edit, and share documents via chat |
| Claude Slides | Create, edit, and share presentations via chat |
| Claude Design | AI productivity capabilities available in the single interface |
| Artifacts | Productivity capabilities available in the single interface |

## 🚀 Availability

The "one Claude" update is rolling out over the next few weeks to Pro and Max users on web, desktop, and mobile. Access for Free and Team users will follow later. Anthropic states there is "nothing to turn on" for the update, and users may continue using Claude chat normally.

## 💡 Why it matters

These tools allow Anthropic to compete with Google, which has natively tied Gemini into its suite of productivity tools, including features for generating and editing documents and creating slides. The addition of Docs and Slides is intended to close the gap between Anthropic's platform and Google's tools, reducing the need for users to leave Claude chats for other applications.
