# Ruflo Launches as an Agent Meta-Harness for Claude Code and Codex

Claude Flow has been renamed to Ruflo, an agent meta-harness and execution layer designed for Claude Code and Codex.

## 🔍 Overview
Ruflo serves as the execution layer around Claude Code and Codex, providing a system that allows for the deployment of intelligent multi-player swarms and the coordination of autonomous workflows. It integrates with native Claude Code, Codex, and Hermes, among others.

## ⚙️ Key details
Ruflo provides several technical capabilities to enhance agent operations:

* **Memory and Learning**: Features adaptive memory, self-learning intelligence, and the ability to remember across sessions.
* **Coordination**: Supports coordinated swarms and the ability for agents to self-organize.
* **Connectivity**: Includes federation for secure communication across machines without leaking data and vector RAG integration.
* **Security**: Includes enterprise security guardrails.
* **Scale**: Adds over 100 specialized agents.

## 🧩 How it works
Users can set up the system with the command `npx ruflo init`. Once initialized, the system functions as follows:

* **Integration**: Users continue to use Claude Code normally.
* **Automation**: A hooks system automatically routes tasks and coordinates agents in the background.
* **Optimization**: The system learns from successful patterns and every task.
* **Simplification**: It removes the need to learn 26 CLI commands or 314 MCP tools.
