# AutoGPT Launches Hosted Platform for Building and Running AI Agents

AutoGPT has introduced a hosted platform that allows users to build, deploy, and run AI agents designed to carry out complete workflows.

## 🧩 How it works
Users can create agents by describing an outcome in plain English or by using a visual builder to shape every step. Once created, agents can be run on demand, on a schedule, or from a trigger.

## ⚙️ Key details
AutoGPT provides the following core components:

| Component | Description |
| :--- | :--- |
| AutoPilot | Turn a plain English conversation into a working agent |
| Agents | Monitor every agent, run, cost, and action requiring attention |
| Marketplace | Customize proven agents from a library for specific work |
| Build | Drag, connect, branch, and inspect blocks for exact control |

Additional technical specifications include:
* Integration with 45+ connected platforms and hundreds of AI models.
* No requirement for infrastructure setup or model API keys.
* Over 185,000 GitHub stars.

## 🚀 Availability
The hosted Platform is publicly available. AutoGPT manages the credentials, reliability, updates, model access, and infrastructure.

* **Paid service:** The hosted Platform uses usage-based agent runs.
* **Free path:** Available via self-hosting.
