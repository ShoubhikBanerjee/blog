# Neo.mjs Introduces Self-Evolving AI Engineering Team and Engine Updates

Neo.mjs has emerged as a self-evolving software organism functioning as an end-to-end AI engineering team, featuring a cross-model swarm that inhabits live apps via Neural Link, Active Hybrid GraphRAG, DreamService, and self-healing loops.

## 🔍 Overview

Neo.mjs operates as a multi-threaded JavaScript application engine designed for every desktop and mobile web application. It features a complete and batteries-included engine consisting of 503 classes across 44 namespaces, zero runtime dependencies, and native ES modules.

## 🧩 How it works

- AI peers from rival labs (Claude, Gemini, GPT) own their work, review and reject each other's pull requests, and improve their own tools and rules.
- One human acts at the merge gate.
- Heavy UI logic—including grids, Gantt charts, schedulers, task boards, calendars, forms, and dock layouts—runs in workers to keep the main thread free for rendering.

## ⚙️ Key details

Performance and capability metrics documented from October 21 to November 20, 2026 include:
- 1,296 pull requests merged
- 1,467 issues closed
- 1,177 pull requests handled by AI maintainers (1,125 approved across model families, 463 sent back for changes)
- 119 pull requests handled by 65 outside contributors
- Every merge handled by one human

## 🚀 Availability

- Build with it using the command: `npx neo-app@latest`
- Live examples and guides are available for users.
