# YouDub Opensourcing AI Video Localization and Dubbing Tool

YouDub is a new open-source desktop application that automates video localization and dubbing through an integrated pipeline of speech recognition, translation, voice cloning, and audio rendering. The tool supports both video links and local file uploads, and generates synchronized subtitles and dubbed audio from source content. A sample demonstration features a 59-second Clive Huang interview translated from English to Chinese with sentence-level voice cloning and preserved background sound. Workflows are built using a three-layer architecture combining Electron desktop shell, Vite React frontend, and Python FastAPI backend, with task management for progress tracking, error handling, and output download. The system uses SentenceX for sentence boundary detection with word-level timestamps, supports OpenAI, Anthropic, and Gemini translation APIs with sliding context, and enforces no artificial limits on video duration, file size, resolution, or frame rate.
