# Chinese Researchers Release AscendGYM Kernel Optimization Benchmark for Huawei NPUs

Researchers from the Shenzhen Loop Area Institute have released AscendGYM, a kernel optimization benchmark designed for Huawei Ascend NPUs. The tool aims to help Chinese organizations develop custom kernels for Huawei chips, particularly important given export controls that limit access to Western semiconductors. AscendGYM evaluates performance across multiple dimensions including cross-case applicability, shape specialization, and optimization efficiency, while providing unified interfaces for compilation, correctness checking, and performance measurement through its AscendForge evaluation environment. The benchmark characterizes achievable performance for specific shapes and scenarios alongside the optimization cost required to obtain gains. According to test results, Opus 5 leads in performance followed by GPT-5.6 and GLM-5.3, with Claude Code yielding the best absolute scores while GPT performs well in Codex environments. Software like AscendGYM represents an essential ingredient for enabling China to rapidly improve the efficiency of its domestic compute substrates.
