# New Comprehensive AI Infrastructure Learning Resource Collection Released

A comprehensive artificial intelligence infrastructure learning resource collection has been introduced, covering the complete technical stack from hardware foundations to advanced applications. This new repository aims to provide systematic learning paths and practical guidance for AI engineers, system researchers, and technical enthusiasts.

## 🔍 Overview
- Status: NEW
- Target Audience: AI engineers, system architects, GPU programming developers, large model application developers, and technical researchers.
- Core Technology Stack: CUDA, GPU architecture, LLM, AI systems, distributed computing, containerized deployment, and performance optimization.
- Practical Components: Includes 12 runnable demos across the repository with dependency requirements, corresponding articles, and validation statuses.

## ⚙️ Key Technical Domains
- Hardware & Interconnects: Covers single-chip basic computing design principles (GPU, TPU), PCIe and NVLink high-speed interconnect bus protocols, GPUDirect cross-node direct-through technology, DMA engine paths (GPU/NIC/NVMe/DPU/CXL), and heterogeneous fusion superchip system-level architecture and delay pyramid models such as the NVIDIA GB300 NVL72.
- Accelerators & Processors: Features understanding of GPU architecture, TPU 101 deep learning specialized accelerator architecture, GPGPU vs NPU inference and training comparison, and Ascend950 sparse attention Forward operator and optimization technology.
- Bus & Interconnect Protocols: Includes PCIe tech, Linux PCIe P2PDMA, CXL interconnect protocol, NVLink, NVIDIA GPUDirect P2P, GPUDirect RDMA and Storage, DMA engine details, NVLink-C2C, and NVIDIA GB300 NVL72 architecture.
- Operations & Monitoring: Encompasses Device Query, nvidia-smi, nvtop guides, IB network architecture and protocol, health checks and performance monitoring, NCCL tutorials, benchmarking, multi-node deployment, and GPUDirect Async deep-dives.
- Cloud-Native Infrastructure: Features Kubernetes-based AI infrastructure building, NVIDIA Container Toolkit, Device Plugin mechanics, Kueue/HAMi fine-grained GPU resource partitioning and pooling, LWS/llm-d distributed inference scheduling, and high-performance distributed storage systems like JuiceFS and DeepSeek 3FS.
- GPU Virtualization: Dedicated to hardware-level, kernel-mode, and user-mode virtualization mechanisms, GPU partitioning, CUDA streams, and MPS resource scheduling and optimization strategies.
