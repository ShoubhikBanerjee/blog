# OrcaRouter Lite Launches as Self-Hosted AI Model Router with Managed Safety Net

OrcaRouter Lite, an open-source single-workspace edition of OrcaRouter, has been released as a self-hosted server that combines local control with a managed fallback for AI model routing. The new router supports OpenAI-compatible APIs and includes built-in streaming, with a focus on simplifying model selection through automated routing and cost optimization.
