# ChroMapper 360/90 Support and Chroma 2.0 Lighting Released

## 📢 New Features

ChroMapper, a Unity-based map editor for Beat Saber, has introduced 360/90 support for the first time ever in a community map editor, along with Chroma 2.0 Lighting.

## 🧩 Key Features

- **360/90 Support** for the first time ever in a community map editor
- - **Chroma 2.0 Lighting** brings lightshows to the next level
- **Optimized** to run on a wide range of devices, from high-end VR machines to Chromebooks
- **Cross-platform**, with official x64 builds available for Windows, Mac OS, and Linux
- Individual users may also build ChroMapper for other platforms
- **Rebindable Keys** means you can adapt your mapping workflow to whatever input device you have installed

## ⚙️ Technical Details

- Developed with Unity in C#
- Uses the GNU GPL v2 license
- Builds are automatically created with Jenkins
- GitHub Releases will be made with every stable update

## 🚀 Availability

- Recommended installation method is through the ChroMapper Launcher, which auto-updates
- x64 builds available for Windows, Mac OS, and Linux

## 💡 Support & Community

- The ChroMapper Discord is the central point of communication between users and the developers
- Atlas Rhythm provides a tutorial for new users
- The ChroMapper Wiki offers documentation about the program, setup, and features
- Localization updates are pulled from CrowdIn on a semi-occasional basis

## 🤝 Development & Contributions

- Build guide available for setting up a development environment
- Developers are encouraged to contribute under the GNU GPL v2 license
- Patreon offers a way to support development and receive perks
- CrowdIn allows users to help translate the application into other languages
