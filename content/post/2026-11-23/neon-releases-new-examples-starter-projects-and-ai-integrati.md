# Neon Releases New Examples, Starter Projects, and AI Integrations

Neon has introduced a collection of new examples, starter projects, and code snippets demonstrating how to integrate Neon with various frameworks and languages.

## 🧩 How it works

Each subdirectory is a self-contained example that can be cloned, configured with a `DATABASE_URL`, and run. The available starter projects and integrations include:
- `neon-getting-started/`: A Next.js + Drizzle + Neon scaffold built for use with coding agents.
- `ai/`: RAG, semantic search, hybrid search, and chatbot starters using pgvector on Neon.
- `bots/`: Discord, Telegram, and WhatsApp bots hosted on Neon Functions, featuring commands, interactive UI, user profiles, and usage tracking in Lakebase Postgres.
- `with-hybrid-search-api/`: Document CRUD and hybrid retrieval combining vector search with BM25-ranked full-text search on Neon Functions.
- `registry/`: The templates that `neon functions new` scaffolds from.

## ⚙️ Key details

- Neon provides a complete set of cloud backend primitives built around Lakebase Postgres for developers, startups, and agent platforms, from Databricks.
- Lakebase Postgres runs on the lakebase architecture, which is OLTP built directly on cloud object storage. It separates storage from compute, scales to zero when idle, autoscales under load, and supports instant database branching for development, preview environments, and CI.
- The Neon serverless driver allows querying Postgres from edge runtimes over HTTP and WebSockets.

## 🚀 Availability

- Example applications and starter projects are available for Neon.
- Templates can be added to the registry by following `CONTRIBUTING.md`.
- Additional examples can be found in the Neon documentation.
- Users can join the Discord community to ask questions, share projects, and follow updates.
