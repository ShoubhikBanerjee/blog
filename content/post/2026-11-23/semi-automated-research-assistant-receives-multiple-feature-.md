# Semi‑Automated Research Assistant Receives Multiple Feature Updates

A semi‑automated research assistant for academic research and software development has received a new update.

## 🔍 Overview
- The assistant supports Claude Code, Codex CLI, Kimi Code CLI, and OpenCode across the full research lifecycle: literature review, ideation, coding, experiments, reporting, writing, and publication.

## 🧩 Supported Workflows
| Branch | CLI / Workflow | Primary Use |
|---|---|---|
| Claude Code | Main branch | Ideation, coding, experiments, writing, publication |
| Codex CLI | codex branch | Literature review, coding, experiments, reporting, writing, project knowledge management |
| Kimi Code CLI | kimi branch | Same as Codex CLI for computer‑science and AI researchers |
| OpenCode | opencode branch | Same as Codex CLI for computer‑science and AI researchers |

## ⚙️ Recent Updates (2026)
- **2026‑11‑23**: Fixed manual Claude Code hooks for home paths with spaces and preserved hook exit codes; Presentation canvases now opt‑in. Codex adds Granola import into Obsidian and installation diagnostics.
- **2026‑10‑19**: Fixed Claude Code plugin hooks for paths with spaces, improved Windows file‑write checks, and documented optional Parallel Search setup.
- **2026‑09‑23**: Made paper‑miner writing patterns reusable across writing skills and preserved them through upgrades and uninstall; Improved Codex agent discovery.
- **2026‑08‑27**: Added optional Xquik support for paper promotion in Claude Code, Codex, and OpenCode.
- **2026‑06‑03**: Added Kimi Code CLI branch with strong support from Kimi.
- **2026‑05‑14**: expression‑skill made the communication core; planning‑with‑files restored as default persistence layer; Nature writing stack expanded; introduced nature‑writing for section drafting; refreshed nature‑polishing to latest standards.

## 🚀 Availability & Integration
- OfoxAI model APIs provide access to Claude, GPT, Gemini, and DeepSeek text models with one API key for literature reading, experiment code, and academic writing.
- Image, video, and speech models are also available for research presentations and communication.
- APIMart offers a low‑cost API platform for AI image & video generation (GPT‑Image‑2 from $0.006 per image, >160 images per dollar). One async API covers both image and video, supports batch processing of tens of thousands of images, and operates pay‑as‑you‑go with no monthly fee.

## 💡 Why it matters
- Unifies the research workflow for computer‑science and AI researchers, reducing context switching.
- Flexible branch selection aligns with preferred code‑generation models (Claude, Codex, Kimi, OpenCode).
- Low‑cost image/video generation enriches research presentations without added expense.
