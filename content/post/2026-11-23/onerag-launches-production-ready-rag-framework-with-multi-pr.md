# OneRAG Launches Production-Ready RAG Framework with Multi-Provider Flexibility

OneRAG is a production-ready Retrieval-Augmented Generation (RAG) framework built with Python and FastAPI that supports seamless switching between multiple vector databases and language models through simple configuration changes. The framework offers 1-line config swaps for 6 vector databases (Weaviate, Pinecone, Qdrant, ChromaDB, pgvector, MongoDB), 5 LLM providers (Gemini, OpenAI, Claude, Ollama, OpenRouter), and includes an OpenAI-compatible API for easy integration with existing codebases. With over 2100 tests and support for hybrid search (Dense + BM25), it enables developers to start locally without API keys using Ollama LLMs, scale to production without rebuilding, and maintain compatibility with OpenAI SDK code via the `/v1/chat/completions` endpoint. Setup is straightforward: clone the repository, sync dependencies, copy the quickstart environment file, and launch the service. Sample data is preloaded and ready to use, while the framework automatically generates environment files if missing.
