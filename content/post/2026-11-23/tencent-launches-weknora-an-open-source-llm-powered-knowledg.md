# Tencent Launches WeKnora: An Open-Source LLM-Powered Knowledge Framework

Tencent has released WeKnora, an open-source, LLM-powered knowledge framework for enterprise document understanding, semantic retrieval and reasoning. It brings a team's documents together so they can be searched, reasoned over and kept up to date. The framework combines RAG for lookups, an agent for multi-step tasks, and a wiki for knowledge organization, all operating on the same knowledge bases.

## 📚 Core Components

WeKnora integrates three main capabilities:

| Component | Description |
|-----------|-------------|
| **RAG** | Answers you can check, with hybrid search, multimodal parsing and citations |
| **Agent** | Tasks done with knowledge and tools, with multi-step reasoning, skills and sandbox, the local browser, MCP tools and memory |
| **Wiki** | Documents organized into a wiki, with a knowledge graph and rollback |

## ⚙️ Key Features

- Skills installed from ClawHub / SkillHub / Git / ZIP run in session-persistent Docker / E2B / Cube sandboxes, with an interactive terminal and graphical desktop beside the chat
- BrowserSkill extension allows the agent to operate the user's own Chrome or Edge, and external MCP services (OAuth included) can be connected and enabled tool by tool
- Cross-session long-term memory keeps the profile, preferences and facts a user has confirmed
- Folder uploads preserve directory structure, and retrieval chunks can be edited, diffed and rolled back
- Auto-sync from multiple platforms including Feishu wiki, Confluence, GitLab, Notion, and others
- Supports 10+ document formats including PDF, Word, images, Excel and XMind
- Q&A integrations with WeCom, Feishu, Slack, Telegram, and embed widgets for external websites
- 30 built-in vendors supporting OpenAI, DeepSeek, Qwen, Zhipu, Gemini, and others
- Multi-workspace RBAC with four roles, per-resource ownership, audit logs, and Langfuse tracing
- All components support swappable LLMs, vector databases, and storage backends
- Can be deployed locally or on private cloud to keep data in user's own environment

## 🚀 Availability

WeKnora is available as open-source software under the MIT license. The current version is v0.9.0, with documentation accessible at docs.weknora.weixin.qq.com and the project hosted at github.com/Tencent/WeKnora.
