# SafeLine Emerges as Top GitHub Trending WAF Repository

SafeLine has newly appeared as a top-ranked GitHub trending repository for Go projects, establishing itself as a self-hosted Web Application Firewall (WAF) designed to protect web applications from attacks and exploits.

## 🔍 Overview

SafeLine is a self-hosted Web Application Firewall (WAF) to protect web apps from attacks and exploits. A web application firewall helps protect web apps by filtering and monitoring HTTP traffic between a web application and the Internet.

## 🧩 How it Works

Unlike a proxy server that protects a client machine's identity, a WAF operates as a reverse-proxy, shielding the server by routing client requests through the firewall before reaching the server. A WAF protects web apps by filtering, monitoring, and blocking malicious HTTP/S traffic while preventing unauthorized data from leaving the application. This is achieved through policies that distinguish between malicious and safe traffic.

## ⚙️ Key Details

SafeLine's core capabilities include:

| Capability | Description |
|------------|-------------|
| Block Web Attacks | Defends against SQL injection, XSS, code injection, os command injection, CRLF injection, XXE, SSRF, path traversal, and other web attacks |
| Rate Limiting | Thwarts DoS attacks, bruteforce attempts, traffic surges, and abuse by throttling excessive traffic |
| Anti-Bot Challenge | Blocks bots and crawlers while allowing human users through challenge mechanisms |
| Authentication Challenge | Requires password entry for visitors when enabled, blocking unauthenticated access |
| Dynamic Protection | Dynamically encrypts HTML and JavaScript code with each visit to the web server |

Additional features include defenses for web attacks, proactive bot abuse defense, HTML & JS code encryption, IP-based rate limiting, and Web Access Control List.
