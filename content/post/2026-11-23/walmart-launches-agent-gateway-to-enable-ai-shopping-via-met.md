# Walmart Launches Agent Gateway to Enable AI Shopping via Meta’s Muse

Walmart is integrating Meta’s AI agent Muse into its website, allowing users to leverage the agent to locate and purchase Black Friday deals on their behalf. The rollout features the Walmart Agent Gateway, a new platform designed to help AI agents discover products without accessing user purchase data, as confirmed by Walmart to The Verge.
