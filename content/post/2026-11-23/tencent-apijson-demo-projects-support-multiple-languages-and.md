# Tencent APIJSON demo projects support multiple languages and frameworks

Tencent has published demo projects for APIJSON, featuring usage examples, documentation, and test data SQL files for various programming languages, frameworks, and clients.

## 🔍 Overview

The project provides sample code and resources for different environments, including:
*   **Languages:** Java, Swift, JavaScript, Python, and others.
*   **Frameworks:** SpringBoot, JFinal, and others.
*   **Clients:** Web, Android, iOS, and others.

## 🧩 How it works

The demo suite includes automated testing tools such as APIAuto, UnitAuto, SQLAuto, AutoUI, and CVAuto. These tools support simple demo apps for testing APIJSON as well as complex production apps like social media feeds.

## ⚙️ Key details

*   **Server Testing:** Users can test API endpoints by skipping setup and using the APIJSON official server address `apijson.cn:8080`.
*   **Tools:** Developers can use the APIAuto machine learning HTTP interface tool or download client Apps for testing.
*   **Client Libraries:** Documentation and links are available for Android, iOS, and JavaScript clients.
*   **Support:** Questions can be submitted as issues on the APIJSON core project.

## 🚀 Availability

The APIJSON-Demo repository is available on GitHub. The project lists contributors including two Tencent engineers, one ByteDance engineer, one Ping An Technology engineer, and the author of the Solon framework.
