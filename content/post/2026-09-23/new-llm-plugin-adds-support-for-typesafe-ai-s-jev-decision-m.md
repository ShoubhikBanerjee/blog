# New LLM plugin adds support for TypeSafe AI's Jev decision model

A new plugin has been released for LLM to provide support for the Jev model from TypeSafe AI. This development, announced on 22nd September 2026, allows users to integrate Jev into their existing LLM workflows for specific decision-making tasks.

## ⚙️ Key details

Users can install the plugin via the command line using `llm install llm-typesafe`. After installation, users must set an API key using the command `llm keys set typesafe`.

## 🧩 How it works

The Jev model is categorized as a "System One" or "Decision Model." It supports three primary types of query processing:

| Answer Type | Function |
| :--- | :--- |
| noul | Performs yes/no questioning and scoring |
| choice | Classifies input into specific categories provided via criteria |
| score | Evaluates input based on a ranked list of criteria |

## 🚀 Availability

The plugin is currently available for installation. Users interested in utilizing the Jev model should note that there is a waitlist for API access.
