# OpenAI launches GPT-6.1 with vision bug fixes and new Sol variant

OpenAI has rolled out GPT-6.1 to all paid plans and the API, adding bug fixes for its vision models and introducing a GPT-6.1 Sol variant focused on web development and coding benchmarks.

## 🔍 Overview
- GPT-6.1 is now available across paid subscription tiers and through the OpenAI API.
- The release includes fixes for a bug that reduced image‑understanding performance in the GPT‑6 Sol and GPT‑6 Luna vision models.

## ⚙️ Key updates
- **Vision bug fixes** – Image‑understanding issues in GPT‑6 Sol and GPT‑6 Luna have been corrected.
- **GPT‑6.1 Sol model** – Provides high performance at a lower price point for web development and coding benchmark tasks.
- **Evaluation integration** – The Sol model is integrated into Arena evaluation platforms for testing.

## 🚀 Availability
- Accessible to users with a paid OpenAI subscription.
- Available via the public API for developers.

## 💡 Why it matters
- Restoring reliable visual task performance improves utility for applications that rely on image understanding.
- A lower‑cost, high‑performance Sol variant gives developers a cost‑effective option for code‑related workloads.
- Integration with evaluation platforms enables systematic performance testing and benchmarking.
