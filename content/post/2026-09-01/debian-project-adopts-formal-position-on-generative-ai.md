# Debian Project Adopts Formal Position on Generative AI

The Debian Project has voted to adopt a formal position on the use of generative AI within the project.

## 📜 Overview
The general resolution titled "Responsible Use of Generative AI" won out.

## 🤖 Key Details
*   **Resolution Title:** "Responsible Use of Generative AI"
*   **Subject:** The use of generative AI within the project.
