# Graham Dumpleton releases Wrapture library for Python tracing and testing

Graham Dumpleton, creator of wrapt and mod_wsgi, has released a new project called Wrapture. The library extends monkeypatching concepts to provide a unified approach for testing and tracing within Python applications.

## 🔍 Overview
Wrapture is a tool designed to wrap functions or methods, allowing developers to trace access or override return values. It serves as an alternative to unittest.mock and facilitates tracing in existing projects.

## 🧩 How it works
- Enables function and method wrapping for tracing and value overriding.
- Provides support for OpenTelemetry.
- Includes a configuration-based mechanism for adding tracing to existing Python projects.
- Supports various testing patterns for complex call chains, such as an OrderService calling a Gateway.

## 💡 Why it matters
Wrapture represents a shift in development methodology for the creator. It is an agent-driven project where every line of code and documentation was written by an AI assistant under the direction of the author. The author notes that while the AI produced the output, the design was engineered specifically based on his long experience in this area of Python.

## 🚀 Availability
Wrapture is a young project, currently a few weeks old.
