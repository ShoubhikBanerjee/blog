# Atos and AWS partner to upskill 400 engineers in agentic AI development

Atos recently completed an intensive upskilling initiative for 400 engineers focused on practical agentic AI development through a partnership with AWS.

## 🔍 Overview
Atos addressed the challenge of building real-world agentic AI capability beyond theoretical knowledge by partnering with AWS in 2026. They ran a three-day competitive event using AWS AI League and Workshop Studio, enabling engineers to progress from foundational skills to deploying multi-agent systems with pathfinding, guardrails, memory, and fine-tuned models.

## 🧩 How it worked
Engineers participated in a gamified challenge where they built autonomous AI agents to navigate a dungeon maze. Agents had to:
- Find paths through maps
- Solve tile challenges
- Avoid traps
- Reach treasure within time/life limits

Scoring combined performance (correct answers, coin collection, map completion) and efficiency (concise responses, life retention). Teams competed on a live leaderboard.

## ⚙️ Key details
- **Participant experience levels**:
  5% no prior knowledge, 25% basic awareness, 50% theoretical understanding (no hands-on), 20% practical experience.
- **Event structure**:
  - 2-hour kick-off workshop
  - Daily 1-hour office hours
  - 1-hour finale for top 3 teams
- **AWS services used**:
  Amazon Bedrock, Bedrock AgentCore, AWS Lambda, Kiro, SageMaker.

## 🧱 Core components
Engineers utilized specialized agent modules with distinct capabilities:

| Component       | Function                                  | AWS Services Used                          |
|-----------------|-------------------------------------------|--------------------------------------------|
| Violent Violet  | AI safety/content filtering               | Amazon Bedrock Guardrails                  |
| Blue Brain      | Code generation/execution                 | AWS Lambda, AgentCore Code Interpreter     |
| Memento         | Context retention                         | AgentCore Memory                           |
| Dark Prophet    | Web information retrieval                 | AWS Lambda, AgentCore Code Interpreter     |
| Bonehead        | Token-efficient general knowledge         | Amazon Bedrock (prompt engineering)        |
| Healthcare API  | Structured data extraction                | Amazon Bedrock (prompt engineering)        |
| Keys & Doors    | Context retention                         | AgentCore Memory                           |
| Spikes & Coins  | Pathfinding/risk assessment               | AWS Lambda                                 |

## 💡 Why it matters
This initiative demonstrates large-scale practical upskilling in agentic AI using cloud-native tools. Engineers gained immediately applicable skills through competitive hands-on development, with all solutions built on production-ready AWS services. The event format required minimal setup while delivering measurable capability advancement aligned with Atos's strategic commitment to Sovereign Agentic AI Studios.
