# Anthropic donates Agent Skills standard to Agentic AI Foundation

On 22 October 2026 Anthropic announced that it is donating its Agent Skills standard to the Agentic AI Foundation (AAIF), which resides under the Linux Foundation.

## 🔍 Overview
- Anthropic today released a news post confirming the donation.
- The donation moves the Agent Skills specification to a neutral, community‑driven body.

## 🤝 Donation Details
- The standard is being handed to the Agentic AI Foundation, the organization Anthropic co‑founded with Block and OpenAI last year.
- AAIF also hosts the Model Context Protocol (MCP), which Anthropic donated earlier.
- Anthropic’s statement: “We’re committed to keeping Agent Skills open, community‑driven, and vendor‑neutral.”

## 📜 Open‑Standard Commitment
- Anthropic first described Agent Skills as an **open standard** in December 2025.
- The same blog author verified the donation intent by querying Claude through the `datasette‑mcp` plugin.

## 🏛️ Governance
- AAIF operates under the Linux Foundation, providing a vendor‑neutral home for specifications like Agent Skills and MCP.
- Anthropic expects the standard to reside permanently within AAIF, “the new home of the MCP specification.”
