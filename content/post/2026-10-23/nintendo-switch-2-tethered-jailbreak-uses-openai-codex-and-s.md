# Nintendo Switch 2 Tethered Jailbreak Uses OpenAI Codex and SmileBASIC 4

A Nintendo Switch 2 console has been jailbroken, and a modder demonstrated a custom Mario Kart World with new playable characters using a software‑only, tethered exploit that leverages an older game and OpenAI’s Codex.

## 🔍 Overview
- The Switch 2 jailbreak is software‑only and tethered, meaning it must be launched from a game each time the console powers on.
- A modder ran a custom version of Mario Kart World featuring Cinnamoroll, the red Angry Bird, Peter Griffin, and Steve from Minecraft.
- The exploit was created with the assistance of OpenAI’s Codex, referred to as the “ns2jb” jailbreak.
- The exploit is built around the game **SmileBASIC 4**, which lets users program and play games (though another modder says the title is “not strictly needed”).

## 🧩 How it Works
- An older game (SmileBASIC 4) is used as the launch point for the jailbreak.
- OpenAI Codex contributed code that enables the “ns2jb” jailbreak.
- Because the jailbreak is tethered, the user must run it from the game every time the console is turned on.
- The method does not modify hardware; it operates entirely in software.

## ⚙️ Key Details
- **Software‑only**: No hardware changes are required.
- **Tethered**: Must be executed from a game on each boot.
- **Required game**: SmileBASIC 4 (though its necessity is disputed by another modder).
- **AI involvement**: OpenAI’s Codex was used to develop the jailbreak code.
