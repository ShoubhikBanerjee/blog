# Amazon Quick Announced as HIPAA-Eligible Service for Healthcare Data

Amazon Quick is now a HIPAA-eligible service, allowing it to be used to process, store, and transmit Protected Health Information (PHI) under a signed AWS Business Associate Addendum (BAA).

## 🧩 How it works
Amazon Quick utilizes chat agents that operate across different data types:

* **Unstructured content**: Includes appeals letters and clinical notes.
* **Structured data**: Includes member records and claims.

These agents can retrieve data from both source types, complete multi-step tasks for users, and call other systems via connectors. Connectors are pre-built integrations for external systems, including:

| Connector | Integration Target |
| :--- | :--- |
| Slack | External System |
| Microsoft Outlook | External System |
| Salesforce | External System |
| Atlassian Jira | External System |
| Microsoft SharePoint | External System |

Users can also integrate custom tools through the Model Context Protocol (MCP). To maintain security, only connectors authorized within an organization are visible.

## ⚙️ Key details
Amazon Quick provides several administrative and security controls:
* ACL-aware retrieval
* Chat and feedback logging
* Controls over chat agent permissions

The service is assessed by third-party auditors under compliance programs including ISO, SOC, PCI DSS, FedRAMP, and HIPAA. This eligibility extends to the desktop, mobile, and web clients of Amazon Quick, subject to user configuration and the shared responsibility model.

## 💡 Why it matters
Under the Health Insurance Portability and Accountability Act (HIPAA), any software that touches PHI—information identifying a person relating to their health, care, or payment—must be secured and audited. 

A HIPAA-compliant deployment is achieved through a combination of:
* An eligible service such as Amazon Quick
* A signed BAA
* Correct configuration, governance, and user safeguards

AWS acts as a business associate for a specific account after the AWS BAA is accepted through AWS Artifact, provided HIPAA-eligible services like Amazon Quick are used to process PHI.
