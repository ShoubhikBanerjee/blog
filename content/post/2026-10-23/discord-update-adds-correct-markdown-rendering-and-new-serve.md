# Discord Update Adds Correct Markdown Rendering and New Server‑Organization Feature

Discord released a new update today that fixes Markdown preview rendering and adds a few usability tweaks.

## 📢 Overview
The company says the update "has a big improvement for Markdown previews: they should now render correctly instead of with “a bunch of symbols,”" and that Markdown files now "render ‘all nice and neat’ thanks to a new update."

## 🛠️ New Markdown Rendering
- "Discord’s latest update released today has a big improvement for Markdown previews: they should now render correctly instead of with “a bunch of symbols,” according to the company."
- "Markdown files in Discord now render ‘all nice and neat’ thanks to a new update."
- "When you upload a Markdown (.md) file, you’ll now see the file rendered all nice and neat and pretty instead of with a bunch of symbols,” Discord says."
- "This includes tables, formatting, all that good stuff."
- "Totally great for when you’re doing a casual Sunday-night sharing READMEs with your friends."

| Feature | Detail |
|---|---|
| Markdown preview rendering | “now render correctly instead of with a bunch of symbols” |
| Server/channel organization | “new ‘Move to…’ feature accessible by right‑clicking the icon on the sidebar” |
| Nitro file size limit | “upload files as large as 1 GB” |

## 📂 Organization Tools
Discord says its new update also lets you organize servers and channels "by right‑clicking the icon on the sidebar and using a new “Move to…” feature."

## 📁 Larger Upload Limits
Discord Nitro members are also now able to "upload files as large as 1GB."

## 🤖 Why it matters for AI
"LLMs and AI agents often rely on Markdown files for instructions and context, so these improved previews could be helpful for people sharing information about AI projects on the platform."

## 📄 Related Markdown Improvements
Google has also improved its Markdown support, as it recently started "letting users edit Markdown files directly in Docs without having to convert the files to the Docs format."
