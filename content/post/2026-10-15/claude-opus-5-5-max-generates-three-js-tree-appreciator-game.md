# Claude Opus 5.5 Max Generates Three.js “Tree Appreciator” Game in 3 Hours

On 14 October 2026 I ran another game experiment with Claude, this time using the default Claude iPhone app in chat mode (not Claude Code mode). I prompted Claude Opus 5.5 Max with a detailed request to build a three‑js game called **Tree appreciator**.

## 🔍 Overview
- The task: create a three‑js game that shows two algorithmically generated trees and centres gameplay on appreciating their differences.
- Prompt instruction: *“Think hard about how to make sure it is both fun and beautiful.”*
- Observation: explicitly telling Opus 5.5 “make sure it is fun” worked “uncomfortably well.”

## 🧩 How it worked
- **Interface**: default Claude iPhone app, chat mode.
- **Model**: Claude Opus 5.5 Max.
- **Prompt** included the game concept, name, and a request for fun and beauty.

## ⏱️ Timing & Output
- Claude processed the request for **3 hours 7 minutes**.
- Result: a cosy spot‑the‑difference game featuring:
  - two algorithmically generated trees,
  - music,
  - animation,
  - achievements.
- The final product was described as “quite compelling to play.”

## 🎮 Game Details
- **Title**: *Tree appreciator*.
- **Mechanic**: Players compare two generated trees and appreciate visual differences.
- **Presentation**: Includes musical background, animated transitions, and achievement tracking.

## 💡 Why it matters
- Demonstrates that a language model (Claude Opus 5.5 Max) can translate a natural‑language game design brief into a functional three‑js prototype within a few hours.
- Shows that simple prompts like “make sure it is fun” can significantly influence the creative output of the model.
