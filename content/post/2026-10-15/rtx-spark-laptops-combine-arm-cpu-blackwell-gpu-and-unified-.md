# RTX Spark laptops combine Arm CPU, Blackwell GPU and unified memory for AI agents

Microsoft and Nvidia held a launch party for the first wave of RTX Spark laptops last week in San Francisco, where a new wave of AI PCs took center stage amid a packed crowd and a lively hands‑on area.

## 🔍 Overview
- RTX Spark is a new class of Windows laptops that pairs an Arm‑based CPU with Nvidia’s Blackwell GPU and a unified‑memory architecture.
- The design enables powerful AI models to run locally on a laptop, making the experience of setting up an AI agent quick and easy.

## 🧩 Architecture & Core Tech
- The chips inside RTX Spark laptops are Arm‑based, instead of the traditional x64 architecture used by AMD and Intel.
- Microsoft’s Prism emulator is used for apps that don’t have a native Arm version.
- "Each core is different. How we translate x64 to that core needs to be highly optimized, and for RTX Spark we’ve done a lot of work to optimize for its microarchitecture." – Peter Dawoud

## ⚙️ Features
- **Get Started experience**: "When users get into Windows for the first time, they’ll see a new Get Started experience that will launch on an RTX Spark laptop that allows them to find the agent they want, get started with that agent, install it, and get to that agent in only two clicks," says Peter Dawoud.
- **Agent installation**: Agents can be installed and updated through the Windows Store, eliminating the need to track dependencies.
- **First‑party agents**: Hermes, Perplexity, and OpenClaw are the first three officially supported agents at launch.
- **Unified memory**: Microsoft’s Surface Laptop Ultra can ship with up to 128 GB of unified memory, making it possible to load huge models into memory.
- "We made incredible investments in Unified Memory Architecture to enable you to load as much as possible into the 128GB," says Dawoud.
- Memory optimizations cover power, performance, battery life, and allow a game to run while rendering a video in the background.
- **Memory slider**: A slider in Nvidia’s Windows app lets users manually adjust how much of the unified memory is dedicated to the GPU side. This is useful on RTX Spark laptops with 24 GB or 32 GB of memory to balance more to the GPU for particular apps and games.
- **Gaming capability**: While RTX Spark laptops aren’t marketed as gaming machines, they can run the latest AAA titles. Anti‑cheat support was secured as a first step for gaming on Windows on Arm.

## 🚀 Availability
The first wave of RTX Spark laptops was unveiled at the San Francisco launch event. Microsoft and Nvidia are continuing to work with additional anti‑cheat providers to bring more games to the platform in the future.

## 💡 Why it matters
- Combining an Arm CPU, Blackwell GPU, and up to 128 GB of unified memory lets laptops load and run large AI models locally.
- The streamlined Windows Get Started flow reduces the steps needed to find, install, and launch an AI agent to just two clicks.
- Unified‑memory tuning and a manual slider give users flexibility to balance performance for AI workloads and gaming on the same device.
