# nxtedition to Showcase AI Agent-Driven End-to-End Production Pipelines at IBC2026

At IBC2026, nxtedition will demonstrate how AI agents can manage an end-to-end production pipeline inside a single environment. This system is designed to remove mechanical steps between editorial decisions rather than automating the decisions themselves, ensuring that journalists and directors maintain full control over the output.

## 🔍 Overview
Unlike typical newsroom AI that simply produces text for hand-off, nxtedition’s agents have a full backend of tools available to them. These agents can use:
*   Storage and compute resources
*   Transcoding and newsroom systems
*   Media and production asset management
*   Rundowns and gallery control
*   Publishing tools

## 🧩 How it works
In the upcoming demonstration, the system processes incoming wire copy from Reuters through an automated workflow. An AI agent builds the story, retrieves matching video assets, applies graphics templates, and generates a complete rundown. This includes prompter text, VTs, and graphics. The entire process—from recording in the studio to driving the live gallery—takes place without exporting data to external applications.

## ⚙️ Key details
The technology is already being utilized by Collective Newsroom for BBC India, a project that is a finalist in the IBC2026 Innovation Awards. 

| Feature | Details |
| :--- | :--- |
| Deployment | On-premise GPU hardware, hybrid, or model-agnostic external calls |
| Connectivity | Agent tools exposed over MCP for external AI assistant integration |
| Language Support | Transcription and translation for nine languages on broadcaster hardware |
| Oversight | All steps visible in story-centric planning and rundowns for manual editing |

## 💡 Why it matters
"AI needs a body," stated Adam Leah, Creative Director at nxtedition. By integrating the intelligence with the actual production tools, the system reduces the delay between ingestion and usage. Live transcription subtitles and tags content as it is ingested, flagging sections for automatic clipping on the broadcaster’s own GPUs. This approach addresses accuracy concerns by making every action the AI takes transparent and editable within the existing planning tools used by producers and directors.

## 🚀 Availability
Visitors can see the demonstration at the nxtedition stand 7.A02 at IBC2026, RAI Amsterdam, from 11-14 September 2026. More information is available at nxtedition.com.
