# Microsoft Announces Eight Updates to Microsoft 365 Admin Center Collaboration Tools

Microsoft has introduced eight new updates to the Microsoft 365 Admin Center focused on its collaboration tools suite.

## ⚙️ Key details

The following features and updates have been added to Microsoft 365 collaboration tools:

| Feature | Description |
| :--- | :--- |
| SharePoint News | Ability to cross-post to Viva Engage |
| Teams Workflows | A new form trigger |
| Viva Engage | Reduced email notifications |
| Teams | Lobby visibility updates |
| PowerPoint Copilot | Two new skills |
| Teams | Centralized channel notification settings |
| Viva Engage | Entra permission requirements |
| Teams | Ability to temporarily pause notifications |
