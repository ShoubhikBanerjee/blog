# ComfyUI-Easy-Use Adds Support for Anima and Krea2 Models

ComfyUI-Easy-Use, a custom node integration package for ComfyUI built upon TinyTerraNodes, has added support for Anima and Krea2 diffusion models. The update introduces new nodes and security fixes while enhancing workflow efficiency for various Stable Diffusion model variants.

## 🧩 How it works

The package integrates and optimizes popular custom nodes to create faster and more convenient workflows, restoring a smooth image production experience similar to traditional Stable Diffusion. Key functional updates include:

- **Anima and Krea2 Support**: Enabled via `easy diffusionModelLoader` and `easy XYInputs: DiffusionModel`.
- **Loader Requirements**: The loader requires an explicit text encoder and VAE selection.
- **Noise Injection**: Achieved in latent space using `easy latentNoisy` or `easy preSamplingNoiseIn` nodes.
- **Prompt Mode**: The loader enables A1111 prompt mode, reproducing images nearly identical to those generated by webui.

## ⚙️ Key details

Recent additions and fixes to the ComfyUI-Easy-Use package include:

| Feature / Update | Description |
| :--- | :--- |
| **New Nodes** | Added `easy PassOrNone` with optional default input and matching types; added `easy tableEditor` for data editing. |
| **Model Support** | Supports SD1.x, SD2.x, SDXL, SVD, Zero123, Stable Cascade, Layer Diffuse, InstantID, SD3, Kolors, Flux, Anima, and Krea2. |
| **Security Fixes** | Fixed style preview path traversal; restricted model downloads to public HTTP(S) addresses; fixed `easy saveText` to confine outputs to the directory. |
| **Performance** | Use native `VAEDecodeTiled` for tiled decode with Qwen Image VAE support. |
| **UI Updates** | Fixed `easy imageChooser` inactivity after frontend updates; fixed disabled Alt+1–9 template shortcuts blocking browser shortcuts. |

## 🚀 Availability

Users can install ComfyUI-Easy-Use by cloning the repository into the `custom_nodes` directory and installing the requirements. For specific integrations like InstantID, the `ComfyUI_InstantID` package must be present. Layer Diffuse usage may require running `pip install -r requirements.txt` for dependencies.
