# ROS 2 Packages Integrate llama.cpp for LLM and VLM Support

A new set of ROS 2 packages has been released to integrate the llama.cpp library into ROS 2 environments. This repository allows developers to incorporate llama.cpp's optimization capabilities into ROS 2 projects to run various machine learning models.

## 🧩 How it works
The `llama_ros` packages enable the execution of GGUF-based models within a ROS 2 framework. The supported model types include:
- Large Language Models (LLMs)
- Vision-Language Models (VLMs)
- Audio-language models
- Embedding models
- Reranking models

## ⚙️ Key details
Beyond basic model execution, the packages provide specific interfaces and features derived from llama.cpp:
- An OpenAI-compatible chat completions interface that supports tool calling, reasoning, and streaming.
- Speculative decoding.
- Support for decision models, including OpenJEV, Lev, Kev, Nimble, Laya, and Clef.
- Grammar-based generation (GBNF).
- Real-time modification of LoRAs.
