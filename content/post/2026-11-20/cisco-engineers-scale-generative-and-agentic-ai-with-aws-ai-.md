# Cisco engineers scale generative and agentic AI with AWS AI League

Cisco engineers are scaling their use of generative and agentic AI through the AWS AI League competition.

## 🔍 Overview
- Cisco is adopting generative and agentic AI to change how its engineers build software.
- The hard part is no longer access to the technology.
- Recorded sessions and slide decks rarely close that gap.
- Engineers learn fastest when they build something real, see it fail, fix it, and try again.

## 🛠️ How it works
- **Learn** – A hands‑on, 2‑hour workshop led by AWS experts introduces the tools and the challenge.
- **Build** – Participants experiment at their own pace, submit to a live leaderboard, and receive real‑time feedback from an automated evaluator.
- **Compete** – Top finalists take the stage in a live, game‑show‑style grand finale.

## 🎮 Competition Highlights
- 2025: Hemanth V, a Cisco software engineer, went from an internal Cisco event to being crowned the first AWS AI League Champion at AWS re:Invent 2025.
- 2026: 1,200 Cisco engineers competed in an AWS AI League tournament at Cisco Transformation Fest 4.0.
- Winner Nishanth Aluhonnu earned a full event pass to AWS re:Invent 2026 in Las Vegas.

## 🤖 Challenges
- **Agentic AI challenge** – Participants build agents with Amazon Bedrock AgentCore. The agents move through a maze‑like grid toward a treasure chest.
- **Model customization challenge** – Participants fine‑tune models in Amazon SageMaker Studio using the latest training recipes.

### Challenge tasks
| Challenge | Real‑world task |
|---|---|
| Handling inappropriate content | Handling inappropriate content |
| Running code | Running code |
| Retrieving information from the web | Retrieving information from the web |
| Extracting structured data | Extracting structured data |

## 📦 Cisco Use Cases
- **Cisco SD‑WAN** – Controller architecture runs on AWS and serves customers globally as a SaaS application.
- **Cisco Cloud Control** – Cloud‑native, AI‑powered application integrated with AWS services for security, networking, observability, and collaboration.
- **Cisco AI Defense** – Uses Amazon Bedrock and Amazon SageMaker AI to embed AI governance and guardrails across the Cisco portfolio.
- Recent co‑innovation: SD‑WAN fabric on demand across the AWS backbone.

## 💡 Why it matters
- AWS AI League helps organizations build advanced AI skills through competition.
- The program moves engineers from watching demos to confidently building with generative and agentic AI.
- The partnership is described as "a true engineering partnership" rather than a vendor relationship.
