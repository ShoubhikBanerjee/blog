# Google Gemini for macOS adds computer use for multi-step tasks

Google's Gemini app for macOS now includes a computer use feature that enables the AI assistant to perform multi-step tasks across local files, desktop applications, and the web.

## 🔍 Overview
- Gemini can now help users "get multi-step tasks done across your local files, desktop apps, and the web"
- Google suggests the feature is useful for speeding up workflows, filling in forms, making presentations, and listing items for sale
- The company says Gemini can better help with filling in forms and creative workflows with this new capability

## 🧩 How it works
- Users decide which apps Gemini can access
- A background window shows a live preview in the chat so users can follow along as Gemini works

## ⚙️ Key details
- Computer use enables interaction with local files, desktop apps, and web content
- Supported use cases include form filling, presentation creation, sales listings, and general workflow acceleration
- The feature operates within user-granted app permissions

## 🚀 Availability
- Rolling out now in English for users in the US
- Settings preview appeared with this week's macOS 27.3 beta

## 💡 Why it matters
- Google is introducing computer use ahead of Apple launching new restrictions for apps requesting "full disk access" on Mac
- Apple's planned restrictions cite potential risks from AI agents with computer use capabilities
