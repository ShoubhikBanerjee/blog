# Activepieces Updates Open Source AI Automation and MCP Toolkit

Activepieces has introduced an all-in-one AI automation platform featuring an extensible, type-safe pieces framework written in TypeScript. The platform offers over 280 open-source pieces available on npmjs.com, with 60% contributed by the community. When contributed, these pieces automatically become available as Model Context Protocol (MCP) servers for use with LLMs through Claude Desktop, Cursor, or Windsurf.

## 🛠️ Key Capabilities

- **AI-First Design**: Native AI pieces allow users to experiment with various providers or create custom agents using the AI SDK.
- **Developer Experience**: Pieces are npm packages written in TypeScript with support for hot reloading during local development.
- **Flow Control & Logic**: Includes loops, branches, auto retries, HTTP requests, and code execution with NPM support, alongside an ASK AI in Code Piece feature for data cleaning.
- **Human in the Loop**: Execution can be delayed for a period of time, or configured to require approval.
- **Human Input Interfaces**: Built-in support for chat and form interface triggers.
- **Enterprise & Security**: Self-hosted and network-gapped for maximum security, allowing developers to set up tools for organizational use via a no-coder builder.
- **Additional Features**: Fully versioned flows, language translations, and customizable templates.

## 🌐 Ecosystem and Availability

- **Integrations**: Supports integrations with Google Sheets, OpenAI, Discord, RSS, and over 200 other services.
- **Open Source Licensing**: The Community Edition is open source under the MIT license, while enterprise features are released under a commercial license.
- **Contributions**: Community contributions are supported and published directly to npmjs.com upon contribution.
