# Microsoft Begins Automatic Windows 11 26H2 Upgrade Rollout

Starting this week, Microsoft has begun automatically upgrading eligible devices that aren't managed by an IT department to Windows 11 26H2.

## 🔍 Overview

*   Windows 11 26H2 is also known as the Windows 11 2026 Update.
*   It contains all the recently announced features in Windows 11, versions 25H2 and 24H2.

## ⚙️ Key details

*   It is delivered using servicing technology, providing a fast installation experience.
*   Windows 11 26H2 became generally available in September 2026 as an enablement package.
*   It is scheduled to reach end of support in October 2029.

## 🚀 Availability

*   Automatic upgrade is available for personal and non-managed business devices running Windows 11 24H2 and 25H2.
*   Automatic delivery is being gradually expanded, starting with devices running Windows 11, versions 24H2 and 25H2, that are not managed by IT departments.
*   Manual installation can be performed via Settings > Windows Update by checking for Windows updates.

## 💡 Why it matters

*   As the rollout progresses, more Windows 11 devices will upgrade automatically without users having to check for updates manually.
*   Since late October 2026, all devices eligible to run Windows 11 have been able to get version 26H2 by manually checking for updates.
