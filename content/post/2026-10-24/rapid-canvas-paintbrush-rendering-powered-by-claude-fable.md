# Rapid Canvas Paintbrush Rendering Powered by Claude Fable

On 23rd October 2026 a new web‑based artifact was released that opens a photo and, within a few seconds, paints a version of that photo using a canvas element and a simulated paintbrush. The work builds on an earlier experiment that used Claude Fable to simulate a watercolor illustration with P5.js.

## 🎯 Overview
- Opens a user‑selected photo.
- Renders a painted version in a few seconds.
- Uses an HTML canvas element.
- Simulates brush strokes programmatically.

## 🛠️ How it works
- The artifact leverages Claude Fable’s ability to generate watercolor‑style imagery.
- P5.js is used to drive the canvas drawing logic.
- The process is fast enough to appear almost instant to the user.
