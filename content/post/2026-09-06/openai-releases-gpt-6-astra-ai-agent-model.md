# OpenAI Releases GPT-6 Astra AI Agent Model

OpenAI has released its GPT-6 Astra model, marking a transition from a simple answer engine to a fully functional AI agent.

## ⚙️ Key details
The GPT-6 Astra model introduces the following capabilities:
* Ability to operate computers
* Ability to browse the web
* Shift from acting as an Answer Engine to a fully capable AI Agent
