# Reply Polska Expands AI Engineering Capabilities with New Agentic Systems Role

## 🔍 Overview
Reply Polska is seeking an AI Engineer to specialize in the development of agentic systems, focusing on integrating LLMs into cloud-native enterprise applications. The position is based in Katowice with a hybrid work model.

## ⚙️ Key details
- Role: AI Engineer - Agentic Systems
- Salary: 9,000 – 13,000 PLN brutto monthly (UoP)
- Location: Katowice, Poland
- Work Mode: Hybrid (1 day per month in office)
- Benefits: 550 PLN monthly budget
- Offer validity: Until 09.10.2026

## 🛠️ Technical Requirements
- Programming: Proficiency in Python and/or JavaScript/TypeScript.
- AI Skills: LLMs, NLP, embeddings, RAG, prompt engineering, structured generation, and agentic workflows.
- Frameworks: Experience with LangGraph, Microsoft Agent Framework, LangChain, or LlamaIndex.
- Cloud: Familiarity with Azure and AWS services, including Azure OpenAI, Azure AI Foundry, and AWS Bedrock.
- Education: Bachelor’s or Master’s degree in Computer Science, Artificial Intelligence, Data Science, Software Engineering, or a related field.

## 📋 Core Responsibilities
| Task | Description |
| :--- | :--- |
| System Design | Design and build agentic AI systems using Azure OpenAI and AWS Bedrock |
| Workflow Development | Develop applications and AI workflows integrating LLMs into cloud-native apps |
| Orchestration | Build and orchestrate AI agents using modern frameworks |

## 🚀 Availability
- The position is open for applications with an immediate start date (ASAP).
