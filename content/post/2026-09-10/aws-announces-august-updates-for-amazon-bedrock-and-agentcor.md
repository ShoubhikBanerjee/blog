# AWS Announces August Updates for Amazon Bedrock and AgentCore

AWS has introduced a series of updates to Amazon Bedrock and AgentCore, expanding the infrastructure and tools available for building, scaling, and managing agentic AI applications.

## 🔍 Overview
Amazon Bedrock, which now serves over 225,000 active customers, has received new capabilities designed to support agents that require extended reasoning, long-term productivity, and complex task management across digital and physical systems.

## 🧩 How it works
AgentCore provides a foundation for building and optimizing agents using various frameworks and models. The new runtime instances allow agents to operate on dedicated Amazon EC2 compute, with support for sessions lasting up to 14 days. Developers can now utilize temporal policies to manage agent sequences and data freshness, while rate limiting controls help manage resource consumption.

## ⚙️ Key details
| Feature | Description |
| :--- | :--- |
| GPT-5.6 Sol, Terra, Luna | Now support million-token context windows and prompt caching. |
| Web Search | Allows models to access real-time information from public websites and provide citations. |
| Daybreak Red | Supports advanced tasks like vulnerability research and exploit reproduction. |
| Daybreak Blue | Supports defensive tasks such as vulnerability discovery and incident response. |
| AgentCore Payments | Enables agents to access and pay for APIs and resources with spending limits. |

## 🚀 Availability
AgentCore has expanded its reach to the US West (N. California) and Asia Pacific (Hyderabad) regions. Cross-Region inference is now available for the GPT-5.6 model family across more than 25 AWS Regions, with both Global and Geo profile options for data-processing requirements.

## 💡 Why it matters
These updates offer organizations greater visibility into AI spending through IAM principal cost allocation and AWS Cost Anomaly Detection. Furthermore, open-source initiatives like the Strands Agent Harness SDK provide additional flexibility for deploying agents across various environments.
