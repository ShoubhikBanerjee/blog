# Datasette-cluster-map plugin updated to version 0.19

On 13th November 2026, version 0.19 of the datasette-cluster-map plugin was released. This tool provides mapping capabilities for datasets containing latitude and longitude columns.

## ⚙️ Key details

*   Compatibility: Updated to support Datasette 1.0a42.
*   Dependencies: Now relies on datasette-leaflet to manage OpenStreetMap tile requests, specifically ensuring they include a referrer header.
*   Functionality: Displays a map for any data with latitude and longitude columns.
