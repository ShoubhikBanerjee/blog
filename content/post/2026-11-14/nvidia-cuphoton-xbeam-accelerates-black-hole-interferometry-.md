# NVIDIA cuPhoton.xBeam Accelerates Black Hole Interferometry Processing

NVIDIA has introduced cuPhoton.xBeam, a GPU-based FX correlator within the cuPhoton toolkit designed to accelerate the processing of radio astronomical data used to image black holes. Developed in collaboration with the Harvard-Smithsonian Center for Astrophysics and the MIT Haystack Observatory, this technology addresses the significant computational demands of very-long-baseline interferometry (VLBI).

## 🔍 Overview
Imaging distant, small-scale black holes like M87* requires capturing radio emissions from gas outside the event horizon using globally distributed telescope stations. The Event Horizon Telescope (EHT) links these stations to record high-speed voltage streams, producing petabytes of data that must be synchronized and correlated to reconstruct images.

## 🧩 How it works
Interferometry involves correlating signals from pairs of telescopes to produce complex visibilities, which sample Fourier components of the sky’s brightness. The cuPhoton.xBeam component organizes these radio signals for parallel processing on GPUs:

| Feature | Function |
| :--- | :--- |
| Data Indexing | Indexes VDIF frames by timestamp, thread, and physical location via .vdix sidecars |
| Correlation | Correlates signals between telescope pairs to produce complex visibilities |
| Data Tracking | Explicitly tracks missing or invalid data without rewriting recordings |

## ⚙️ Key details
Performance testing demonstrated significant improvements in data processing speed:

* Execution: Processed a 10 TB dataset in 70 seconds on an NVIDIA Vera Rubin NVL72 system with 64 GPUs.
* Efficiency: Achieved a 460x speedup compared to an x86 CPU baseline of 31,992 seconds.
* Infrastructure: Utilizes GPUDirect Storage (GDS) in compatibility mode for high-speed data ingestion.

## 💡 Why it matters
Future initiatives, such as the next-generation EHT (ngEHT) and the proposed Black Hole Explorer (BHEX), aim to improve image quality and measure the photon ring near a black hole's shadow. The current cuPhoton.xBeam tool provides a scalable pipeline to handle the massive data rates generated by these observation arrays, enabling researchers to construct 3D gas models from visibility data.
