# Meta's Muse AI Exposes Cloud Filesystem to Users

Recent developments show that Meta’s Muse now allows users to access and download its entire filesystem, a capability described as "intended behavior."

## 🧩 How it works
Muse utilizes an architecture that differs fundamentally from other AI platforms like Gemini and ChatGPT. Its structure is closer to running OpenClaw on a local machine, but the machine is hosted in the cloud. Key architectural details include:

* Each user is provided with their own persistent Linux VM in Meta’s cloud.
* The Muse Secure VM functions as the user's own computer in the cloud.
* Users can operate this Linux box to install software, write and compile code, and use a browser to surf the web.

## ⚙️ Key details
While Muse previously only offered a text file download of its directory tree, recent updates have expanded this access:

* Muse now provides a clickable file browser with root access when asked to see its filesystem.
* Muse will zip up the root directory for download, providing "the full filesystem listings" with "all with secrets stripped out."

## 💡 Why it matters
Muse is identified as the first consumer-accessible agentic AI system. Due to these capabilities, there are concerns regarding how powerful and dangerous the system is, particularly when running on a Mac.
