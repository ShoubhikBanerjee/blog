# OpenAI Releases GPT-6 Astra with Advanced Computer Use and Graphical Capabilities

OpenAI has released GPT-6 Astra, a new model that significantly improves upon its predecessor, GPT-5.6, across multiple categories. While the model shows progress in writing, math, and coding, it is particularly distinguished by its graphical capabilities and its ability to interact with local computer interfaces.

## 🔍 Overview
GPT-6 Astra represents a major step forward, outperforming the previous GPT-5.6 model in nearly all evaluated areas. It is particularly noted for:
* Leapfrogging GPT-5.6 in math, coding, and writing.
* Exceptional performance in image and rendering tasks.
* The ability to operate local software through the Codex/ChatGPT app.

## ⚙️ Key details
Independent evaluations from Artificial Analysis provide a look at the model's performance relative to existing benchmarks. GPT-6 Astra achieved a 99.9% score on the ARC-AGI-3 benchmark, which measures logic puzzles and generalization, while its predecessor GPT-5.6 Sol reached 7.8%.

| Benchmark or Index | Details |
| :--- | :--- |
| ARC-AGI-3 | Measures logic puzzles and generalization; Astra achieved 99.9%. |
| Coding Agent Index v1.4 | A blend of agentic coding tasks where Astra is currently at the frontier. |
| Intelligence Index v4.2 | A general index blending various task types, including Terminal-Bench v2.1. |
| Computer Use | A capability where the model interacts with GUIs via the mouse cursor on local machines. |

## 🧩 How it works
Evaluation accuracy depends on the specific harness used during testing. While models are often optimized for a primary harness during training, independent benchmarks use various setups to provide more trustworthy results:
* **Stirrup:** An open-source, minimal harness used by GDPval-AA and AA-Briefcase.
* **Terminus 2:** The harness used for Terminal-Bench v2.1 within the Intelligence Index.
* **τ-Bench:** The harness utilized for τ³-Banking evaluations.

## 💡 Why it matters
The model’s computer use capability allows it to operate software on a local machine, which is demonstrated through intuitive graphical tasks. Notable examples of this performance include:
* Modeling and rendering a 3D version of New York City in Blender.
* Conducting virtual open house tours.
* Using the mouse cursor to interact with a browser version of MS Paint to redraw images (demonstrated using Astra Medium and High variants).

While traditional LLM strengths include text-based tasks like writing and API usage, Astra's ability to navigate graphical user interfaces represents a maturing frontier in model capabilities.
