# OpenAI Launches ChatGPT Images 2.5 and Sketch Feature

OpenAI announced ChatGPT Images 2.5 on Tuesday, introducing updated image generation tools and a new feature called Sketch that allows users to use doodles as part of their prompts.

## 🧩 How it works

Users can now influence image generation through drawing and direct feedback:
* **Sketch:** By typing `@Sketch` into the chat box, a window appears where users can draw a doodle and then tell ChatGPT how to make an image based on that sketch.
* **Direct Comments:** Users can leave comments directly on specific parts of images to request changes, such as changing a cat's eyes from blue to green.

## ⚙️ Key details

OpenAI stated that ChatGPT Images 2.5 provides several improvements over Images 2.0:

| Feature | Improvement |
| :--- | :--- |
| Visual Quality | More natural lighting and richer textures |
| Instruction Following | Better at following editing instructions across multiple turns |
| Performance | Latency reduced by up to 50% compared with Images 2.0 |

## 🚀 Availability

ChatGPT Images 2.5 is currently available for the following users on desktop, mobile, and web:
* ChatGPT users
* ChatGPT Work users
* Codex users
