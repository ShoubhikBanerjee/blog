# OpenHands Cloud Deployment Helm Charts Released Under Polyform License

A repository containing Helm charts for installing OpenHands Cloud in Kubernetes clusters has been released. This software is licensed under the Polyform Free Trial License, rather than an open-source license, and has specific usage terms based on the duration of use.

## 🔍 Overview

The repository provides the official Helm charts necessary to install and run OpenHands Cloud within a self-hosted Kubernetes cluster. Notably, these identical charts are also utilized to power the public, official version of OpenHands Cloud, which is hosted at [app.all-hands.dev](https://app.all-hands.dev).

For users deploying the software, the repository outlines the following components:

| Component | License | Issue Tracking Location | Description / Instructions |
| :--- | :--- | :--- | :--- |
| **OpenHands Cloud App & Helm Charts** | Polyform Free Trial License (non-open source) | Current repository | Used for installing OpenHands Cloud in Kubernetes clusters; see `charts/openhands/README.md` for full instructions. |
| **Core OpenHands** | MIT License | Core OpenHands repository | The core OpenHands codebase. |

## ⚙️ Key details

* **Installation Methods:** While the Helm charts are available for self-hosting in Kubernetes, the preferred method of installing OpenHands Cloud is via Replicated.
* **Issue Reporting:** Issues should be filed according to the specific repository. Problems concerning the OpenHands Cloud app and the deployment Helm charts must be reported in the cloud repository, while issues with the core software belong in the core OpenHands repository.

## 🚀 Availability

The software in this repository is distributed under the Polyform Free Trial License, which limits free usage to a maximum of 30 days per calendar year. 

Users who wish to operate the software beyond this 30-day limit must acquire a commercial license by [contacting the team](https://www.all-hands.dev/contact).
