# OpenAI GPT-6 Astra Now Generally Available on Amazon Bedrock

OpenAI has announced the general availability of GPT-6 Astra, its most capable model to date, on the Amazon Bedrock inference engine.

## 🔍 Overview
GPT-6 Astra is designed for demanding tasks that require greater depth and judgment. It is built to enhance the capabilities of AI agents that automate complex workflows, analyze data, and write code at production scale.

## 💡 Why it matters
The model applies deeper reasoning to complex business decisions and produces professional-quality output aligned with organizational standards, templates, and voice. Key application examples include:

| Use Case | Capability |
| :--- | :--- |
| Financial Analysis | Reconciles conflicting data sources and identifies discrepancies that could alter recommendations. |
| Contract Review | Reviews hundreds of pages with a context window of up to 1 million input tokens to identify high-risk provisions. |
| Codebase Management | Investigates problems across large codebases, reasons through dependencies, and handles fixes from diagnosis through testing. |

## ⚙️ Key details
* **Interface Capabilities**: Advances computer and browser use, allowing the model to work across applications via software interfaces when connectors or APIs are unavailable.
* **Enterprise Integration**: New enterprise plugins for ChatGPT Work extend browser-use capabilities across common business applications.
* **Prompt Caching**: Supports both implicit and explicit prompt caching for workflows that reuse the same context, such as recurring document reviews. Explicit caching allows users to set cache breakpoints to reduce latency, cost, and repeated processing.

## 🛡️ Security and Governance
GPT-6 Astra is the first OpenAI model to reach a "Critical" classification for cybersecurity capability under the Preparedness Framework. Security measures include:
* **Real-time Safeguards**: Automated safeguards monitor for misuse and can pause or stop activity that exceeds defined boundaries within the Amazon Bedrock service boundary.
* **Infrastructure Protection**: Zero-operator access is enforced at the chip level, preventing AWS operators from accessing prompts and completions during inference.
* **Data Security**: Data is encrypted at rest and in transit, complemented by AWS controls for auditing model invocation and governing access.

## 🚀 Availability
Users can access GPT-6 Astra through the following methods:
* Direct calls via Amazon Bedrock APIs.
* Configuration of Codex or ChatGPT Work to use the model on Amazon Bedrock.
