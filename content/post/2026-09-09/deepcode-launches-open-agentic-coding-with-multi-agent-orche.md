# DeepCode Launches Open Agentic Coding with Multi-Agent Orchestration

DeepCode has introduced an open agentic coding system designed to advance code generation through the use of multi-agent systems. The development focuses on streamlining developer workflows through specialized agent architectures.

## 🧩 How it works
The system is built on a single Agent runtime and utilizes several core engineering components to manage code generation:
- Agent Harness
- Loop Engineering
- Multi-Agent Orchestration

## ⚙️ Key details
DeepCode provides two distinct interfaces for interacting with the Agent runtime. Both interfaces open the same local projects and session history:

| Interface | Primary Function |
| :--- | :--- |
| Interactive CLI | Terminal workflows |
| Tauri Desktop workbench | Visual Sessions, review, and settings |
