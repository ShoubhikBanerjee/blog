# CC Switch Launches as Cross-Platform Manager for AI Coding Agents

CC Switch is a newly released cross-platform desktop manager designed to configure and switch between various AI coding agents and tools. Built with Tauri 2, it supports Windows, macOS, and Linux environments.

## 🔍 Overview
CC Switch serves as an all-in-one manager for a variety of agentic tools and models, including:

| Tool | Description |
| :--- | :--- |
| Claude Code | AI coding assistant |
| Claude Desktop | AI desktop application |
| Codex | Coding agent |
| Gemini CLI | Command line interface |
| Grok Build | Development build tool |
| OpenCode | Coding tool |
| OpenClaw | Coding agent |
| Hermes Agent | Agentic tool |

## ⚙️ Key Details
CC Switch facilitates integration with Kimi K3, Moonshot AI's model with 2.8 trillion parameters, native vision, and a 1-million-token context window. The manager also supports integration with several API relay service providers:

* **PackyCode**: Provides relay services for Claude Code, Codex, Gemini, and others. Users can use promo code "cc-switch" during their first recharge for a 10% discount.
* **ZetaAPI**: Focuses on model fidelity and offers pay-as-you-go billing with a 10x compensation guarantee for quality inconsistencies. Users can use promo code "CC-SWITCH" for a 10% discount on the first top-up.
* **APINEBULA**: An enterprise-grade aggregation platform that provides access to Claude, GPT, and Gemini models. Users can use promo code "ccswitch" for a 10% discount on the first recharge.

## 🚀 Availability
CC Switch is available for Windows, macOS, and Linux. The official website for the application is ccswitch.io.
