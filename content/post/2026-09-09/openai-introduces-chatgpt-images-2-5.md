# OpenAI introduces ChatGPT Images 2.5

OpenAI has released ChatGPT Images 2.5, an update to image generation models that have been used for more than 3 billion images across ChatGPT Images and the GPT‑Image models in the API.

## ⚙️ Key details
This latest release includes several improvements:
* Faster response times
* Better ability to preserve subjects in reference photos
* Improved instruction-following ability across multiple turns

## 🚀 Availability
Two new model IDs are available in the API:

| Model ID | Use Case |
| :--- | :--- |
| gpt-image-2.5-sunburst | Workflows where editing precision matters most |
| gpt-image-2.5-flare | Fast, high-quality everyday image generation |
