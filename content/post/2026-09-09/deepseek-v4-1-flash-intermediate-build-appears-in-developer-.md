# DeepSeek V4.1 Flash Intermediate Build Appears in Developer Beta

An internal beta notice for DeepSeek V4.1 Flash has been reproduced by developers on Reddit and Hacker News, suggesting a test build for the next iteration of DeepSeek's speed-oriented V4 model.

## 🔍 Overview
DeepSeek V4.1 Flash is an intermediate version that is newer than DeepSeek V4 Flash 0731, though it has not been officially released. While the public DeepSeek documentation continues to list only deepseek-v4-flash, deepseek-v4-pro, and deepseek-v4-flash-vision-exp, the beta notice identifies V4.1 Flash as the next step in the sequence following the V4 Preview and Vision Exp releases.

## ⚙️ Key details
The beta notice makes four specific claims regarding V4.1 Flash:
* A new architecture
* Native multimodality
* Greater capability
* Better speed and cost efficiency

## 📊 Performance and Comparison
User reports indicate the model is experimental and under heavy load. Performance data includes:

* **Decoding Rates:** Developer Ivan Fioravanti reported an average of 350 tokens per second; other users reported ranges between 300–500 tokens per second.
* **Efficiency:** In one test, V4.1 Flash finished approximately 38% sooner and used about 43% fewer total tokens than Vision Exp, although the V4.1 session still had pending tasks while Vision Exp had completed all 11.
* **Baseline:** Artificial Analysis measures the documented V4 Flash 0731 API at 125.7 output tokens per second with a 0.92-second time to first token.

## 🧩 Model Family

| Model | Characteristics |
| :--- | :--- |
| V4 Flash | Faster, less expensive member of the family |
| V4 Pro | Higher-capability tier for harder agent tasks; includes reasoning-effort controls |
| Vision Exp | Adds image understanding to the Flash line; converts images into up to 384 billable tokens |

## 🚀 Availability
V4.1 Flash is currently available as a test endpoint with a temporary model ID, beta pricing rule, and concurrency cap. The beta ID indicates that this specific endpoint will expire, and no public source has provided a final release date.
