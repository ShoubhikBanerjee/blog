# AI Edge Gallery adds support for Gemma 4 and Thinking Mode

The AI Edge Gallery has been updated to provide official support for the newly released Gemma 4 family of models, enabling users to run powerful open-source Large Language Models (LLMs) locally on mobile devices.

## 🔍 Overview
AI Edge Gallery is a flexible sandbox and destination for running open-source LLMs directly on hardware. All model inferences happen on-device, meaning no internet is required, ensuring privacy for prompts, images, and sensitive data.

## ⚙️ Key details

| Feature | Description |
| :--- | :--- |
| Thinking Mode | Allows users to see a model's step-by-step reasoning process; currently works with supported models starting with Gemma 4. |
| Agent Skills | Augments capabilities with tools like Wikipedia for fact-grounding, interactive maps, and visual summary cards. |
| Dedicated Workspace | A space to test prompts and single-turn use cases with control over temperature and top-k parameters. |
| Model Management | Allows users to download models from a list, load custom models, and run benchmark tests on specific hardware. |

## 🧩 How it works
Users can access various on-device ML/GenAI use cases, including:
* **Multimodal Capabilities**: Identifying objects, solving visual puzzles, or getting descriptions via the camera or photo gallery.
* **Audio Processing**: Real-time transcription and translation of voice recordings into text.
* **Automated Tasks**: Offline device controls and a virtual garden mini-game powered by a finetune of FunctionGemma 270m.
* **Modular Skills**: Loading skills via URL or browsing community contributions on GitHub Discussions.

## 🚀 Availability
* **OS Requirements**: Android 12 and up, and iOS 17 and up.
* **Installation**: Available via Google Play, App Store, or as an apk from the latest release for users without Google Play access.
* **Technical Foundation**: Powered by Google AI Edge (Core APIs and tools) and LiteRT (lightweight runtime for optimized execution).
