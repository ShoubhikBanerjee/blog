# CapRover Scalable PaaS for Application and Database Deployment

CapRover is a scalable Platform as a Service (PaaS) designed as an easy-to-use app/database deployment and web server manager that automates Docker and nginx.

## 🔍 Overview
CapRover provides a platform for deploying applications and databases without requiring Docker or nginx knowledge. It is designed for developers who prefer writing code over managing server configurations and those seeking to reduce costs compared to services like Heroku or Microsoft Azure.

## 🧩 How it works
CapRover utilizes several technologies under its interface to maintain robustness and speed:

| Component | Purpose |
| :--- | :--- |
| Docker Swarm | Containerization and clustering |
| Nginx | Load-balancing (via fully customizable templates) |
| Let's Encrypt | Free SSL (HTTPS) |
| NetData | Performance monitoring |

## ⚙️ Key details
CapRover supports a wide range of applications and databases, including:
- **Languages/Frameworks:** NodeJS, Python, PHP, ASP.NET, Ruby
- **Databases:** MariaDB, MySQL, MongoDB, Postgres
- **CMS:** WordPress

Key features include:
- Web GUI for convenience and a CLI for automation and scripting.
- Dropdown-based installation for databases like MariaDB, MySQL, and MongoDB.
- No lock-in; applications continue to work if CapRover is removed.
- Setup requires only the ability to copy and paste instructions from the "Getting Started" documentation.

## 🚀 Availability
Further details and documentation are available at https://CapRover.com/.
