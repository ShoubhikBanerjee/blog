# Launch of the Get Shit Done with AI Bootcamp

The AI Engineering Academy has introduced the "Get Shit Done with AI" Bootcamp, a self-paced program focused on real-world applications designed to equip students with the skills to become AI engineers.

## 🔍 Overview
The bootcamp covers a broad spectrum of AI development, ranging from core code and machine learning fundamentals to the deployment of generative AI applications.

## ⚙️ Key Details

### Technical Curriculum
* **Language & Data Essentials:** Python data structures, functional tricks, typing, JSON, pathlib, NumPy, and Pandas.
* **Mathematical Foundations:** Linear algebra, calculus, and probability.
* **Machine Learning Fundamentals:** Linear regression (feature scaling to evaluation) and PyTorch (tensors, autograd, data loading, optimizers, and training loops).
* **Generative AI & LLMs:** Tutorials on Ollama, LLMs, RAGs, LangChain, LangGraph, Fine-tuning, DSPy, and AI Agents (CrewAI).
* **Supported Models:** ChatGPT, gpt-oss, Claude, Qwen, Gemma, Llama, and Gemini.

### Production & Deployment
* **Data Engineering:** Data exploration using Pandas and Seaborn (Bank Marketing dataset), data validation with pandera, feature engineering with scikit-learn Pipelines, and versioning with DVC.
* **MLOps:** Experiment tracking with MLflow and tuning LightGBM models.
* **Shipping:** Building REST APIs with FastAPI and packaging applications into Docker containers.
* **Cloud Deployment:** Pushing artifacts to S3, storing images in ECR, and orchestrating deployment via AWS ECS and EC2.

## 🚀 Availability
Interested individuals can access the program through the following channels:
