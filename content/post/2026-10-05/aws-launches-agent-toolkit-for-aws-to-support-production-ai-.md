# AWS Launches Agent Toolkit for AWS to Support Production AI Agents

AWS has officially launched the Agent Toolkit for AWS, a suite of specialized Model Context Protocol (MCP) servers designed to help users maximize their use of AWS wherever they use MCP. Informed by customer feedback, the toolkit serves as the successor to the MCP servers, plugins, and skills previously available on AWS Labs.

## 🔍 Overview
The Agent Toolkit for AWS is recommended for developers who are building production software using coding agents, as well as those building agents for their own customers.

## ⚙️ Key details
The toolkit provides built-in capabilities to support secure and visible agent workflows:
* **Identity management**: Includes IAM condition keys to distinguish agent actions from human actions.
* **Observability**: Offers visibility through CloudWatch and CloudTrail.
* **Vetted capabilities**: Includes skills that have been evaluated for accuracy and effectiveness.

## 🚀 Availability
The Agent Toolkit for AWS is now live. For users currently utilizing the existing AWS Labs repository, that repository will continue to work and accept contributions. Over time, the most useful projects from that repository will be transitioned into the Agent Toolkit for AWS.
