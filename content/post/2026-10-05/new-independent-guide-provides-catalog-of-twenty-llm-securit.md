# New independent guide provides catalog of twenty LLM security and red teaming tools

An independent evaluation guide has been released featuring 20 synced entries from the community-maintained Awesome MLSecOps catalog. This resource provides a central list of tools designed to find weaknesses in Large Language Model (LLM) applications that conventional application scanners cannot detect.

## 🔍 Overview

LLM security tools help teams exercise various components of Gen AI applications under adversarial input. These tools are designed to test model behavior, system prompts, retrieval pipelines, tool calls, output handling, and policy controls. The catalog serves as a discovery aid rather than a security certification, helping users find resources directly from the community rather than through paid placement programs.

## ⚙️ Key details

The tools listed in the guide support several security and testing functions for generative AI:

*   **Prompt-injection testing:** Identifying vulnerabilities to malicious instructions.
*   **Jailbreak evaluation:** Checking model guardrails against abuse.
*   **Sensitive-data leakage checks:** Validating that models do not expose protected information.
*   **Guardrail validation:** Testing programmable barriers between application code and the LLM.
*   **Repeatable red-team campaigns:** Organizing offensive security tests against applications.

## 🚀 Availability

The following tools and frameworks are included in the guide, with descriptions maintained from the Awesome MLSecOps repository:

| Tool Name | Description |
| :--- | :--- |
| AI Goat | A Large Language Model designed for getting hacked and vulnerable LLM CTF challenges. |
| NeMo Guardrails | Programmable guardrails for developers to add between application code and the LLM. |
| Meta's suite | Safety and security tooling including Llama Guard, Code Shield, and CyberSecEval. |
| Python Risk Identification Tool | A tool for identifying risks in generative AI applications. |
| Generative Application Firewall (GAF) | An open-source firewall for protecting generative AI applications. |
| Repello AI tool | An open-source offensive tool for testing against system prompt leakage. |
| Self-hostable DLP gateway | Enterprise prompt gateway for ChatGPT, Claude, and Gemini using Squid, Go ICAP, and mTLS. |
| Bias Tester | A framework for testing bias in LLMs. |
| Prompt Injection CTF playground | A playground for practicing prompt injection attacks. |

## 💡 Why it matters

When choosing an LLM security tool, developers are advised to match the tool's test library to their specific threat model and deployment architecture. These tools exercise application controls that traditional scanners may miss, providing specialized coverage for LLM-based systems.
