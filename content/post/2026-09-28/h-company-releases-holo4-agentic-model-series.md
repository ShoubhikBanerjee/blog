# H Company Releases Holo4 Agentic Model Series

H Company has introduced Holo4, a new series of agentic models designed for real business workflows across multiple interfaces.

## 🔍 Overview
Holo4 models are designed to interact with software through any available interface, including GUIs, code, APIs, and MCP. Unlike models trained for a single interface, Holo4 is a single model that runs across various platforms without needing to select different versions for each.

**Supported platforms include:**
* Desktops
* The web
* Android
* Code sandboxes
* Business APIs

## ⚙️ Key details
Holo4 models are based on Qwen and show significant improvements over that base. They were trained using supervised and reinforcement learning on a large set of tasks and environments, including those from the Agentic Task Factory.

| Model Variant | Type/Size |
| :--- | :--- |
| Holo4 27B | Dense |
| Holo4 35B-A3B | Mixture of Experts |
| Holotron4 Nano | Updated version of Holotron 3 |

## 🧩 How it works
Holo4 performs a variety of agentic actions to complete business tasks:
* Clicks and types on screens
* Writes and executes its own code
* Calls API tools or MCP

**Example capabilities demonstrated by Holo4 27B:**
* Building a 3D model of the Eiffel Tower in FreeCAD based on specific scale and coordinate measurements.
* Creating and running a Pac-Man-style game in Godot with a player driven by a simple heuristic.

## 💡 Why it matters
On the OSWorld 2.0 benchmark for desktop control, Holo4 27B scores 61.7% and Holo4 35B-A3B reaches 30.9%. While these trail Opus 5.5 (81.8%), Holo4 achieves these results with a much lower cost and orders of magnitude fewer parameters. It also competes with frontier models on the AutomationBench for API use.

## 🚀 Availability
Both Holo4 sizes are available on the H Models API and are priced at H Models API rates for single runs. Every trajectory behind public benchmark scores has been open-sourced and can be downloaded from Hugging Face or replayed at trajectories.hcompany.ai.
