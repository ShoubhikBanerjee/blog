# Release of Claude Opus 4.5 and GPT-5.1 Models

In November 2025, two new AI models, Claude Opus 4.5 and GPT-5.1, were released as incremental improvements over previous versions.

## ⚙️ Key details

| Model | Integration | Performance Update |
| :--- | :--- | :--- |
| Claude Opus 4.5 | Paired with coding agent harness | Improved from “often make mistakes” to “reliable enough to use on a day-to-day basis” |
| GPT-5.1 | Paired with coding agent harness | Improved from “often make mistakes” to “reliable enough to use on a day-to-day basis” |

## 💡 Why it matters

While these models provide improved reliability for day-to-day use when paired with agent harnesses, certain capabilities remain limited:

*   Drawing bicycles remains a challenge for both models.
*   The GPT-5.1 bicycle frame is described as "pretty crap."
*   Claude still cannot "really draw a bicycle."
