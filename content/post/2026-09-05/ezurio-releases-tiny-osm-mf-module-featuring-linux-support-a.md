# Ezurio Releases Tiny OSM-MF Module Featuring Linux Support and AI Capabilities

Ezurio has introduced the Tiny OSM-MF module, a hardware component designed to run Linux on the Sitara AM67 processor with integrated 4-TOPS AI performance.

## ⚙️ Key details

The module is built for the Cortex-A53 cores and supports a variety of operating systems. Ezurio provides software support for the following environments:

| Operating System | Support Status |
| :--- | :--- |
| Yocto Linux | Supported |
| Buildroot Linux | Supported |
| Android | Supported |
| Debian | Supported |
| QNX | Supported |
