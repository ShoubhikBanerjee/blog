# Stable Baselines3 declared stable with focus on maintenance

Stable Baselines3 (SB3) has reached a stable state as most features from the original roadmap have been implemented. Development focus has shifted to bug fixes and maintenance, including documentation updates and user experience improvements, while newer algorithms continue to be developed in associated repositories.

## 🔍 Overview
Stable Baselines3 is a set of reliable implementations of reinforcement learning algorithms in PyTorch. It is the next major version of Stable Baselines. The toolset is designed to be simple for beginners to experiment with advanced RL concepts without being buried in implementation details, though it assumes some prior knowledge about Reinforcement Learning.

## 🧩 How it works
The algorithms are intended to make it easier for the research community and industry to replicate, refine, and identify new ideas. They serve as baselines to build projects on top of and as a tool for comparing new approaches against existing ones. The performance of each algorithm was tested, and detailed logs and reports are provided on the OpenRL Benchmark platform.

## ⚙️ Key details
- **Core Library**: SB3 provides reliable PyTorch implementations of RL algorithms.
- **Associated Repositories**:
    - **SB3 Contrib**: Newer algorithms are regularly added here.
    - **SBX**: Faster variants are developed in this SB3 + Jax repository.
    - **RL Zoo**: An active training framework with its own roadmap.
- **Integrations**: SB3 includes integrations with Weights & Biases for experiment tracking and Hugging Face for storing and sharing trained models.
- **Migration**: A migration guide from SB2 to SB3 is available in the documentation.

## 🚀 Availability
Documentation is available online at https://stable-baselines3.readthedocs.io/. Detailed presentations of SB3 can be found in the v1.0 blog post or the associated JMLR paper. RL Baselines3 Zoo, part of the ecosystem, provides scripts for training, evaluating agents, tuning hyperparameters, plotting results, and recording videos. It also includes a collection of tuned hyperparameters for common environments and RL algorithms, along with agents trained with those settings, providing a simple interface to train and enjoy RL agents and benchmark different algorithms.
