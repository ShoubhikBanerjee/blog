# QLC+ Is a Free, Cross-Platform Open-Source Lighting Control Tool

QLC+ is a free, open-source, and cross-platform software designed to control DMX and analog lighting systems. It is a fork of the original QLC project and aims to continue development while introducing new features to reach the level of available commercial software.

## 📝 Overview
QLC+ is powerful and user-friendly software that supports a wide range of lighting hardware, including moving heads, dimmers, and scanners. It is designed for use in live shows, theatre, architectural installations, and venues, empowering both experienced professionals and beginners to take control of their lighting fixtures.

## 🧩 How It Works
The software supports multiple lighting control protocols, including DMX, Art-Net, and sACN. While the `master` branch is kept free of critical errors, users who regularly update the source code via `git pull` may occasionally encounter compiler warnings, errors, or unresolved symbols due to dependencies between objects, which can sometimes require a full package recompilation.

## ⚙️ Key Details
* **Licensing & Cost**: Free and open-source.
* **Protocols**: DMX, Art-Net, sACN.
* **Community Support**: A dedicated forum is available to submit new fixtures, give feedback, and share new ideas.
* **Documentation**: Official documentation is provided to explain specific features of QLC+.
* **Issue Tracking**: A badge is available to view currently confirmed issues, and compilation guides along with platform-specific instructions are hosted in the GitHub Wiki.

## 🚀 Availability
QLC+ runs on the following operating systems:
* Linux
* Windows (10 and later)
* macOS (10.12 and later)
* Raspberry Pi

A dedicated support page is available to help users find assistance and resolve potential issues.
