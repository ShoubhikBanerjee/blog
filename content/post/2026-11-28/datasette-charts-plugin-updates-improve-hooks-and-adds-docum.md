# Datasette Charts plugin updates improve hooks and adds documentation website

The datasette-charts plugin has released an update addressing friction points identified in its chart type plugin hooks, along with the launch of a dedicated documentation website.

## 🔍 Overview
The datasette-charts plugin features a hook system that allows other plugins to define new chart types. To test this functionality, Claude Opus 5.5 was used to build an experimental plugin, which revealed several friction points in the design. The current release addresses these issues to improve the development process for additional chart plugins.

## ⚙️ Key details
- The release improves the ergonomics of building additional chart plugins.
- Friction points identified by an experimental Claude Opus 5.5 plugin have been resolved.

## 🚀 Availability
- A new website for the plugin is available at charts.datasette.io.
- The website includes a tutorial for plugin authors.
- A gallery displays core charts and annotations, with each item linking to an interactive demo on Datasette Lite.
