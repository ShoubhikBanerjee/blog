# Update on Full-Stack AI App Generator and Pydantic AI Ecosystem

A production-ready full-stack AI app generator has been updated, providing a FastAPI and Next.js 15 project generator that includes AI agents, RAG, and over 20 enterprise integrations.

## ⚙️ Key details

**Technical Specifications:**
- Python 3.11+
- Powered by Pydantic AI
- Next.js 15 with WebSocket streaming and real-time chat UI
- Infrastructure: Docker, K8s, and Celery
- Authentication: JWT and OAuth

**Integrated Frameworks and Pipelines:**
- AI Agent Frameworks: PydanticAI, PydanticDeep, LangChain, LangGraph, and DeepAgents
- RAG Pipeline options: Milvus, Qdrant, pgvector, and ChromaDB

## 🧩 How it works

**Core Features:**
- Conversation Sharing: Includes public links, direct sharing, and an admin browser
- Enterprise Tools: Admin panel and 20+ out-of-the-box integrations
- CLI Capabilities: Claude Code-style CLI featuring a Docker sandbox, /improve command, multi-agent teams, and browser automation

**Modular Components:**

| Component | Function |
| :--- | :--- |
| pydantic-deepagents | Modular agent runtime for Python; powers the deepagents framework option |
| pydantic-ai-shields | Drop-in guardrails for Pydantic AI agents (5 infra and 5 content shields) |
| pydantic-ai-subagents | Declarative multi-agent orchestration with token tracking |
| summarization-pydantic-ai | Smart context compression for long-running agents |
| pydantic-ai-backend | Sandboxed execution for AI agents using Docker and Daytona |
