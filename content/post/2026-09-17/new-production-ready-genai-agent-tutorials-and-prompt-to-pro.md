# New Production-Ready GenAI Agent Tutorials and Prompt to Production Course Released

The Agents Towards Production resource and the Prompt to Production course have launched to provide end-to-end, code-first tutorials for building production-grade GenAI agents. This open-source playbook is designed to guide developers through the transition from initial prototypes to enterprise-scale deployment using reliable and modular production systems.

## 🔍 Overview

Agents Towards Production serves as a central resource for building scalable GenAI agents. It features a collection of 28 production-grade tutorials and a comprehensive 17-module course. These materials cover the methods and paradigms required to build efficient software with AI, ranging from structured prompting to working production systems.

## ⚙️ Key details

The materials provide coverage of several technical domains necessary for enterprise AI applications:

*   **Workflows and Coordination:** Stateful workflows and multi-agent coordination.
*   **Data and Memory:** Vector memory and Redis-based storage.
*   **Infrastructure:** Docker deployment, GPU scaling, and FastAPI endpoints.
*   **Tools and APIs:** Real-time web search APIs and browser automation.
*   **Development Lifecycle:** Fine-tuning, observability, evaluation, and UI development.
*   **Safety:** Implementation of security guardrails.

## 🧩 How it works

The project incorporates several industry-standard tools and frameworks to facilitate agent development:

| Tool | Function |
| :--- | :--- |
| LangChain | AI agent framework and workflow orchestration platform for building language model applications. |
| Redis | In-memory database and vector storage used for agent memory, caching, and real-time processing. |
| Claude Code | Can be integrated with an AI assistant via `npm install` to guide users through tutorials. |

## 🚀 Availability

The Prompt to Production course is currently live, with all 17 modules, lectures, and hands-on labs available. The tutorial repository includes step-by-step contributions from various companies, allowing users to open specific tutorials directly from the project repository. Every module in the course pairs a video lecture with a practical lab session.
