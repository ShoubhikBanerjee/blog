# Anthropic Introduces Claude Docs and Slides and Merges Chat Interfaces

Anthropic is updating Claude by introducing two new beta productivity tools, Docs and Slides, and merging its chat interfaces into a single experience.

## 🧩 How it works

Claude can now generate documents and presentations directly from any chat. Users can request changes to these creations or make edits manually. 

* **Claude Docs**: These begin as private documents that can be shared with other editors for simultaneous collaboration. Collaborators and Claude can leave comments similar to those found in Google Docs.
* **Claude Slides**: These allow users to create presentations through Claude chats.
* **Unified Access**: Everything created with Claude Design, Slides, or Docs is hosted at one shareable link accessible via mobile phones.

## ⚙️ Key details

Anthropic is simplifying the user experience by merging regular chats and Cowork into "one Claude." 

| Feature | Description |
| :--- | :--- |
| One Claude | A single interface merging regular chats and Cowork, making all AI productivity tools available from any chat. |
| Integration | Artifacts and Claude Design capabilities are available through the new single interface. |
| Task Handling | Claude can determine what a task needs to provide Cowork and Design capabilities from any conversation using existing context, skills, and connectors. |

## 🚀 Availability

The "one Claude" update and new tools are rolling out over the next few weeks with the following terms:

* **Initial Access**: Pro and Max users on web, desktop, and mobile.
* **Future Access**: Team and Free users.
* **Activation**: There is "nothing to turn on" for the update, and users may continue using Claude chat normally.
