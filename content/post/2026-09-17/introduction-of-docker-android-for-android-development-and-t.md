# Introduction of Docker-Android for Android Development and Testing

Docker-Android is a docker image designed to support all aspects of Android development and testing, including native, web, and hybrid-app projects.

## ⚙️ Key details

Docker-Android provides the following capabilities:
* Ability to build Android projects.
* Execution of unit and UI-Tests using frameworks such as Espresso and Appium.
* VNC support to view the inside of the docker container.
* Log sharing feature via a web-UI.
* External control of the emulator using adb connect.
* Integration with cloud solutions, including Genymotion Cloud.
* Support for mcp server (beta-version).

## 🚀 Availability

Various image tags are available:
* budtmo/docker-android:emulator_9.0
