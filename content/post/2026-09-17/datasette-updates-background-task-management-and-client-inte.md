# Datasette Updates Background Task Management and Client Integration

Datasette has introduced new capabilities for plugin management and internal client functionality.

## ⚙️ Key details

* Plugins can now launch and manage background tasks using the new `datasette.add_background_task()` method.
* Datasette has been migrated to `httpx2` to enable features such as the internal `datasette.client.get()` method.
