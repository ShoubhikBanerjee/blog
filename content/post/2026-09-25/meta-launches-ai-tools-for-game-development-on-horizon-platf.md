# Meta Launches AI Tools for Game Development on Horizon Platform

Meta has announced a plan to encourage game creation for its Horizon social platform through two new AI-powered development tools. This move follows a recent pivot for Horizon, which launched as a VR app but now primarily focuses on mobile.

## 🧩 How it works

Meta is introducing tools that allow users to create games using AI prompts. According to Meta, these tools enable creators to turn ideas into complete 2D or 3D mobile games that include:

* Progression systems
* Balanced difficulty
* Art direction
* Multiplayer

## ⚙️ Key details

| Tool | Platform | Description |
| :--- | :--- | :--- |
| Horizon Create | Mobile App | Create games with AI prompts |
| Horizon Studio | Browser App | Create games with AI prompts and more granular controls |

To increase the reach of these games, Meta will allow titles made with Horizon Create and Horizon Studio to be recommended and played directly on Facebook and Instagram. Meta states, “Someone scrolling through Instagram can tap a clip of your game and be in a multiplayer session within seconds, without needing to download an app or being redirected.” Games that are “engaging, stable, culturally relevant, and keep players coming back” will receive more reach.

## 🚀 Availability

The apps will be available in early access, and interested users can sign up for a waitlist.

## 💡 Why it matters

This push into AI-generated video games comes as Roblox, a similar and more popular platform with 123 million daily active users, is also implementing AI-powered development features in its mobile app. By contrast, Horizon has struggled to gain similar scale, with a 2022 report indicating it had 300,000 monthly users.
