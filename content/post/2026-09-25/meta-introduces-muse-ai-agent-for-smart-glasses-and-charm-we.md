# Meta Introduces Muse AI Agent for Smart Glasses and Charm Wearable

Meta has introduced Muse, an AI agent designed to assist users with productivity, health, and relationship goals.

## ⚙️ Key details

Muse features a mascot named "Jolly," described as a pink-cheeked character with plush ivory fur. Depending on the context, the agent's appearance and persona can vary:

| Version/Instance | Description |
| :--- | :--- |
| Jolly | The official mascot seen in various outfits on campus cutouts. |
| Cooper | Meta CTO Andrew Bosworth's agent, dressed as a test pilot. |
| Henry | An audio-only version with the tones of a British man, designed to assist a fictional 38-year-old gym bro named Sean. |

## 🧩 How it works

Users can interact with Muse through smart glasses to assist with decision-making based on personal context, such as viewing an object and receiving AI guidance. The agent can also learn from user data, such as emails, to alter its appearance.

Capabilities and observed performance include:
* **Health Guidance**: Providing workout regimens for goals such as regaining muscle and achieving a sub-30 minute 5K.
* **Contextual Analysis**: Evaluating snacks for protein content relative to calories.
* **Limitations**: In demonstrations, the agent mistakenly reported incorrect protein grams for a protein bar and failed to add granola bites to a cart because the product "did not exist in the catalog."

## 🚀 Availability

Muse is being integrated into the following hardware:
* All of Meta's smart glasses.
* Charm, a new standalone AI wearable described as part chunky smartwatch, part Humane AI Pin, and part Tamagotchi.
