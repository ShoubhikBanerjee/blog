# Streamlined Edge ML Workflow for WeBe Band Wearable Device

Researchers have developed a streamlined edge ML workflow to enable the rapid development, optimization, and deployment of machine-learning models directly on the WeBe Band, a wrist-worn device for multimodal physiological data monitoring.

## 🧩 How it works
The system focuses on system-level automation and deployability, integrating the open-source Piccolo AI ecosystem with an automated pipeline. This framework provides the following capabilities:
- Hardware-aware model compilation
- Generation of deployable firmware artifacts
- Support for over-the-air (OTA) deployment
- Hardware-aware quantization and AutoML
- Performance profiling to meet latency targets within device memory and power limitations

## ⚙️ Key details
The workflow supports multiple lightweight model classes and provides on-device profiling tools to evaluate memory footprint and inference latency under realistic conditions.

| Model Class | Performance Observations |
| :--- | :--- |
| Classical machine-learning algorithms | Offer strong real-time performance |
| Neural networks | Require careful resource management |

## 💡 Why it matters
This work enables researchers and developers to rapidly iterate on models and evaluate them directly on target hardware. While demonstrated on the WeBe Band platform, the workflow is designed to be extensible to other ML-powered edge devices.
