# uvx commit-rewriter Adds Support for Non-Default Branches

On 24th September 2026, an update was released for the commit-rewriter tool to allow support for branches other than the default branch.

## ⚙️ Key details
* Users can run the tool against another branch by using the command: `uvx commit-rewriter --branch other`.
