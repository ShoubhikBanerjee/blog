# IBM provides guides and APIs for building Gen AI applications on watsonx

IBM has released examples and guides for building and deploying Gen AI applications using the watsonx platform and its APIs.

## ⚙️ Key details
To begin using the watsonx APIs, the following three values are required:

| Requirement | Description |
| :--- | :--- |
| Project or space ID | Necessary value for API usage |
| Regional endpoint | Example: `https://us-south.ml.cloud.ibm.com` |
| IBM Cloud API key | Obtained via the link on Developer Access |

## 🚀 Availability
Users can access the following resources to get started:
* **Developer Access**: Used to receive the required project/space ID, endpoint, and API key.
* **watsonx Developer Hub**: Provides documentation and quickstarts.
