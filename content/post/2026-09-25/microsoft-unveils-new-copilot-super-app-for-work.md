# Microsoft Unveils New Copilot Super App for Work

Microsoft has officially unveiled a redesigned Copilot "super app" that bundles chat, coding, and AI agents into a single interface designed for work.

## 🔍 Overview
The new Copilot app serves as the default landing experience for users and is organized into three primary tabs:

| Tab | Description |
| :--- | :--- |
| Home | Combines Copilot Chat and Cowork; includes a "Today" personalized dashboard for emails, meeting requests, and Teams threads. |
| Code | Allows users to create and share apps, trackers, dashboards, or automations as cloud-hosted internal apps. |
| Autopilot | A cloud-based personal AI assistant (formerly known as Scout) that acts as a "digital teammate." |

## 🧩 How it works

**The Code Tab**
* Powered by the same underlying technology as GitHub Copilot.
* Runs in a sandboxed environment and can be hosted securely within a tenant.

**Autopilot Agents**
* Operates on its own cloud computer instance with its own identity, memory, computer, and workspace.
* Built on Microsoft IQ to understand organizational workflows.
* Can be @mentioned in Teams, Outlook, chats, channels, and documents.
* Capable of watching Teams channels, running recurring work tasks, or handling follow-ups.

## ⚙️ Key details

Microsoft is introducing a hybrid billing model for the service:
* **User Subscription License:** Provides access to Copilot in Chat, Word, Excel, PowerPoint, Outlook, and Teams.
* **Usage-Based Billing:** Applies to Cowork, Code, and Autopilot, including long-running agentic capabilities or the use of models such as Astra and Fable.
* **Management:** Microsoft uses an auto model picker for tasks; IT admins can use a new "FinOps for AI" tool to manage spend.

## 🚀 Availability
* **Home and Code tabs:** Rolling out to the Frontier program for early access in the coming weeks.
* **Autopilot:** Entering private preview later this month.
* **Code (Premium/Pro):** Preview available for Microsoft 365 Premium and Pro subscribers later this year.

## 💡 Why it matters
Microsoft aims for the new Copilot to be as influential as Office, with Jared Spataro, chief marketing officer of AI at work at Microsoft, stating, "Just as Office defined work for the PC era, the new Copilot is built to define it for the AI era."
