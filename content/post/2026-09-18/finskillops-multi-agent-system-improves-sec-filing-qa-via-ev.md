# FINSKILLOPS Multi-Agent System Improves SEC Filing QA via Evolved Skills

Updates have been provided regarding FINSKILLOPS, a multi-agent system designed for SEC filing question answering (QA).

## 🧩 How it works
FINSKILLOPS manages a skill registry through the following processes:
* Derives reusable skills from typed failure diagnoses that are grounded in evidence.
* Governs skills using targeted validation and protected-case regression checks.
* Utilizes negative controls and versioned replacement or retirement.

## ⚙️ Key details
Testing across six financial QA benchmarks showed that a single frozen skill registry achieved the highest reference consistency and verdict-weighted correctness among evaluated systems. 

Performance metrics include:
* **Correctness Improvement:** Evolved skills increased correctness from 3.70 to 4.55 on an enhanced benchmark.
* **Operational Study:** In a 12-round study, 6 of 33 proposed skills were promoted.
* **Error Reduction:** The monitoring non-correct rate decreased from 20.0% to 12.5%.
