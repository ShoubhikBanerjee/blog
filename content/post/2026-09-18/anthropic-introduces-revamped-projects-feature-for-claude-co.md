# Anthropic introduces revamped projects feature for Claude Code

Anthropic has launched a revamped projects feature in Claude Code that enables users to manage and coordinate a team of multiple AI agents working on the same codebase.

## 🧩 How it works

The system utilizes a hierarchical structure to manage complex assignments:

* **Coordinator**: A central agent that directs the overall operation and keeps work organized.
* **Threads**: Parallel tasks running under the coordinator. Each thread is a Claude Code cloud session operating on its own copy of the repo and its own branch.
* **Sub-components**: Threads can further divide delegated work using workflows, loops, and subagents to increase the speed of large assignments.

## ⚙️ Key details

* **Shared Resources**: Agents operate under one roof with shared goals, memory, and a library of artifacts and files.
* **Conflict Resolution**: If multiple threads modify the same code, the overlap is resolved as a merge conflict, similar to a standard PR.
* **User Interaction**: Users can monitor and update progress via the main project chat or interact with individual threads.
* **Environment**: Threads currently run in the cloud, though Anthropic states support for local code and tools is coming “very soon.”

## 🚀 Availability

The feature is currently in beta for select Claude Max and Pro subscribers. Access will later expand to:

* All Pro, Max, Team, and Enterprise users
* Regular Claude chats
* Cowork
