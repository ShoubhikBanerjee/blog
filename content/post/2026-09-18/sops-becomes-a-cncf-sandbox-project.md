# SOPS Becomes a CNCF Sandbox Project

SOPS, an editor of encrypted files originally launched at Mozilla in 2015, has been donated to the Cloud Native Computing Foundation (CNCF) as a Sandbox project in 2023.

## 🔍 Overview
SOPS is an editor of encrypted files that was inspired by sneaker, password store, credstash, hiera-eyaml, and the experience of managing PGP encrypted files by hand for many years.

## ⚙️ Key details

| Feature | Supported Options |
| :--- | :--- |
| Supported Formats | YAML, JSON, ENV, INI, and BINARY |
| Encryption Methods | AWS KMS, GCP KMS, Azure Key Vault, HuaweiCloud KMS, age, and PGP |
| License | Mozilla Public License Version 2.0 |

## 🧩 Project History
* **Original Authors:** Adrian Utrilla (@autrilla) and Julien Vehent (@jvehent).
* **Key Contributors:** The project was carried for a long time by AJ Bahnken (@ajvb) and received contributions from numerous other contributors.
* **Current Status:** Now under the stewardship of a new group of maintainers as a CNCF Sandbox project.
