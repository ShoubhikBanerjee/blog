# Survey Defines Taxonomy for Large Language Model Fusion

A new survey titled "From Parameters to Behaviors: A Survey of Model Fusion for Large Language Models" provides a unified definition and systematic taxonomy for model fusion, which integrates capabilities from source models into a single target model.

## 🔍 Overview
As of June 2026, Hugging Face hosts more than 2M models, providing a rich base for capability integration and model reuse. This survey aims to map the field of model fusion to support future work, as previous surveys often only covered separate parts of the space.

## 🧩 How it works
The survey organizes prior work into three levels of fusion:

| Fusion Level | Description |
| :--- | :--- |
| Parameter-level | Integration based on model parameters |
| Representation-level | Integration based on representations |
| Behavior-level | Integration based on model behaviors |

## ⚙️ Key details
In addition to the taxonomy, the survey includes:
* A review of benchmarks, metrics, and applications.
* A summary of current challenges.
* Identification of future directions.
* A comprehensive list of papers regarding model fusion.
