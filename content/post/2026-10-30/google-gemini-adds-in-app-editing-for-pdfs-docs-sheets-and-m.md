# Google Gemini adds in‑app editing for PDFs, Docs, Sheets, and more

Google Gemini now lets users generate, preview, and edit a variety of file types without leaving the chat interface.

## 🔍 Overview
- Gemini can handle PDFs, Google Docs, Google Sheets, slide decks, Markdown files, TXT files, and code directly in a conversation.
- The capability expands on earlier support for generating and downloading files, allowing on‑the‑fly tweaks.

## 🛠️ New file‑editing features
- Edit files you generate with Gemini without exiting the app.
- Highlight text in a file to ask Gemini questions or request changes (e.g., turn a highlighted table into a graph).
- Expand documents to full‑screen mode for easier editing.
- Existing Workspace integrations, such as the Gemini bar in Google Docs, continue to work.

## ⚙️ Supported formats & platform availability
| File format | Web editing | Mobile editing |
|------------|------------|----------------|
| PDF (preview & edit) | ✅ | ✅ |
| Google Docs | ✅ | ❌ |
| Google Sheets | ✅ | ❌ |
| Slide decks | ✅ | ❌ |
| Markdown | ✅ | ❌ |
| TXT | ✅ | ❌ |
| Code | ✅ | ❌ |

## 🚀 Availability
- The new capabilities are live today for all Gemini users.
- PDF preview and editing are available on both web and mobile; all other formats are currently web‑only.

## 💡 Why it matters
- Users no longer need to switch between Gemini and separate editing apps, streamlining workflow.
- Full‑screen editing and contextual highlights make it easier to transform content directly within the chat.
- Anthropic introduced a similar document‑editing feature in Claude chats earlier this year, highlighting a broader move toward integrated AI‑powered productivity tools.
