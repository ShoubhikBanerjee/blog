# OpenAI adds API credit benefit for $100‑$500 ChatGPT subscriptions

OpenAI announced that subscribers paying $100, $200, or $500 per month for ChatGPT now receive an equivalent amount of credits that can be applied to one of their API organizations. The move mirrors Anthropic’s benefit introduced earlier this month for Max and Team subscribers.

## 🔍 Overview
- Anthropic introduced a benefit: $100, $200, and $500 per month subscribers receive the equivalent quantity of (expiring) credits for the Anthropic API.
- OpenAI launched a very similar deal: $100, $200, or $500 subscription plans get the same quantity of credits to apply to an API organization.
- The update was reported on 29 October 2026.

## 🧩 How it works
- Eligible ChatGPT subscription tiers (the $100, $200, and $500 plans) automatically earn a matching number of API credits.
- The credits are tied to an API organization owned by the subscriber.
- Credits are expiring, matching the description used for Anthropic’s benefit.

## ⚙️ Key details
- **Subscription tiers**: $100, $200, $500 per month.
- **Credit amount**: Same numeric value as the subscription price (e.g., a $200 plan gets 200 credits).
- **Applicability**: Credits can be used with the subscriber’s OpenAI API organization.
- **Reference**: "API credits benefit for eligible ChatGPT subscriptions."

## 🚀 Availability
- The benefit is available to all current and new subscribers of the $100, $200, or $500 ChatGPT plans.
- No additional actions are required; credits are automatically allocated.

## 💡 Why it matters
- Users who maintain subscriptions with both Anthropic and OpenAI can leverage the same credit structure across both providers.
- One user noted: "I maintain subscriptions with both companies, so this is great news for me!"
- The same user added: "I may even ship some public‑facing demos now that the credits are already covered by my existing subscriptions."
