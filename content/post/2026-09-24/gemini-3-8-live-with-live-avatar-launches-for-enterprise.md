# Gemini 3.8 Live with Live Avatar Launches for Enterprise

Building on the launch of Gemini 3.8 Live, a new feature called Live Avatar has been introduced to bring near real-time visual presence to native live dialogue models.

## 🔍 Overview
Live Avatar pairs near real-time video generation with speech to create a dynamic visual persona that listens, sees, and speaks. This allows enterprise agents to communicate using multimodal capabilities, including facial expressions and simultaneous processing of visual and audio inputs.

## ⚙️ Key Details
* **Multimodal Interaction:** Features precise lip-syncing, natural expressions, and fluid turn-taking.
* **Multilingual Support:** Includes native speech-to-speech synchronization across 97 languages, allowing for mid-conversation language switches without visual drift or loss of video fidelity.
* **Background Processing:** Utilizes asynchronous tool calling to fetch data or trigger tasks (such as checking in a hotel guest) in the background without interrupting the active dialogue.
* **Customization:** Organizations can use a library of preset avatars or generate a custom animated avatar from a high-quality reference image to preserve brand styling and identity.

## 🛡️ Safety and Transparency
To respect identity and maintain transparency, all audio and video output is watermarked with SynthID. This imperceptible watermark is woven directly into the output to help minimize misattribution and misinformation.

## 🚀 Availability
* **Gemini Enterprise:** Gemini 3.8 Live with Live Avatar is available now.
* **Custom Avatars:** Currently available only through enterprise allowlisting.
* **Developer Access:** API documentation is available to get started.
