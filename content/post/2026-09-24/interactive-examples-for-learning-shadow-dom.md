# Interactive Examples for Learning Shadow DOM

New interactive examples are available to help users learn about shadow DOM and how shadow roots function.

## 🧩 How it works
Shadow roots create isolated DOM trees that feature:
* Private stylesheets
* Elements that interact with the page DOM in specific, controlled ways

## ⚙️ Key details
The interactive examples demonstrate the following concepts:
* Style encapsulation
* Inheritance
* Slots
* Parts
* JavaScript access
