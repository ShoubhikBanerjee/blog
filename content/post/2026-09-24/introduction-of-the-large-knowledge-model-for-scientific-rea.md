# Introduction of the Large Knowledge Model for Scientific Reasoning Infrastructure

The Large Knowledge Model (LKM) has been introduced as a scientific knowledge infrastructure designed to transform literature into a shared, computationally accessible reasoning resource.

## 🧩 How it works
LKM represents scientific papers as source-grounded reasoning graphs. This system aligns reasoning chains, claims, and related questions across papers while coupling semantic retrieval with structural traversal over the same objects.

This representation creates a Scientific Reasoning Landscape consisting of three connected views:

| View | Function |
| :--- | :--- |
| Question Landscape | Organizes open directions and research problems |
| Workflow Landscape | Exposes reusable scientific procedures |
| Evidence Landscape | Connects conclusions to conditions, disagreement, and support |

## ⚙️ Key details
The unified substrate supports several capabilities:
* Reasoning-aware scientific search
* Evidence-grounded question answering
* Comparative evidence analysis
* Research planning

Researchers and agents can use the system to develop research plans informed by unresolved evidence and established workflows, retrieve work via scientific intent, and synthesize answers using inspectable supporting arguments.

## 💡 Why it matters
Evaluations of the corpus-scale system show that with the answering model fixed, LKM retrieval improves accuracy across three benchmarks:
* **ChemBench:** 9.30%
* **PubMedQA:** 4.20%
* **SciBench:** 14.69%
