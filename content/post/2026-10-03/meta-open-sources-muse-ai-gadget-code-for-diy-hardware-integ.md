# Meta open-sources Muse AI gadget code for DIY hardware integration

Meta now lets you make your own Muse gadgets that feature the company’s new AI agent with code that the company open sourced.

## 🔍 Overview
- Muse gadgets are open source devices you build yourself.
- Meta open sources code to let you make Muse AI gadgets.

## 🧩 How it works
- Program an off‑the‑shelf ESP32 board or set up a Raspberry Pi with Meta’s SDKs.
- Connect Muse to your displays, buttons, sensors, actuators, and other workbench components.
- You can also connect Muse to your own hardware to put on your displays or a Raspberry Pi.

## ⚙️ Key details
- The platform is provided as open source code.
- Meta cautions users to “Proceed at your own risk!”
- Community‑built skills enable the AI agent to “turn on a light, control your TV, send a document to a printer, and more, depending on your setup.”

## 🚀 Availability
- Meta manufactured 5,000 Muse Home Link gadgets.
- You can claim a waitlist spot for the Muse Home Link now.
- Shipping is expected sometime this month.

## 💡 Why it matters
- The open‑source approach lets developers and hobbyists create custom AI‑enabled hardware solutions using readily available boards like ESP32 and Raspberry Pi.
