# Claude Opus 4.7 Leads Grok 4.20 in Performance and Coding Point Estimates

Updated on October 2, 2026, new performance rankings indicate that Claude Opus 4.7 is ahead of Grok 4.20. Across seven shared results, Claude Opus 4.7 achieved a higher public point estimate of 65.82, compared to 59.19 for Grok 4.20.

## 🔍 Overview
Claude Opus 4.7 leads in several benchmark categories using the BenchAlign v5.8 lane. While both models have equal documented context windows, Claude Opus 4.7 maintains higher supported estimates in specialized tasks.

* **Coding Performance:** Claude Opus 4.7 has a public coding point estimate of 57.9 versus 23.0 for Grok 4.20.
* **Agentic Performance:** Claude Opus 4.7 holds a 53.2 point estimate against 24.0 for Grok 4.20.
* **Global Ranking:** Claude Opus 4.7 is ranked #25/144 in coding and #38/119 in agentic categories based on supported evidence.

## 🚀 Availability
Model efficiency and data availability differ between the two systems. While Claude Opus 4.7 leads in most performance benchmarks, Grok 4.20 shows advantages in operational costs.

* **Token Costs:** Grok 4.20 has a lower estimated token cost for the stated workload.
* **Input Caching:** Claude Opus 4.7 has no published cached-input rate; consequently, cached tokens use its listed input rate.
* **Sample Volumes:** Comparisons used 8 Claude Opus 4.7 only samples and 16 Grok 4.20 only samples.
* **Provisional Lane:** Grok 4.20 recorded a score of 35.6 (#44/49) and an unranked score of 41.1 in the provisional lane.

Conditional ranges for these models do not establish rank confidence.
