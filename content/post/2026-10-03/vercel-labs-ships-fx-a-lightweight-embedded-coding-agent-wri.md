# Vercel Labs Ships fx, a Lightweight Embedded Coding Agent Written in Zig

Vercel Labs has shipped fx, a new embedded coding agent runtime designed for high-performance integration.

## 🔍 Overview

Unlike traditional tools, fx is not a hosted service. Instead, it is a highly compact runtime designed to be embedded directly.

## ⚙️ Key details

The fx agent includes the following technical specifications and features:

* **Language and Size:** Written in Zig, with a footprint of approximately 6MB.
* **Performance:** Features rapid execution with cold-starts in 10µs.
* **Capabilities:** Speaks ACP, mounts MCP servers, and prints JSON.
