# Claude Opus 5.5 and Claude Code used to create pixel art animation

A user utilized Claude Opus 5.5 and Claude Code to generate a pixel art animation and a corresponding video for a keynote presentation at the WeAreDevelopers World Congress North America.

## ⚙️ Key details

* **Model used for animation**: Claude Opus 5.5
* **Tool used for video production**: Claude Code
* **Animation style**: Animated pixel art on HTML 5 canvas
* **Content**: At least 20 jumping kakapo parrots with confetti
* **Video specifications**: 15 seconds long

## 🧩 How it works

1. **Asset Generation**: The user provided three kakapo photos from Google image search to Claude Opus 5.5 to create an HTML 5 canvas pixel art animation.
2. **Video Conversion**: The user downloaded the HTML and instructed a local Claude Code session to create a video from the file.
3. **Automation**: Claude Code used Playwright to load the HTML in a browser and execute specific clicks to trigger the confetti effect.
4. **Scripting**: Claude Code produced a Playwright script that scheduled clicks across the center, corners, edges, and top-center of the clickable area starting 3 seconds into the video.
