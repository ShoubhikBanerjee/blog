# Transformers Serves as Centralized Model-Definition Framework for Machine Learning

Transformers provides a centralized model-definition framework used for state-of-the-art machine learning across various modalities for both training and inference.

## 🔍 Overview
Transformers acts as the pivot across different frameworks. When a model definition is supported, it becomes compatible with various modeling libraries, inference engines, and training frameworks.

## ⚙️ Key details
* **Supported Modalities:** Text, computer vision, audio, video, and multimodal models.
* **Technical Requirements:** Works with Python 3.10+ and PyTorch 2.5+.
* **Resource Availability:** Over 1M+ model checkpoints are available on the Hugging Face Hub.

## 💡 Why it matters
By centralizing the model definition, Transformers ensures this definition is agreed upon across the ecosystem. This enables compatibility with the following tools:

| Category | Compatible Tools |
| :--- | :--- |
| Training Frameworks | Axolotl, Unsloth, DeepSpeed, FSDP, PyTorch-Lightning |
| Inference Engines | vLLM, SGLang, TGI |
| Modeling Libraries | llama.cpp, mlx |
