# Langflow and OpenHuman Provide New Tools for AI Agents and Workflows

Recent developments in AI orchestration include the available tools Langflow and OpenHuman, both of which focus on building, deploying, and managing AI-powered agents and workflows.

## 🔍 Overview

Langflow is an open-source platform and tool for building and deploying AI-powered agents and workflows. OpenHuman is an open-source agent harness featuring local-first memory, workflows, and agent orchestration.

## ⚙️ Key Details

### Langflow Capabilities
* **Visual Authoring:** Features a visual builder interface for quick iteration and an interactive playground for step-by-step testing and refining.
* **Integration:** Supports all major LLMs, vector databases, and a growing library of AI tools.
* **Customization:** Provides source code access for customizing components using Python.
* **Orchestration:** Supports multi-agent orchestration with retrieval and conversation management.
* **Deployment:** Can be deployed as an API, exported as JSON for Python apps, or deployed as an MCP server to turn flows into tools for MCP clients.
* **Observability:** Integrates with LangFuse, LangSmith, and other services.
* **Security:** Built with enterprise-ready scalability and security.

### OpenHuman Capabilities
* **Memory:** Uses a Memory Tree and Obsidian Wiki to build a persistent local memory of your world, storing data as scored Markdown trees in SQLite on the user's machine.
* **Orchestration:** Runs fleets of agents on durable graphs.
* **Research:** Functions as a deep researcher that sweeps the web and user data.
* **Connectivity:** Includes 100+ OAuth integrations, 5,000+ MCP servers, and 90,000+ Skills for tools like GitHub, Notion, Gmail, and Slack.
* **Automation:** An auto-fetch feature feeds the brain every 20 minutes.

## 🚀 Availability

| Tool | Installation and Access | Platform/Availability |
| :--- | :--- | :--- |
| Langflow | Langflow Desktop (includes all dependencies) | Windows, macOS, and major deployment clouds |
| OpenHuman | Installers from tinyhumans.ai/openhuman or GitHub Releases | Terminal installs (Homebrew, Debian/Ubuntu .deb, AUR, install scripts) |

Langflow is available at http://localhost:7860/ or http://127.0.0.1:7860. OpenHuman is currently in Early Beta and under active development.
