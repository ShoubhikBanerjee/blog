# Dim0 Launches Open-Source AI Canvas with Real-Time Agent Collaboration

Dim0 has released an open‑source AI canvas that integrates notes, code, mini‑apps, and an AI agent on a single infinite board, all in real time.

## 🔍 Overview
- Open‑source, real‑time collaborative AI canvas.
- Notes, mini‑apps, and agents on one infinite board.
- Infinite canvas: thousands of nodes and nested boards, smooth at scale.
- Real whiteboard underneath: hand‑drawn shapes, arrows, images, media, and 200,000+ icons via Iconify.
- Rich notes: Notion‑style rich text, math, code, and sub‑pages, edited in place.
- Mini‑apps: interactive React apps that can be opened, edited, and exported.
- Code & documents: run code in sandboxes; drop files that the agent can search (RAG).

## 🧩 How it Works
- Board‑aware agent reads the canvas and selected nodes.
- Takes multi‑step tool actions.
- Writes results back as editable nodes.

## ⚙️ Key Details
- Bring your own model: OpenAI, Anthropic, Gemini, Mistral, DeepSeek, Qwen, and more, switch anytime.
- Docker is the only prerequisite.
- Install scripts fetch the latest release from the terminal.
- The app launches without a Gatekeeper / SmartScreen prompt (ad‑hoc signed, not yet notarized).
- Dim0 ships a standalone desktop build (macOS · Linux · Windows) that runs fully local and offline.
- Boards live on‑device; the agent calls providers directly.

## 🚀 Availability
- Open‑source under MIT license.
- Self‑hostable; data stays yours (no training, no telemetry).
- Open http://localhost:3000 → create a board → type a prompt.
- Sign in to use managed AI and sync boards across devices.

## 💡 Why it Matters
- Real‑time multiplayer: live cursors, shared edits, a shared agent; conflict‑free sync, solo or fifty people deep.
- The board holds notes, code sandboxes, mini‑apps, documents, nested boards, and presentation frames, all next to each other.
- Your whole team can be on it at once.
