# Ruler provides a unified configuration for multiple AI coding agents

Managing instructions across multiple AI coding tools becomes complex as your team grows.

## 🔍 Overview
Ruler solves this by providing a single source of truth for all your AI agent instructions, automatically distributing them to the right configuration files.

## 🧩 How it works
- Supports a range of agents such as GitHub Copilot, Claude, Cursor, Aider, etc.
- Uses nested rule loading to handle complex project structures.
- Delivers context‑specific instructions for different components.

## ⚙️ Key details
- **Single source of truth** – centralizes instruction management.
- **Automatic distribution** – writes the appropriate configuration files for each agent.
- **Nested rule loading** – enables hierarchical, component‑level rules.
