# TencentDB Agent Memory: Unified Hub for AI Agents

TencentDB Agent Memory has launched a unified memory hub for AI agents, converting conversations, documents, and code into reusable assets.

## 🔍 Overview
- TencentDB Agent Memory is a team-level memory hub for AI Agents.

## 🧩 How it works
- Four reusable memory assets: Chat Memory, Skill, LLM‑Wiki, Code‑Graph.

## ⚙️ Key details
- Start all three services in one go (memory-core + memory-hub + proxy).
- Open the panel: http://localhost:8125.
- The MongoDB storage backend is experimental (off by default); see INSTALL.md for details.
- A migration tool is available for older releases (v1.x / v0.x) to v2.0.0+.
- One Proxy, unchanged protocol, zero‑code integration — point the Agent's base URL to the Proxy and configure its User Key.
- Most clients don't require a plugin, hook, or MCP server.
- OpenCode has a ready‑to‑use adapter configuration.
- Pi uses the pi‑plugin extension to connect through OpenAI Chat Completions.
