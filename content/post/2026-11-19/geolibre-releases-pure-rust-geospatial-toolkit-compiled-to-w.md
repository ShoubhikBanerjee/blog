# GeoLibre Releases Pure-Rust Geospatial Toolkit Compiled to WebAssembly

GeoLibre has released a new pure-Rust geospatial toolkit compiled to WebAssembly, enabling client-side geospatial processing without requiring servers, native installations, or GDAL dependencies. The toolkit is available as an npm package (`geolibre-wasm`) and PyPI package (`geolibre-wasm`) and ships with both the existing whitebox-wasm tools and new GeoLibre-authored tools located in the `geolibre-tools` crate. The release includes a self-contained demo page that loads all tool manifests and allows users to run geoprocessing on sample or custom GeoTIFF files entirely in the browser, with support for viewing exit codes, stdout, output files, and download links.
