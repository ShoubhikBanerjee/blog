# RAGFlow 1.0.0 released as an agent-native RAG database

RAGFlow 1.0.0 has been released, marking the transition of the leading open-source Retrieval-Augmented Generation (RAG) engine into an agent-native database. The system evolved into context infrastructure that fuses cutting-edge RAG with Agent capabilities to create a superior context layer for LLMs.

## 🔍 Overview

- RAGFlow positions itself as a leading open-source Retrieval-Augmented Generation (RAG) engine.
- It provides a streamlined RAG workflow adaptable to enterprises of any scale.
- The release enables developers to transform complex data into high-fidelity, production-ready AI systems with exceptional efficiency and precision.

## 🧩 How it works

Powered by a converged context engine and pre-built agent templates, RAGFlow focuses on:
- Deep document understanding-based knowledge extraction from unstructured data with complicated formats.
- Finding "needle in a data haystack" of literally unlimited tokens.
- Offering an intelligent and explainable approach to data processing.
- Providing plenty of template options to choose from.
