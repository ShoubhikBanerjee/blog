# TypeSafe Releases Jev Decision Model for AI Agent Routing

TypeSafe has released Jev, a decision model designed to offload routine routing and selection tasks from expensive frontier models in AI agent workflows. The system handles decisions such as model selection, skill loading, passage retrieval, and turn summarization at a fraction of the cost and latency of large language models.
