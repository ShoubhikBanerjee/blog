# Open Interface Lets LLMs Control Computers via Keyboard and Mouse Simulation

Open Interface is a tool that enables large language models to operate a computer by simulating keyboard and mouse input while using screenshots to assess progress and course-correct.

## 🔍 Overview
- Full Autopilot for All Computers Using LLMs
- Self-drives your computer by sending requests to an LLM backend (GPT-4o, Gemini, etc)
- Automatically executes steps by simulating keyboard and mouse input
- Course-corrects by sending the LLM backend updated screenshots of the progress as needed

## 🧩 How it works
- User provides a natural-language request
- Request is sent to an LLM backend such as GPT-4o or Gemini
- LLM determines the required steps to complete the task
- Steps are executed automatically via simulated keyboard and mouse input
- Progress is assessed by sending updated screenshots back to the LLM
- The LLM can course-correct based on visual feedback

## ⚙️ Key details
- Example tasks demonstrated: Solve Today's Wordle, Make me a meal plan in Google Docs, Write a Web App
- Connects to LLMs like OpenAI GPT-4V
- Requires Accessibility access to operate keyboard and mouse
- Requires Screen Recording access to take screenshots for progress assessment
- Licensed under MIT

## 🚀 Availability
- Platforms supported: macOS, Linux, and Windows

### macOS
- Binary available from the latest release
- Unzip the file and move Open Interface to the Applications Folder
- May show "Open Interface cannot be opened error" — press Cancel, then go to System Preferences -> Security and Privacy -> Open Anyway
- Grant Accessibility access and Screen Recording access when prompted (or manually via System Settings -> Privacy and Security)

### Linux
- Binary tested on Ubuntu 20.04
- Download the Linux zip file from the latest release
- Extract the executable
- Follow Setup section to connect Open Interface to LLMs such as OpenAI GPT-4V

### Windows
- Available (specific installation steps not detailed in evidence)
