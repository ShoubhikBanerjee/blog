# AgentCore Identity Adds Private CA Certificate Support for Private Identity Providers

AWS has added private certificate authority (CA) certificate support to AgentCore Identity, enabling agents to authenticate with private identity providers (IdPs) using custom CA certificates stored in AWS Secrets Manager or Amazon S3.
