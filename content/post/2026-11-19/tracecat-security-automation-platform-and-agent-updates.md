# Tracecat Security Automation Platform and Agent Updates

Tracecat is an open source security automation platform designed for teams and AI agents, providing a unified platform with everything AI-native security teams need to build agents and automate cyber defense. The repository is available under the AGPL-3.0 license, excluding code under the `packages/tracecat-ee` directory and code that gates enterprise features.

## ⚙️ Key Details

- Unlimited agents, cases, lookup tables, and workflows
- Build custom agents with prompts, tools, MCP, subagents, and skills
- Track, automate, and resolve incidents with agents
- Execute deterministic logic with resilience and scale on Temporal
- Store and query structured data
- Turn prompts into automations from Claude Code, Codex, Copilot, and more
- 100+ pre-built connectors and 50+ hosted MCP servers for security tools
- Connect custom agents to any MCP server via remote HTTP / OAuth or local `npx` / `uvx` commands
- Sync custom Python scripts from your Git repo into Tracecat
- Run untrusted code and agents within `nsjail` sandboxes or `pid` runtimes
- SAML / OIDC support and exportable into your SIEM
- Isolated different teams and dev / prod environments into workspaces
- RBAC, ABAC, OAuth2.0 scopes for humans and agents
- Review and approve sensitive tool calls from a unified inbox, Slack, or email
- Sync workflows, agents, and table schemas to GitHub, GitLab, Bitbucket, and others

## 🚀 Availability

- Sign up for Tracecat Cloud, or self-host with Docker, AWS Fargate, or Kubernetes
- Runs fully air-gapped
- Tracecat Enterprise is available as a managed Cloud with US or EU hosting, or as a self-hosted deployment with dedicated support

## 🛠️ Technology Stack

- Backend: Python with FastAPI, SQLAlchemy, Pydantic, uv
- Frontend: Next.js with TypeScript, React Query, Shadcn UI
- Database: PostgreSQL
