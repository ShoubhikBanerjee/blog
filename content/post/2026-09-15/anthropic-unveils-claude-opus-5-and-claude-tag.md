# Anthropic Unveils Claude Opus 5 and Claude Tag

Anthropic has released Claude Opus 5, a new flagship model designed for long-running agents, alongside Claude Tag, an internal tool for proactive coding work.

## 🔍 Overview
Claude Opus 5 is positioned as a step-change for long-running agents. It is described as "thoughtful and proactive" and achieves state-of-the-art (SOTA) results on coding and knowledge work evaluations, as well as on Frontier-Bench and GDPval-AA.

## ⚙️ Key details
* **Performance and Cost:** The model hits SOTA on Frontier-Bench and GDPval-AA at half the price of Fable 5.
* **Claude Tag:** An evolution of Claude Code where tagging @Claude triggers proactive work. This tool is already generating 65% of Anthropic's product team code, with usage expanding beyond engineering.
* **Model Lineage:** The Opus lineage page confirms that Opus 4.5 (Nov 2025) and 4.6 (Feb 2026) were the predecessors to Opus 5.

## 🚀 Availability
Anthropic has entered partnerships to embed its technology into various enterprise stacks:

| Partner | Integration Details |
| :--- | :--- |
| NEC | Claude Opus 4.7 and Claude Code will be embedded in the BluStellar Scenario program for finance and manufacturing. |
| Cognizant | Rolling Claude into Flowsource, Neuro AI Engineering, and Neuro IT Ops, including spec-driven development with Claude Code. |

## 💡 Why it matters
Anthropic's institute documented Claude agents independently running an open-ended AI safety research project end-to-end, which included proposing hypotheses, testing, and iterating across parallel agents. In response to increasing autonomy, an engineering post discussed capping the "blast radius" of capable agents across Cowork, Claude Code, and claude.ai.
