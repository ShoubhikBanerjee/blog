# Perplexity Portable Computer Launches on NVIDIA RTX Workstations

Perplexity has released its Portable Computer agent for Windows PCs equipped with NVIDIA GeForce RTX and NVIDIA RTX PRO Workstations. This update brings multistep AI workflows to local hardware, allowing users to analyze files, cross-reference documents, and manage recurring tasks without sensitive data leaving their device.

## 🧩 How it works
Perplexity Portable Computer functions as an on-device sibling to the cloud-based Perplexity Computer. It features a simplified installation process that includes the model, runtime, and computer tooling in a single package. While the agent runs locally, it includes a clear off-ramp for tasks requiring higher reasoning; if a request exceeds the local model's capabilities, the agent prompts the user for permission before routing the task to a cloud-based model.

## ⚙️ Key details
* **Default Model**: The agent utilizes a Qwen 3.8 27B model, post-trained by Perplexity and tuned for NVIDIA RTX GPUs.
* **Hardware Requirements**: Requires a GPU with 24GB or more of VRAM.
* **Cloud Credits**: Local execution does not consume Perplexity Computer cloud credits.
* **Integrations**: The agent features built-in connectors for several common platforms:

| Connector | Application |
| :--- | :--- |
| Microsoft Outlook | Email |
| Microsoft OneDrive | File Storage |
| Microsoft Word | Document Editing |
| Google Drive | File Storage |
| Gmail | Email |
| Slack | Communication |
| GitHub | Software Development |

## 💡 Why it matters
According to Gerardo Delgado of NVIDIA, "As local models become more capable, AI agents can handle more work directly on a PC while keeping sensitive information on the device." The release allows users to bypass the technical complexity of assembling their own AI stacks. By running agents locally, Perplexity aims to support high-value workflows in sectors such as engineering, finance, and product analytics that involve regulated or sensitive data.

## 🚀 Availability
The software is currently available for Windows PCs running NVIDIA GeForce RTX and NVIDIA RTX PRO Workstations with at least 24GB of VRAM. Support for NVIDIA DGX Station is expected to follow the initial release.
