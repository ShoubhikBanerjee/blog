# Kiro Crew Offers a Persistent, Self-Evolving Development Workspace

Kiro Crew is an open-source development workspace that runs locally or remotely on your hardware, with work designed to persist, learn, and evolve beyond a single session.

## 🔍 Overview

You can work with Kiro Crew through a desktop app, web dashboard, or CLI, and continue the same work through connection tools such as Slack and Discord.

## 🧩 How it works

- Multi-step tasks can run unattended.
- Recurring jobs run on a schedule.
- Heartbeats monitor systems until something needs attention.
- Kiro Crew Apps adapt the workspace to a specific job, combining a purpose-built interface with agents, skills, schedules, integrations, and backend services.

## ⚙️ Setup and updates

Kiro Crew can be run in several ways:

- Use the desktop app, which includes automatic updates.
- Install it on a machine or remote host with a one-line install.
- Use the Docker image for always-on servers.
- Build it from source.

The default agent runs on `kiro-cli`, which must be installed and signed in to separately. On first launch, Kiro Crew checks for this prerequisite and links to the official setup guide if it is missing. Download links fetch the newest build on their channel, and the app updates itself on that same channel. The recommended channel is Stable unless there is a reason to choose another.

## 🚀 Availability

Kiro Crew is available for macOS, Linux, and Windows. Package options include:

| Platform | Package |
|---|---|
| macOS (Apple Silicon or Intel) | `.dmg` |
| Windows (x64) | `.exe` |
| Linux (x86_64 or aarch64) | `.deb`, `.rpm`, or AppImage |

On Linux, the one-line install is the recommended starting point; a desktop package can be added for a native window and in-app updates.
