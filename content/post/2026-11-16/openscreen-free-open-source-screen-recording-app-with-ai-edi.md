# OpenScreen: Free, Open-Source Screen Recording App with AI Editing

OpenScreen is a new open-source desktop application that turns raw screen recordings into polished demos without watermarks or subscriptions. It supports Windows, macOS, and Linux, offering features like AI-powered editing, automatic captions, and GPU-accelerated export.

## 📸 What It Does

OpenScreen is designed to help users record their screen and instantly transform the result into share-ready content for platforms like YouTube, X, Reddit, or documentation sites.

Key capabilities include:

- Record a specific window or your entire screen
- Capture both microphone and system audio
- Webcam overlay with picture-in-picture mode
- Auto and manual zooms with adjustable settings
- Custom cursor size, smoothing, and click effects
- Automatic on-device captions with offline transcription
- An AI editing assistant that applies changes from natural language descriptions
- Support for multiple background options including wallpapers and gradients
- Motion blur and per-segment speed control on the timeline
- Text, arrow, and image annotations with animation presets
- Timeline snapping guides and audio waveform visualization
- Export to MP4 or GIF with GPU-accelerated rendering (Metal, D3D11, Vulkan)

## ⚙️ Key Details

| Feature | Description |
|---------|-------------|
| Licensing | MIT License, 100% free for personal and commercial use |
| Platforms | Windows, macOS, Linux |
| AI Assistant | Works with Claude, OpenAI, Gemini, Mistral, OpenRouter, MiniMax, or any OpenAI-compatible endpoint |
| CLI Support | Headless recording, JSON editing, and rendering via command line |
| Caption Languages | Arabic, Czech, English, Spanish, French, German, Italian, Japanese, Korean, Dutch, Polish, Portuguese (Brazil), Russian, Turkish, Vietnamese, Simplified Chinese, and Traditional Chinese |

Development started with Siddharth Vaddem, who archived the original repository after v1.5.0 before moving development to a new repository under the same name and MIT license. The project remains actively maintained, though users should expect rough edges and occasional breaking changes to the project format and CLI.
