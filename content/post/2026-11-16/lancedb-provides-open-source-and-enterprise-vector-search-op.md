# LanceDB Provides Open Source and Enterprise Vector Search Options

LanceDB has launched as a database designed for fast, scalable, and production-ready vector search. The system is built on the Lance columnar format, serving as a central location for developers to build, train, and analyze AI workloads while storing and indexing petabytes of multimodal data.

## 🔍 Overview
LanceDB supports comprehensive search capabilities, including vector similarity search, full-text search, and SQL. It allows users to store, query, and filter vectors, metadata, and multimodal data such as text, images, videos, and point clouds. The platform is engineered to search billions of vectors in milliseconds using state-of-the-art indexing.

## 🧩 How it works
The database is built on the Lance columnar format, which provides efficient storage and analytics. Advanced features include zero-copy operations and automatic versioning, allowing users to manage data versions without requiring extra infrastructure. The system also supports GPU usage in the process of building vector indexes.

## ⚙️ Key details
LanceDB is available in two primary configurations:

| Version | Description |
| :--- | :--- |
| LanceDB Embedded (open source) | Runs in the application's process; data resides on local disk or in object storage; 100% open source with no vendor lock-in. |
| LanceDB Enterprise | Offers production-scale distributed search, indexing, and maintenance, plus complete data sovereignty and security. |

## 🚀 Availability
Developers can integrate LanceDB through Python, Node.js, Rust, and REST APIs. Native support is provided for Python and JavaScript/TypeScript, with API and SDK support available for Python, TypeScript, and Rust.
