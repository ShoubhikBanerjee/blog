# Locally.Uncensored 3.0.10 Adds Cross-Platform AI Support and Computer Control

## 🔍 Overview
Locally.Uncensored has released version 3.0.10, providing an all-in-one local AI studio for desktop environments. The application enables users to run chat, image generation, video generation, and coding agents directly on their own hardware without requiring Docker, terminal configurations, or cloud connectivity.

## 🧩 How it works
The software operates as a locally hosted web server featuring a React UI. It includes a "Unified Canvas" for generation tasks such as in-painting, out-painting, and brush tool support. Users manage their AI workflows through a node-based architecture or an organized gallery system for storing and remixing content.

## ⚙️ Key details
- **Model Support:** Compatible with SD 1.5, 2.0, SDXL, SD 3.5 (Medium and Large), Flux.1 Dev, and Flux.2 Dev, as well as support for ckpt, diffusers, and certain gguf models.
- **Agent Capabilities:** Includes a coding agent for development tasks.
- **Security:** Built via GitHub Actions from public source code; Windows installers are code-signed via SignPath.io.

## 🚀 Availability
Locally.Uncensored 3.0.10 is available for the following platforms:

| Platform | Supported Formats |
| :--- | :--- |
| Windows 10/11 | NSIS installer (.exe), .msi |
| Linux | .AppImage, .deb, .rpm |
| macOS (Apple Silicon) | .dmg (Beta) |
| Android 7.0+ | .apk |

*Note: Intel Macs are not supported. Features like computer control are currently under testing for macOS.*
