# MobileBuildMCP Launches AI Development Toolkit for iOS and macOS Projects

MobileBuildMCP introduces a Model Context Protocol (MCP) server and CLI designed to enhance agent workflows for iOS and macOS development projects. The toolkit ships as a single package offering direct terminal access and an MCP server for AI coding agents, supporting flexible installation via global binary or npx without requiring a global install. It requires macOS 14.5 or later, Xcode 16.x or later, and Node.js 18.x or later (though the latter is not required for Homebrew installation).
