# DeepEval adds Jev support and Confident AI for automated failure detection

DeepEval, an open‑source framework for evaluating large‑language model systems, has announced new capabilities that expand its testing toolbox.

## 🔍 Overview
- DeepEval is a simple‑to‑use, open‑source LLM evaluation framework.
- It is similar to Pytest but specialized for unit testing LLM apps.

## 🧩 How it works
- Incorporates the latest research metrics such as G‑Eval, task completion, answer relevancy, hallucination, etc.
- These metrics use LLM‑as‑a‑judge and other NLP models that run locally on your machine.
- Supports evaluation of AI agents, voice agents, multi‑turn chatbots, RAG pipelines, or anything else built with LangChain or OpenAI.

## ⚙️ New Features
- **Jev** is now available in DeepEval, both in existing metrics and the latest JevEval.
- **Confident AI** surfaces failing traces before any eval is written, clusters them into failure modes, and converts them into the next eval.

## 🚀 Usage Benefits
- Use evaluations to determine the optimal models, prompts, and architecture.
- Helps prevent prompt drifting.
- Enables confident transition from OpenAI to Claude.
