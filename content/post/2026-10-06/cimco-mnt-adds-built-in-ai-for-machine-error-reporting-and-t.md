# CIMCO MNT Adds Built-In AI for Machine Error Reporting and Troubleshooting

CIMCO MNT now integrates built-in AI to help operators create clearer fault descriptions and assist technicians during troubleshooting by searching documentation linked to the machine.

## 🔍 Overview

When something goes wrong, quick and accurate error reporting makes it easier to get the right people involved and keep repair work moving. CIMCO MNT provides a complete workflow for reporting, assigning, resolving, and documenting errors.

## ⚙️ Key Details

- **Error reporting:** Operators can report an error as soon as it is discovered using the method that best fits the shop floor.
- **Reporting methods:** This can be done directly from a phone or tablet by scanning a QR code at the machine, through dedicated Operator Screens, or through other connected systems capable of sending data to MNT.
- **Starting an error report:** Even a short description is enough to get started.
- **AI assistance:** Built-in AI can improve the entered text or guide the operator through a few simple questions and use the answers to create a clearer and more useful fault description.
- **Prioritization and assignment:** Each error can be prioritised and assigned to the appropriate technician or team, helping maintenance teams see what needs attention and who is responsible.
- **Troubleshooting:** When repair work begins, technicians can use the documentation linked to the machine as part of the troubleshooting process. MNT’s built-in AI can search this documentation and bring forward relevant guidance, helping technicians find useful information without having to manually work through manuals and other files.
- **Documentation:** The repair work is documented in a Service Report, including what was done, who performed the work, time spent, and any materials or replacement parts used.
- **Searchable records:** Once completed, the Service Report provides a searchable record of both the original fault and the work carried out.
- **Notifications:** Automatic notifications can also keep relevant users informed as the error moves through the process.
