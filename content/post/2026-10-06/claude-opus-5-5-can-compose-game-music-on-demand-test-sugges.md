# Claude Opus 5.5 Can Compose Game Music on Demand, Test Suggests

A recent test indicates that Claude Opus 5.5 can compose competent computer game music on demand, using a simple text-based format and a built-in audio playback artifact. The test was run on 6th October 2026.

## 🔍 Overview

A user wanted to see if Claude Opus 5.5 could compose music, and instructed the model to write computer game music. The request specified designing a simple text-based format for the music and building an artifact that could play it out loud, including example tracks. The music was meant to match the quality of the original *Secret of Monkey Island*.

## 🧩 How It Works

The approach involved two steps:
- Design a simple text-based format for the music.
- Build an artifact (within the model's environment) that can play the music out loud, including example tracks.

## ⚙️ Key Details

The results were evaluated as follows:
- The output leaned heavily into the Monkey Island theme, more than intended.
- Despite that, the results were described as surprisingly good.

## 💡 Why It Matters

The test raises a question about whether composing competent music is a new capability for text models that emerged in the past few months — similar to 3D graphics generation. The user noted that careful experiments with other recent and not-so-recent models would be needed to confirm if this is new or if such abilities have existed for a while.
