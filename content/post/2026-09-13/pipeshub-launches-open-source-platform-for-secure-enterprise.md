# PipesHub Launches Open‑Source Platform for Secure Enterprise Knowledge‑AI Integration

PipesHub, an open‑source platform, enables secure connection of enterprise knowledge to AI applications.

## 🔍 Overview
- PipesHub is an open‑source platform for securely connecting enterprise knowledge to AI.
- It connects AI applications to knowledge stored across a company’s business systems.

## 🛠️ How it works
- Provides 50+ enterprise connectors (Slack, Google Drive, GitHub, Microsoft 365, Notion, etc.) for real‑time and scheduled indexing.
- Enables unified search across connected systems with citations to original documents.
- Search results are filtered by each user’s permissions (permission‑aware search).
- Retrieves information via a graph‑backed knowledge graph that captures relationships across data.
- Supports multimodal inputs including images, diagrams, scanned files, and voice.

## ⚙️ Key features
- **Explainable Answers** – grounded answers with precise block citations.
- **Permission‑Aware Search** – source‑level access controls.
- **Bring Your Own Model** – any LLM can be run in a VPC; data never leaves the infrastructure.
- **Unified Search & Agents** – search, Q&A, deep research, web search, and AI agents on one context.

## 🚀 Deployment
- Install with a single command:
```
curl -fsSL https://get.pipeshub.com/install | bash
```

## 💡 Why it matters
- Gives AI agents trusted context and teams permission‑aware search with verified citations.
- Keeps enterprise data self‑hosted and under full control.
- Enables developers to build agents, workflows, and MCP clients that leverage connected knowledge.
