# Agency Agents desktop app launches for AI agent management

Agency Agents has released a native desktop application for macOS, Linux, and Windows designed to manage and install collections of AI agent personalities into various development tools.

## 🔍 Overview
Born from a Reddit thread and months of iteration, The Agency provides a library of specialized AI agents. Each agent is designed as an expert with unique personality traits, established workflows, and defined deliverables.

## 🧩 How it works
Users can browse the agent roster and install selections into their preferred AI development environments. The installation process includes:

*   Generation of integration files for supported tools.
*   Interactive installation that auto-detects installed software.
*   Options to target specific tools or install only required teams.
*   Automatic updates to ensure agents remain current.

## ⚙️ Key details
Each agent file is structured to include:

*   Identity and personality traits.
*   Core mission and workflows.
*   Technical deliverables with code examples.
*   Success metrics and communication style.

## 🚀 Availability
The app supports installation into the following platforms:

*   Claude Code
*   Cursor
*   Codex
*   Gemini
*   Osaurus
*   OpenCode
*   Qwen

Note: The OpenCode runtime currently registers only approximately 119 agents, and the installer provides warnings if a selection exceeds this limit.
