# Abacus.AI Releases Smaug Model Family Optimized for Enterprise Agentic Workloads

On September 10, 2026, Abacus.AI released three open-weight language models specifically built for enterprise AI agents. The new lineup, consisting of Smaug Agentic, Smaug Flash, and Smaug Mini, utilizes a specialized fine-tuning technique applied to existing open-weight base models rather than training new architectures from scratch.

## 🔍 Overview

The Smaug line is designed for enterprise agentic workloads, which involve automation tasks such as reading documents, calling APIs, checking results, and self-correcting mistakes without human intervention. Each model in the family is built on a leading open-weight base to target a distinct point on the capability-efficiency curve.

## 🧩 How it works

What Abacus.AI calls “Smaug” is a fine-tuning technique applicable to any open-source base model. This methodology combines human-curated, real-world agentic traces with synthetic data grounded in hard examples. Abacus.AI says this method lifts the performance of long-running agentic loops by 15-20% without raising compute costs.

## ⚙️ Key details

The lineup consists of three distinct models tailored for different enterprise needs:

| Model Name | Base Model | Characteristics |
| :--- | :--- | :--- |
| Smaug Agentic | Moonshot AI Kimi K3 | A 2-trillion-parameter model built for complex coding and hard reasoning loops. |
| Smaug Flash | DeepSeek V4 Flash | Built for always-on agents requiring long context and heavy tool or API usage. |
| Smaug Mini | Qwen3.8 27B | A lighter, 27B-parameter model for cheap, high-volume multimodal tasks. |

Smaug Agentic sits closer to the size of frontier closed models, designed for tasks where an agent might spend dozens of steps writing, testing, and refactoring code. Smaug Mini is suited for smaller reasoning chains where a lighter model is more cost-effective to run at scale.

## 🚀 Availability

All three Smaug models are currently available through several channels:

*   **Hugging Face:** Model weights are available for download and can be fine-tuned or hosted anywhere, including a company's own cloud VPC.
*   **RouteLLM API:** Abacus.AI serves the models via its own API for teams that prefer not to manage their own inference infrastructure.
