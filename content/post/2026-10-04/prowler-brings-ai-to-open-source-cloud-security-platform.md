# Prowler Brings AI to Open Source Cloud Security Platform

Prowler, the world’s most widely used open-source cloud security platform, now includes AI-driven capabilities to automate security and compliance across any cloud environment. This update positions Prowler as a platform that can "Secure ANY Cloud at AI Speed," offering thousands of ready-to-use security checks and compliance frameworks.

## 🔍 Overview

Prowler is the Open Cloud Security Platform trusted by thousands to automate security and compliance in any cloud environment. With thousands of ready-to-use checks and compliance frameworks, Prowler delivers real-time, customizable monitoring and seamless integrations, making cloud security simple, scalable, and cost-effective for organizations of any size.

## ⚙️ Key Capabilities

Prowler now delivers **AI-driven**, **customizable**, and **easy-to-use** assessments, dashboards, reports, and integrations, making cloud security **simple**, **scalable**, and **cost-effective** for organizations of any size. Key features include:
- Thousands of ready-to-use security checks, remediation guidance, and compliance frameworks
- Prowler ThreatScore: Weighted risk prioritization scoring that helps you focus on the most critical security findings first

## 🏆 Supported Compliance Frameworks

Prowler includes hundreds of built-in controls to ensure compliance with a wide range of standards and frameworks:

| Category | Frameworks |
|----------|------------|
| Industry Standards | CIS, NIST 800, NIST CSF, CISA, and MITRE ATT&CK |
| Regulatory Compliance and Governance | RBI, FedRAMP, PCI-DSS, and NIS2 |
| Frameworks for Sensitive Data and Privacy | GDPR, HIPAA, and FFIEC |
| Organizational Governance and Quality Control | SOC2, GXP, and ISO 27001 |
| Cloud-Specific Frameworks | AWS Foundational Technical Review (FTR), AWS Well-Architected Framework, and BSI C5 |
| National Security Standards | ENS (Spanish National Security Scheme) and KISA ISMS-P (Korean) |
| Custom Security Frameworks | Tailored to your needs |

## 🚀 Availability

Prowler is available in two web application formats that simplify running Prowler across your cloud provider accounts:
- **Prowler Cloud**: A hosted web application
- **Prowler Local Server**: A self-hosted open-source version

Both provide a user-friendly interface to visualize the results and streamline your security assessments. For more details, refer to the Prowler Local Server documentation and try Prowler Cloud.

## 💡 Why It Matters

By integrating AI-driven assessments and threat prioritization into an open-source platform with thousands of built-in checks and extensive compliance framework support, Prowler makes cloud security more accessible and efficient for organizations of any size. The community is invited to join the Prowler community.
