# web-edit adds clipboard support for text and images

The web-edit web app now includes a copy‑to‑clipboard option for both text and image data.

## 🔍 Overview
- web-edit is a tiny web app for browsing and editing files in a folder.
- It was mainly built for editing files on different machines via Tailscale.

## 🛠️ New Feature
- Added a "copy to clipboard" option for text data.
- Added a "copy to clipboard" option for image data.
- Provides an easy way to copy logs from DeepSeek 4.1 Flash prompts run on a phone into a Gist.

## 🚀 Availability
- The copy‑to‑clipboard feature is now part of web-edit (no specific release date provided).
