# 3D FEA module added to Tcl/Tk-based software

A new 3D Finite Element Analysis (FEA) module has been developed for an existing Tcl/Tk-based FEA software package.

## 🧩 How it works
- The software is written in Tcl/Tk and is compatible with Tcl/Tk 8.0.
- It is designed to run on SGI machines.

## ⚙️ Key details
- The basic package is for 2D beam-only problems, sufficient for most civil engineering tasks.
- The 2D module works well and at acceptable speed on a 100 MHz MIPS R4000 CPU.
- Performance is slower for stability and dynamics tasks.
- A new 3D FEA module has been added to extend the software's capabilities.

## 🚀 Availability
- The software is used on SGI machines with Tcl/Tk 8.0 compatibility.
