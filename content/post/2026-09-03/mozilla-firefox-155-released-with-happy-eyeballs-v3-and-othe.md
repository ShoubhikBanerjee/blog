# Mozilla Firefox 155 released with Happy Eyeballs v3 and other updates

The open‑source Mozilla Firefox web browser has been updated to version 155 and is now available for download.

## 🔍 Overview
- Firefox 155 is the latest release of the community‑maintained web browser.
- It includes support for Happy Eyeballs v3, which aims to reduce page‑load latency.
- The release also brings a variety of other changes.

## ⚙️ Key details
- **Happy Eyeballs v3**: Improves connection selection for faster page loading.
- **Open‑source**: The browser continues to be distributed under an open‑source license.
- **Downloadable now**: The new version can be obtained from Mozilla’s official download channels.

## 🚀 Availability
- Firefox 155 is ready for immediate download.
- Users can replace older versions or install it fresh on supported operating systems.

## 💡 Why it matters
- Faster page loading enhances the browsing experience for all users.
- Ongoing open‑source development ensures community transparency and continued improvement.
