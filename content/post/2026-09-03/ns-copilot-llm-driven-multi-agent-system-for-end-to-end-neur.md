# NS-Copilot: LLM‑Driven Multi‑Agent System for End‑to‑End Neuroscience Analysis

A new system called NS‑Copilot has been introduced that uses large language models and a multi‑agent architecture to automate neuroscience data analysis.

## 🔍 Overview
- NS‑Copilot is an LLM‑driven multi‑agent system for neuroscience analysis.
- It autonomously supports end‑to‑end workflows for diverse professional tasks.
- The system unifies domain‑specific pre‑trained models.
- It supports key neuroscience modalities, including EEG and extracellular spike data, through a natural‑language interface.

## 🧩 How it works
- Given raw data and a task description, NS‑Copilot orchestrates agents with specialized roles:
  - Planning
  - Adaptive control
  - Code generation
  - Result synthesis
- This orchestration enables analysis without dataset‑specific heuristics.

**Supported modalities**
| Modality | Supported |
|----------|-----------|
| EEG | ✅ |
| Extracellular spike data | ✅ |

## 📊 Evaluation
- NS‑Copilot was evaluated on neuroscience benchmarks spanning:
  - Alzheimer’s disease
  - Parkinson’s disease
  - Working memory spike decoding
- Across 8 trials per task, the system consistently outperformed strong baselines on the primary metric.

## 💡 Why it matters
- Demonstrates effective and scalable neuroscience analysis using LLM‑driven multi‑agent coordination.
- Reduces the need for hand‑crafted, dataset‑specific heuristics.
- Provides a natural‑language interface that can streamline complex analytical pipelines for researchers.
