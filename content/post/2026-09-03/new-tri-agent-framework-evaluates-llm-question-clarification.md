# New tri-agent framework evaluates LLM question clarification

Researchers have introduced a novel tri-agent framework to evaluate an LLM's ability to engage in clarifying dialogue, particularly for ambiguous or underspecified user queries in interactive systems.

## 🔍 Overview
Large Language Models (LLMs) are increasingly used in systems where precise understanding of user intent is critical. A key challenge is effective question clarification, which this framework aims to address.

## 🧩 How it works
The framework consists of three LLM-based agents:

| Agent | Role |
|-------|------|
| Question Clarifying Agent (QCA) | System under evaluation; identifies ambiguities and poses clarifying questions |
| Respondent Agent (RA) | Simulates human user responses, including irrelevant or challenging replies |
| Evaluator Agent (EA) | Assesses dialogue quality using a comprehensive set of metrics |

## ⚙️ Key details
- The framework includes a methodology for synthetic data generation, demonstrated in the supply chain domain.
- Metrics evaluate ambiguity handling, question quality, dialogue efficiency, language appropriateness, and final intent alignment.
- The Evaluator Agent (EA) is validated against human judgments.

## 💡 Why it matters
This work provides a structured approach to benchmark, validate, and improve the clarification capabilities of conversational LLM applications.
