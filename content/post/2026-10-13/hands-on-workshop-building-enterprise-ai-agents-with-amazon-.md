# Hands-On Workshop: Building Enterprise AI Agents with Amazon Bedrock AgentCore

Amazon is hosting an in-person workshop to teach participants how to build production-ready AI agents using Amazon Bedrock AgentCore. This interactive session is designed to take attendees through the essential components of building and deploying AI agents in a secure, scalable environment.

## 🔍 Overview

The workshop focuses on AgentCore's modular architecture, offering direct experience through guided exercises and real-world scenarios. Participants will learn to harness the power of Amazon Bedrock AgentCore to build and deploy AI agents in a secure, serverless environment.

## 🧩 How it works

The session starts with the fundamentals of agent deployment using AgentCore Runtime. It progresses through practical implementations of authentication, service integration, and advanced tool utilization. Attendees will work through each component of the architecture to understand how to implement browser automation and code execution.

## 🚀 Availability

The event is IN PERSON. A laptop with an internet connection is required; AWS will provide everything else needed to start building with AgentCore.

## 💡 Why it matters

By attending, participants will gain the skills to:

*   Configure authentication and access controls with AgentCore Identity
*   Create and manage API integrations through AgentCore Gateway
*   Set up persistent memory management for agents
*   Establish effective monitoring and observability practices
