# Anthropic Offers Hands‑On Claude Code Workshop for Technical Teams

Anthropic announced a hands‑on workshop focused on Claude Code for technical leaders, architects, and engineers.

## 🔍 Overview
- Designed for technical leaders, architects, and engineers ready to move beyond demos to implementation.

## 🛠️ What you’ll do
- Get comfortable using Claude Code.
- Build working prototypes you can use immediately.
- Have your questions answered in real‑time.
- See firsthand how to use Claude Code for enterprise development workflows.
- Learn best practices for integrating Claude Code into your environment.
- Build working code on your own machine.
- Receive direct support from Anthropic engineers and Bounteous teams.

## ⚙️ Key details
- Session size limited to 30 participants.
- By submitting, you acknowledge the Anthropic Privacy Policy.
