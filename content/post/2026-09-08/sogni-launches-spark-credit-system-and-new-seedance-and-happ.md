# Sogni Launches Spark Credit System and New Seedance and HappyHorse Models

Sogni has introduced a unified credit system called Spark to power its suite of SuperApps, SDK, and creative workflows. Alongside this new payment infrastructure, Sogni has released several upgraded models for image and video generation that require Premium Spark for access.

## 🧩 How it works
Spark credits function as a universal currency across Sogni services. One Spark is equivalent to the baseline SDXL fast render value, with an internal value pegged at $0.005 USD per unit of GPU inference time. Users can purchase Premium Spark via Stripe for pay-as-you-go access, or prepay using USDC or USDT on Base, Etherlink, or Ethereum at dashboard.sogni.ai.

## ⚙️ Key details
Premium Spark is required to access premium model gates and external API models. Specific model requirements include:

| Model | Capabilities | Requirements |
| :--- | :--- | :--- |
| Seedance 2.0 Mini | 480p and 720p resolution | Premium Spark |
| Seedance 2.0 | 480p, 720p, 1080p, 4K; up to 12 reference assets | Premium Spark |
| Seedance 2.5 | 480p and 720p; multimodal reference path | Premium Spark |
| HappyHorse 1.1 | 720p, 1080p; synchronized audio and lip-sync | Premium Spark |

## 🚀 Availability
- Seedance 2.5 supports up to 30 media items per request, including reference images, videos, and audio clips.
- HappyHorse 1.1 generations range from 3-15 seconds at a fixed 24fps across various aspect ratios, including 16:9, 9:16, and 1:1.
- The Sogni model gpt-image-2 is restricted to Premium Spark users only.
- Premium Spark access for Seedance and HappyHorse models includes credit-card premium coverage checks.
