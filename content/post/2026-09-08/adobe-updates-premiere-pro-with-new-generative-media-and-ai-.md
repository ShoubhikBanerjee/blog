# Adobe Updates Premiere Pro with New Generative Media and AI Audio Tools

Adobe is overhauling how editors interact with AI in its Premiere professional video editing software, introducing a dedicated interface for generative media directly within the project timeline.

## 🧩 How it works
Editors can now highlight an empty gap on video or audio tracks to generate content without leaving the software. The new Generative Media tool allows for the creation of video, sound effects, music, and soundscapes, eliminating the need to use browsers or external applications to source missing assets.

## ⚙️ Key details
Editors can select from several underlying models directly within the timeline to suit specific project styles:

| Model Name | Capability |
| :--- | :--- |
| Adobe Firefly | Generative Media |
| Google Veo | Generative Media |
| Runway | Generative Media |
| Luma | Generative Media |
| Kling | Generative Media |

## 🎙️ New AI Audio Capabilities
Premiere is receiving new AI-powered audio tools in beta, including:
* Separation of overlapping speakers.
* Automatic music ducking under speech.
* Independent adjustment of dialogue and ambience.

## 🛠️ After Effects Integration
Adobe is also bringing its AI Assistant to After Effects in beta. This feature supports plain-language commands to help editors organize projects, fix technical issues, and create effects without the manual use of expressions.
