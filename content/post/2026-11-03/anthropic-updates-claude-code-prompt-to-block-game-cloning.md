# Anthropic Updates Claude Code Prompt to Block Game Cloning

Anthropic has modified Claude Code’s system prompt to prevent the model from being used to recreate existing video games.

## 🔍 Overview
- Retro gaming is currently being overrun with AI‑made decompilations, recompilations, and ports.
- Anthropic says it will still let people use Claude Code to make games, but it does not want the tool used for direct clones of specific titles.

## 🛠️ Prompt Change
- Two new sentences were added to Claude Code’s prompt on Opus 5.5:
  - **“Do build original games, games in a genre, and games from the user’s own designs and assets.”**
  - **“Don’t build a recreation of a specific existing game, even if it is named or called original.”**
- The change is intended to steer Claude away from recreating someone else’s specific game because using Claude to infringe IP is against Anthropic’s usage policy.

## 🎮 What Developers Can Still Do
- Create original games.
- Build games that fit a particular genre.
- Develop games using the user’s own designs and assets.

## 📜 Policy and Next Steps
- Anthropic’s Addy Osmani said the update is part of ensuring the model complies with the IP usage policy and that “original games, genre games, and games built from your own designs and assets are meant to keep working.”
- The company will continue to iterate to strike the right balance.
- If Claude rejects a request that the user believes is theirs, they are invited to forward it to Anthropic for review.
- Anthropic has been asked whether other Claude system prompts will be updated as well.
