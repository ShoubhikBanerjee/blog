# Indegene Deploys LLM‑Powered Data Quality Agent on AWS for Life Sciences

Indegene has launched a production‑grade, large language model (LLM)‑powered Data Quality Agent inside its NEXT Unified Data Platform (NEXT UDP) on Amazon Web Services. The agent automatically creates context‑aware data‑quality rules, validates them, and generates ready‑to‑run SQL and Python code, all under a centralized, human‑in‑the‑loop governance model.

## 🔍 Overview
- Indegene Limited (BSE: 544172, NSE: INDGN) is the strategic operating partner to the life‑sciences industry, serving the world’s top 20 biopharma companies.
- NEXT UDP is an AI‑driven data platform that unifies commercial, medical, clinical, and enterprise data into a governed environment.
- The platform includes a suite of standalone AI agents; the Data Quality agent is the focus of this update.

## 🧩 How it works
1. **Data profiling** – The agent examines a new dataset to understand its structure and content.
2. **Rule generation** – Using LLM reasoning, it produces context‑aware technical and business rules (e.g., HCP ID format, product market‑share totals).
3. **Validation** – Generated rules are automatically validated against the data.
4. **Code output** – The agent emits executable SQL and Python scripts that implement the validated rules.
5. **Governance** – All outputs are subject to human‑in‑the‑loop review before deployment, satisfying strict life‑science compliance requirements.

## ⚙️ Key capabilities
- **Context‑aware rule creation** – blends technical checks (null, format, uniqueness) with business logic (market‑share percentages, specialty‑aligned prescription activity).
- **Multi‑language code generation** – produces both SQL and Python ready for immediate execution.
- **Centralized governance** – human oversight is built into the pipeline to meet regulated‑industry standards.
- **Scalable production** – runs reliably in a production environment on AWS.

## 📊 AI agents in NEXT UDP
| Agent | Primary function |
|-------|------------------|
| Data Ingestion agent | Automates data intake and preprocessing |
| Data Quality agent | Generates, validates, and codifies data‑quality rules |
| Orchestration agent | Coordinates workflow execution across agents |
| Data Catalog agent | Maintains metadata, lineage, and searchable catalog |
| SQL Bot Generator agent | Produces SQL snippets for ad‑hoc queries |

## 🚀 Benefits for life‑science organizations
- Consolidates fragmented enterprise data into a trusted source of truth.
- Standardizes data‑quality and governance across multiple business domains.
- Improves metadata visibility, lineage, and traceability.
- Reduces manual effort across data‑engineering workflows.
- Delivers trusted, AI‑ready data for analytics and decision‑making.

## 🗺️ Availability
- The Data Quality agent is deployed within NEXT UDP on AWS and is available to Indegene’s life‑science clients as part of the platform’s managed services.
