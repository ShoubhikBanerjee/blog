# NVIDIA NeMo Agent Toolkit Adds Amazon S3 Vectors for Persistent Agent Memory

NVIDIA’s open‑source NeMo Agent Toolkit (NAT) now integrates Amazon S3 Vectors as a persistent memory backend, allowing agents deployed on Amazon EKS to store and retrieve long‑term knowledge with elastic scale.

## 🔍 Overview
- Open‑source framework for building, profiling, and optimizing AI agents.
- Framework‑agnostic; works with Strands Agents, LangChain, LlamaIndex, CrewAI, and custom implementations.
- Four core capabilities: Agent orchestration, Profiling, Evaluation, Optimization.
- Agents are defined as composable workflows with configurable LLMs, tools, and prompts.
- Execution options: `nat run` locally or `nat serve` as a persistent service.

## 🧩 How it works
- Includes a dedicated memory subsystem that stores conversation history, user preferences, and long‑term knowledge.
- Memory module is extensible via a plugin interface; custom providers implement the `MemoryEditor` abstract interface (`add_items()`, `search()`, `remove_items()`).
- `MemoryItem` model holds conversation history, tags, metadata, user_id, and an optional textual memory string.
- Provider discovery uses the `_type` field in a YAML configuration.
- The `auto_memory_agent` workflow automatically captures and retrieves memory without explicit LLM calls.
- Amazon S3 Vectors serves as a memory backend: vectors are 1024‑dimensional embeddings generated by Amazon Titan Text Embeddings V2, stored with scoped metadata, and searchable with semantic similarity.

- Semantic retrieval with configurable distance metrics (cosine, euclidean).
- Filterable metadata (strings, numbers, Booleans, lists) on each vector.
- Memories become visible immediately after insertion.
- Scale to 2 billion vectors per index with no capacity planning.
- Pay‑as‑you‑go pricing; no idle compute costs.
- IAM policies per bucket and index; per‑tenant indexes provide hard isolation.

## 🚀 Deployment
- Deployed on Amazon Elastic Kubernetes Service (EKS) for full operational control.
- Requires Python 3.11 or 3.12; NAT version 1.6 tested.
- Memory plugin integrates Amazon Titan Text Embeddings V2 (1024 dimensions) and translates search filters into S3 Vectors metadata queries.

## 💡 Why it matters
- Provides persistent, scalable memory for multi‑agent workflows.
- Enables detailed profiling of token usage, latency, throughput, and runtimes.
- Supports automated hyper‑parameter tuning to balance quality, cost, and latency.
- Leverages AWS’s elastic storage and security model for isolated, cost‑effective deployments.
