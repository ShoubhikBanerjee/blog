# Hands‑On “Colab and Chill” Workshop Teaches AI‑Assisted Data Science

A new hands‑on workshop called “Colab and Chill” was announced for Wednesday, October 14, 2026.

## 🎯 Overview
- Date: Wednesday, October 14, 2026
- Time: 10:00 am – 11:30 am
- Location: South Learning Lab 3430, Hill Library
- No software installation is needed
- The session is “relaxed, hands‑on” and brings the “vibe coding” philosophy to data science
- Participants are invited to “code by conversation” and leave with a reusable workflow for any dataset

## 🛠️ What You’ll Learn
- **Navigate the AI Landscape** – Differentiate between “Knower” tools (e.g., NotebookLM) and “Doer” tools (e.g., Gemini) to select the appropriate AI assistant for specific research stages.
- **Engineer Effective Prompts** – Apply the PARTS framework (Persona, Aim, Recipients, Theme, Structure) to craft precise prompts that guide AI in generating relevant analysis outputs.
- **Perform AI‑Assisted EDA** – Use Google Colab’s integrated AI features to generate visualizations, statistical summaries, and cleaning scripts without writing code from scratch.
- **Mitigate Hallucinations** – Implement the “code generation” strategy—asking AI to write code rather than perform mental math—to ensure reproducibility and accuracy.

## 📊 Tools Highlighted
| Tool | Role |
|------|------|
| NotebookLM | “Knower” – synthesis and knowledge retrieval |
| Gemini | “Doer” – execution and code generation |
