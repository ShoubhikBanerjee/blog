# Claude Code Implementation Leads to Workflow Shifts at Large Company

A shift in software development operations at a large company has centralized the creation of project documentation and technical assets around Claude Code. Engineers are reporting that all technical deliverables are being generated by the tool, resulting in a significant change to daily work routines.

## ⚙️ Key Details
- Claude Code is now responsible for generating specs, code, tests, PRDs, tickets, ticket resolutions, and reports.
- Engineers ranging from L1 to L7 levels are primarily tasked with reviewing and submitting the output provided by the model.
- The current workflow requires staff to work 12 to 13-hour days to manage these submissions.

## 💡 Why it Matters
- Management has indicated that code velocity is not a bottleneck, despite the increased internal pressure to ship as much as possible.
- There is internal friction regarding the implementation, as team members report that they do not review the generated content, and the team does not prefer the current automated process.
