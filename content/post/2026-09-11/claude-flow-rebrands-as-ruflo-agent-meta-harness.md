# Claude Flow Rebrands as Ruflo Agent Meta-Harness

Claude Flow has been renamed to Ruflo, an agent meta-harness designed for Claude Code and Codex. It serves as the execution layer that provides models with tools, memory, loops, sandboxes, and controls to enable autonomous workflows.

## 🔍 Overview
Ruflo acts as a "nervous system" for Claude Code, allowing agents to self-organize into swarms and collaborate. Users can initialize the system with `npx ruflo init`, after which the hooks system automatically routes tasks and coordinates agents in the background without requiring the user to learn 314 MCP tools or 26 CLI commands.

## 🧩 How it works
Ruflo operates on the principle that an Agent = Model + Harness. While the model handles the writing, the Ruflo harness provides the following:

* **Coordination**: Deploys intelligent multi-player swarms and autonomous workflows.
* **Memory**: Features adaptive, self-learning memory that remembers across sessions.
* **Federation**: Enables secure communication between agents on different machines without leaking data.
* **Integration**: Native support for Claude Code, Codex, Hermes, and vector RAG integration.
* **Security**: Includes enterprise security guardrails.

## ⚙️ Key details
Ruflo is released under the MIT License and provides a 14-chapter guide covering topics from initial tasks and memory to agent teams, plugins, cost, and verification.
