# Datasette Releases Security Patches Developed with Frontier AI Models

Datasette has released two new security patch versions, 1.0a39 and 0.65.4, following a security audit conducted using frontier AI models.

## 🚀 Availability

Security fixes are available for the following versions:
* 1.0a39 (current alpha series)
* 0.65.4 (stable 0.65.x family)

These patches are recommended for users running Datasette instances on the public web, specifically those mixing public and private tables.

## ⚙️ Key details

Following issues reported by Sevban Dönmez, Alex Garcia and a collaborator conducted an audit using the following models:

| Model | Role |
| :--- | :--- |
| Claude Fable 5.1 | Security Audit |
| GPT-5.6 | Security Audit |
| GPT-6 Astra | Security Audit |

Development of the fixes took place over nearly a week in a shared private repository. For most issues, one person created automated tests to highlight the problem, while the other implemented the fix.

## 💡 Why it matters

Datasette will be incorporating security audits by frontier models into all of its development work going forward.
