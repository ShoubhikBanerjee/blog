# Shopify Returns to Swift and Kotlin Codebases for Native Apps

Shopify is moving from React Native back to separate Swift and Kotlin codebases for its native applications.

## 💡 Why it matters
In 2020, Shopify switched to React Native for three reasons:
* Stop building the same features twice
* Allow developers to work across the stack
* Spend less time chasing feature parity and more time shipping value

Shopify states that agents can now handle enough of the implementation, translation, testing, and review work that those factors are no longer the deciding factors they were in 2020.

## ⚙️ Key details
Shopify is the maintainer of three significant React Native libraries. Their status is as follows:

| Library | Status |
| :--- | :--- |
| react-native-skia | Finding a new home |
| flash-list | Finding a new home |
| restyle | To be archived at the end of 2026 (noted as having a smaller user base than other libraries) |
