# Introduction of SEC535 AI Security Defense Course and GOAA Certification

A new training path centered on AI security has been introduced, featuring the SEC535 course and the GIAC Offensive AI Analyst (GOAA) certification to address threats leveraging artificial intelligence.

## 🔍 Overview
AI security involves the tools, techniques, and strategies required to protect against threats that use artificial intelligence while securing AI systems. The SEC535 course focuses on defensive approaches against offensive AI tools used by adversaries to position students as specialists in AI security defense.

## 💡 Why it matters
Professionals can utilize the GIAC Offensive AI Analyst (GOAA) certification to validate their ability to apply real-world offensive AI techniques to cybersecurity challenges. Certified individuals prove proficiency in advanced tactics, including:

* AI-driven attack simulations to emulate sophisticated adversaries
* Automated vulnerability discovery
* Deepfake-enabled phishing

## ⚙️ Key details
### Student Requirements
Students should possess a basic understanding of AI/ML concepts, familiarity with enterprise security architecture, and a solid foundation in cybersecurity principles. Python programming experience is beneficial but not required.

### System Requirements
* Students must bring their own system configured according to provided instructions.
* Systems should be backed up before class.
* It is strongly advised not to use a system storing sensitive data.
* Course media, which can be 40 - 50 GB in size, is delivered via download and is required on the first day of class.

### Learning Path

| Stage | Course/Certification |
| :--- | :--- |
| Start | SEC401: Security Essentials - Network, Endpoint, and Cloud |
| Progress | SEC504: Hacker Tools, Techniques, and Incident Handlings |
| Core | SEC535 |
| Continue | SEC699: Advanced Purple Teaming - Adversary Emulation & Detection Engineering |
| Continue | FOR508: Advanced Incident Response, Threat Hunting, and Digital Forensics |

## 🚀 Availability
Learning options include:
* Online
* On demand
* Live in-person training events
