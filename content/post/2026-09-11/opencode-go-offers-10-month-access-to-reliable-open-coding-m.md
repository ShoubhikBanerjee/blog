# OpenCode Go Offers $10/month Access to Reliable Open Coding Models

OpenCode has launched OpenCode Go, a $10‑per‑month subscription that provides reliable, low‑latency access to popular open‑source coding models.

## 🔍 Overview
- Open models now perform close to proprietary models on coding tasks.
- Reliable, low‑latency access to these models can be difficult because provider quality and availability vary.
- OpenCode Go addresses this gap with a stable global service, especially for international users.

## 🧩 How it works
- Subscribe to OpenCode Go and receive an API key.
- The service functions like any other provider in the OpenCode platform.
- It is optional; users can still use OpenCode without the subscription.
- Designed for OpenCode and similar coding agents that send comparable request types.
- Traffic is monitored to prevent abuse that could degrade other users’ experience.

## ⚙️ Key details
- Pricing: $10 per month.
- Usage limits are expressed as monthly dollar amounts; each model enforces:
  - 5‑hour limit: 20 % of the monthly limit
  - Weekly limit: 50 % of the monthly limit
  - Monthly limit: 100 % of the monthly limit
- Token pricing is listed per 1 M tokens (exact amounts are model‑specific).
- The list of available models may change as new models are tested and added.
- The x‑opencode‑session header request remains open, but sending that header is no longer required.
- Clients beyond OpenCode have been validated, though future support is not guaranteed and some have incomplete session support.

## 🚀 Availability
- Subscription costs $10/month and provides stable global access.
- Primarily aimed at international users seeking consistent performance.
- Works with the latest version v0.81.6 or later, which includes the session‑header fix.

## 💡 Why it matters
- Open models have improved to near‑proprietary performance, offering a cheaper alternative for coding tasks.
- Because many providers can serve these models competitively, costs are generally lower than closed‑source options.
- OpenCode Go bundles reliable, low‑latency access into a simple subscription, reducing the overhead of managing multiple providers.
