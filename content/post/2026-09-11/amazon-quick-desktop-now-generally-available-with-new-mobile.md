# Amazon Quick Desktop Now Generally Available with New Mobile Activity Feed

Amazon Quick is now generally available as a desktop application for macOS and Windows, following a preview period used by customers in healthcare, sports, and manufacturing.

## ⚙️ Key details
Quick is built on existing organizational tools, systems, and infrastructure, requiring no migration or new ecosystem adoption. It runs on AWS and includes several security and compliance features:
* **Compliance:** Built-in certifications for HIPAA, FedRAMP, SOC 2, and ISO 27001.
* **Privacy:** Data remains in the user's environment and conversations remain private.
* **Auditability:** Full audit trails are provided via AWS CloudTrail and Amazon CloudWatch.

## 🧩 How it works
Quick utilizes agents and shared workspaces to synthesize information and automate tasks:

| Feature | Function |
| :--- | :--- |
| Shared Workspace | Makes dashboards, agents, and automations available to the whole team |
| Asynchronous Agents | Allows users to go from concept to working prototype quickly and run tasks on their behalf |
| Task Execution | Synthesizes information across systems, drafts deliverables, updates records, and executes follow-ups |
| Natural Language Query | Allows teams to ask complex questions and receive grounded answers in seconds |

## 🚀 Availability
* **Desktop:** Generally available on Windows and macOS.
* **Mobile:** A new activity feed is being added to iOS and Android. This feed consolidates signals from CRM, calendar, messaging, and email into a prioritized view based on patterns, priorities, and relationships. Items resolved by agents automatically disappear from this view.

## 💡 Why it matters
Southwest Airlines is using Amazon Quick to build autonomous agents and agentic AI tools to streamline operations for over 70,000 employees and enhance customer experiences. The organization reports that Quick has significantly cut time-to-insight and is powering high-impact use cases such as market analytics.
