# Clay Rebuilds AI Agent with Coding Harness and Custom Data Layer

## 🔍 Overview
Clay rebuilt its AI agent, Sculptor, from a limited tool-calling system into a coding agent on the Pi harness, adding a new data layer called Audiences to unify CRM and Gong data. The new system allows the agent to run the Clay CLI in a cloud sandbox and use off-the-shelf open-weight models that are significantly cheaper than Opus. Since acquiring Avenue in 2023, Clay has grown from about 50 to around 600 people and recently raised $115 million at a $7.1 billion valuation. The company also launched an automatic router that selects the best model for each task and shipped 25 to 30 new integrations.
