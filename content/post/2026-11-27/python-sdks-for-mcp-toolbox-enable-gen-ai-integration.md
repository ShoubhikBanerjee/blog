# Python SDKs for MCP Toolbox Enable Gen AI Integration

A new set of Python SDKs has been released to let developers interact with the MCP Toolbox for Databases from their generative AI applications.

## 🔍 Overview
These SDKs are designed to seamlessly integrate the functionalities of the MCP Toolbox into Gen AI applications. They allow you to load tools defined in Toolbox and use them as standard Python functions or objects within popular orchestration frameworks or your custom code.

## 🧩 Packages
| Package | Integration | Path | Guide |
|---|---|---|---|
| `toolbox-core` | Framework-agnostic / Custom apps | `packages/toolbox-core/` | Python Core Guide |
| `toolbox-adk` | Google ADK Integration | `packages/toolbox-adk/` | ADK Package Guide |
| `toolbox-langchain` | LangChain / LangGraph Integration | `packages/toolbox-langchain/` | LangChain Guide |
| `toolbox-llamaindex` | LlamaIndex Integration | `packages/toolbox-llamaindex/` | LlamaIndex Guide |

## ⚙️ Installation
- Set up the Toolbox Service: Ensure you have a running MCP Toolbox server (follow the MCP Toolbox Server Getting Started Guide).
- Install the appropriate SDKs:
  - `pip install toolbox-adk`
  - `pip install toolbox-core`
  - `pip install toolbox-langchain`
  - `pip install toolbox-llamaindex`
