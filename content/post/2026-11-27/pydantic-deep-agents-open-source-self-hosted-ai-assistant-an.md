# Pydantic Deep Agents: Open‑Source, Self‑Hosted AI Assistant and Framework

Pydantic Deep Agents releases an open‑source terminal AI assistant and Python framework. It lets you point any model—Claude, GPT, Gemini, or a local model—to the same harness.

## 🔍 Overview

Pydantic Deep Agents is an open‑source, self‑hosted terminal AI assistant and Python framework. It lets you point any model—Claude, GPT, Gemini, or a local model—to the same harness.

## 🧩 How it works

- The assistant runs on Pydantic AI.
- It can plan, edit files, run shell commands, search the web, remember across sessions, spawn sub‑agents, and connect to MCP servers.
- The single function call `create_deep_agent()` provides a model with a filesystem, shell, planning, memory, sub‑agents, sandboxed execution, MCP, and unlimited context.
- Live Run Forking splits a single run into parallel branches; an AI judge merges the branches back together.
- When an agent faces a decision point (e.g. "should I refactor this with a decorator or a context manager?" ), the fork‑and‑merge mechanism allows exploring both options.

## ⚙️ Key details

| Feature | Description |
|---------|-------------|
| Type safety | 100 % type‑safe |
| License | MIT for the assistant and framework; Apache‑2.0 for Agenticos |
| Model support | Claude, GPT, Gemini, local |
| Runtime | Self‑hosted terminal AI assistant |
| Harness | Same code used for the single‑function `create_deep_agent()` |

## 🚀 Availability

- Install it locally and point it at any model.
- Use it today, or ship your own agent in one function call.
- The repo contains both the terminal assistant and the Python framework.

## 💡 Why it matters

- Provides a unified, open‑source alternative to commercial assistants like Claude Code.
- Enables teams to use a sovereign, self‑hosted AI layer with budgets, approvals, guardrails, and activity tracking via Agenticos by Vstorm.
- The fork‑and‑merge runtime supports parallel reasoning paths, giving developers more flexibility when designing agent behavior.
