# OpenAI Adjusts GPT-6.2 Usage Limits Following Billing Error

OpenAI has confirmed a fix for a billing bug that incorrectly discounted usage for GPT-6.2 Astra and Sol models. This adjustment means that performing the same tasks will now consume more of a user's plan allowance than previously recorded.

## ⚙️ Key Details

The correction affects usage rates differently depending on the specific model being utilized:

| Model | Change in Limit Consumption |
| :--- | :--- |
| GPT-6.2 Astra | 40% faster |
| GPT-6.2 Sol | 25% faster |

Despite these changes, OpenAI stated that both models maintain better usage efficiency compared to their predecessors, GPT-6 Astra and GPT-6.1 Sol. This update only impacts GPT-6.2 Astra and Sol; other models retain their existing usage calculations.

## 💡 Compensation for Users

OpenAI stated it will not charge users for the discrepancy caused by the billing mistake. As an apology for the disruption, the company is providing an additional usage reset to subscribers on Go, Plus, Pro, and Business plans.

* The banked reset can be accessed in ChatGPT under Settings > Usage by clicking the 'Reset' button.
* This additional reset expires one month after being added to the account.
* The reset allows users to restore exhausted usage limits.
