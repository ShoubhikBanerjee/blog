# agent_learning: An Open-Source AI Agent Development Textbook

An open-source AI Agent textbook and learning repository called `agent_learning` has been released to address the skill gap between calling an LLM API and building a complete Agent system. The resource provides a systematic tutorial covering the full lifecycle of agent development, from foundational concepts to production deployment.

## 🧩 How it works
The textbook is structured to guide developers through the core components of agentic systems. It covers the transition from basic capabilities to advanced deployment strategies, including:
- **Core Capabilities**: Function calling, memory systems, planning, RAG, and context engineering.
- **Advanced Topics**: Agentic RL, multi-agent systems, and self-evolving agents.
- **Production Readiness**: Evaluation, security, and deployment pipelines.

The curriculum includes 26 chapters organized across six main areas: foundations, core capabilities, frameworks, multi-agent systems, production, and capstone projects. The material bridges theoretical papers and practical application by providing explanations for techniques such as ReAct, Reflexion, MemGPT/Letta, GraphRAG, and GRPO.

## ⚙️ Key details
The repository is designed for bilingual accessibility and includes substantial visual aids to support complex concepts. 

| Feature | Description |
| :--- | :--- |
| **Language Support** | English and Chinese editions with matching tables of contents |
| **Visual Resources** | 330+ original SVG diagrams and 5 interactive demos |
| **Practical Baseline** | `reference-agent/` folder with a runnable baseline including tools, memory, and security gates |
| **Code Structure** | Separate sources for English (`src/en/`) and Chinese (`src/zh/`) mdBooks |

The chapter structure includes specific deep dives into:
- **Frameworks**: LangChain, LangGraph, OpenClaw, Hermes Agent, Claude Code, and OpenCode V2.
- **Techniques**: Harness Engineering, Skills, and Context Engineering.
- **Advanced Systems**: Multimodal Agents and DeepSeek Harness.

## 💡 Why it matters
The `agent_learning` repository is explicitly designed for developers who have moved past simple API integration and need to build, evaluate, secure, and deploy Agent systems. By combining theoretical paper-to-practice explanations with runnable code baselines and interactive demos, it serves as a comprehensive reference for both individual developers and teams looking to standardize their AI agent development workflows.
