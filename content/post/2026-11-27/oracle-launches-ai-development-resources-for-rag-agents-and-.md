# Oracle Launches AI Development Resources for RAG, Agents, and Database Integration

Oracle has released a suite of technical resources to help developers build AI applications, agents, and systems using Oracle AI Database and OCI services. These materials include reference apps, notebooks, and workshops covering RAG, vector and hybrid search, AI agents, and agent memory, with practical examples using LangChain and LangGraph. The repository provides complete, working examples that showcase end-to-end implementations, including source code, deployment configurations, and documentation for understanding architectural patterns and best practices.

## 📚 Available Resources

- Reference apps, notebooks, and workshops for RAG, vector and hybrid search, AI agents, and agent memory
- Integration examples using LangChain and LangGraph
- Applications demonstrating AI-powered solutions with Oracle technologies
- Complete, working end-to-end implementations with source code and deployment configs

## 🧪 Featured Implementations

| Application | Description |
|-----------|-------------|
| Gamified fitness platform | Built with Oracle 26ai JSON Duality Views (FastAPI + Redis), created live during a webinar |
| Intelligent RAG system | Multi-agent Chain of Thought (CoT), PDF/Web/Repo processing, with Oracle AI Database 26ai integration |
| Financial services AI agent | Uses Oracle AI Database as a unified memory core for vector, graph, spatial, and relational queries |
| Next.js chatbot | Pairs Oracle AI Database 26ai SQL, vector, and hybrid search with typed generative UI components |
| Full-stack AI application | Oracle JET UI, OCI Generative AI integration, Kubernetes deployment, and Terraform infrastructure |
| AI chat app | Uses TanStack Start and Oracle 26ai Select AI to query a shoe store database with natural language |
| Team knowledge base | Slack, GitHub and docs connectors; in-database ONNX embeddings; Oracle Text + vector hybrid retrieval with RRF through langchain-oracledb; per-caller access control via DBMS_RLS row policy; exposed to Claude Code over MCP and LangChain create_agent CLI |
| AI agent harness | Migrates RAG corpus from MongoDB into Oracle AI Database 26ai while preserving vector search and enabling SQL/JSON Duality queries |

## 🔧 Key Technologies

- Oracle AI Database 26ai with JSON Duality Views
- Vector and hybrid search capabilities
- langchain-oracledb for integration
- DBMS_RLS for row-level security and access control
- ONNX embeddings processed in-database
- Support for LangChain and LangGraph frameworks
- OCI Generative AI service integration
- Kubernetes and Terraform for deployment
