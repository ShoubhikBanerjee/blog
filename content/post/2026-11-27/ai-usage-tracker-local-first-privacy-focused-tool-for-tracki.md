# AI Usage Tracker: Local-First, Privacy-Focused Tool for Tracking AI Coding Costs

AI Usage Tracker, formerly Claude Usage Tracker, is a local-first tool that automatically discovers and aggregates your AI coding usage across 10+ development tools — covering both Anthropic Claude and OpenAI Codex.

## 🔍 Overview

It scans known data directories, parses JSONL/log files, calculates costs using model-specific pricing, and presents everything in a beautiful dark-themed interactive dashboard powered by Chart.js.

## 🧩 How it works

- Auto‑discovery detects Claude and Codex tools.
- Parses JSONL/log files from supported tools.
- Calculates costs per token using model‑specific pricing.
- Displays top‑level stats (Today / Week / Month / All‑time / Sessions).

## ⚙️ Key details

- Top‑level All / Claude / Codex pill toggle scopes entire dashboard to a single provider.
- No cloud, no telemetry, no accounts; everything stays on your machine.
- Cost grouped by working directory to show which projects burn through token budget.
- Filters by source, model, date range, and minimum cost.
- Day‑by‑day session timeline with expandable rows and color‑coded model chips.
- Hourly × day activity grid revealing most productive and expensive coding hours.
- Drill into any session: token breakdown, conversation preview, one‑click resume command (claude --resume <id> / codex resume <id>).
