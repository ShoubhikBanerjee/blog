# Google debuts 'Create My Widget' AI tool for custom home screen widgets on Pixel devices

Google has introduced Create My Widget, an AI-powered feature that lets Pixel users design custom home screen widgets through natural language prompts. The tool, part of Android's Gemini Intelligence suite, is currently in beta and rolling out to Pixel phones.

## 📱 What Can You Build?

Create My Widget enables users to generate a variety of functional widgets including:

- Weather-based messages (e.g., "Tut tut, looks like rain" when precipitation is detected)
- Entertainment displays (like hourly Jurassic Park quotes from the original film)
- Personal habit trackers (such as logging daily mental health walks)
- Event countdowns (counting down to holidays or calendar events)
- Sports updates (showing recent scores and upcoming game times)
- Recipe suggestions (daily three-ingredient cocktail ideas)

## ⚙️ How It Works

The feature operates as a prompt shortcut for Gemini. When you tap a created widget, it opens the Gemini interface on your home screen, processes your request, and generates the desired output. Some examples:

| Widget Type | Functionality |
|-------------|---------------|
| Quote Widget | Displays a different Jurassic Park quote each hour |
| Weather Widget | Shows "Tut tut, looks like rain" during precipitation, "No rain right now" otherwise |
| Walk Logger | Triggers Gemini to add a walk to calendar and provides a checklist for marking completed walks |
| Bus Schedule | Searches for arrival times at a specified stop (though results vary in usefulness) |

## 🚀 Availability and Limitations

- Currently in beta testing
- Rolling out to Pixel phones (tested on Pixel 11 Pro)
- Creation time: approximately 20 seconds per widget
- Not a one-size-fits-all solution—some use cases like real-time transit data produce less useful outputs
