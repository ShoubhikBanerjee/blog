# Azure Databricks Enters Beta on Azure Government

At Microsoft Ignite 2026, Databricks announced that Azure Databricks on Azure Government has entered Beta. This release marks a step in providing public sector organizations access to the Databricks Data + AI Platform within an environment working toward FedRAMP Class D and DoW IL5 authorization.

## ⚙️ Key Details
- The new environment runs on the same architecture as commercial Azure Databricks, enabling it to receive the full Databricks platform through ongoing releases.
- It is a first-party Azure service, managed through the Azure portal and integrated with Microsoft Entra ID.
- During Beta, the environment is intended for non-production workloads, though workspaces created now will carry forward to General Availability.
- Databricks is actively pursuing FedRAMP Class D and DoW Impact Level 5 authorizations, expected in early 2027.

## 🚀 Availability
- The environment is currently open for Beta to organizations that require a dedicated government cloud.
- Users can opt in by registering the preview feature in the Azure portal using a dedicated Azure Government subscription that has not been used for Azure Databricks.
- Existing users on the legacy Azure Government environment can explore the new environment side-by-side with their current workspaces.
