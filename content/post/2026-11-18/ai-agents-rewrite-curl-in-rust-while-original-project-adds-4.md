# AI Agents Rewrite Curl in Rust While Original Project Adds 400 Bugfixes

## 🔍 Overview

During a period when AI agents converted 185,000 lines of C code into 340,000 lines of Rust code, the actual curl project merged over 300 commits.

## ⚙️ Key details

The original curl project improved during this timeframe of a little more than three weeks, incorporating:

*   Over 200 bugfixes that the Rust rewrites did not include.
*   Fixes for a few vulnerabilities.
*   An additional 200 bugfixes in the following month, along with maybe a few more vulnerability fixes.

## 💡 Why it matters

The evidence highlights a comparison between the static output of the AI rewrite and the ongoing maintenance of the source project. The text asks whether these clones will keep up with the actual development pace of the original software.
