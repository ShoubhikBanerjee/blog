# Curated List of AI/LLM Code Execution Sandboxes

A curated list of code-execution sandboxing solutions for AI/LLM agents has been released. The collection features various runtime environments designed to secure code execution for autonomous agents.

## 🔍 Overview
The list encompasses a wide array of sandboxing technologies, ranging from open-source cloud runtimes to commercial enterprise-grade solutions. It includes options for full cloud VMs, MicroVMs, and container-based environments.

## ⚙️ Key details
*   **Boot Times:** Solutions offer boot times ranging from milliseconds to 2 seconds.
*   **Isolation Methods:** Technologies include Firecracker microVMs, hardware-level isolation, and Kubernetes backends like gVisor and Kata.
*   **SDK Support:** Available SDKs include TypeScript, Python, Rust, and CLI tools.
*   **Networking:** Features include private overlay networking, fine-grained controls, and public preview URLs with no inbound ports.

## 🛡️ Security Features
*   **Isolation:** Hardware-level isolation via Firecracker microVMs and VM-level isolation.
*   **Monitoring:** Tamper-evident audit logs and action-level tracing.
*   **Access Control:** Host-enforced egress allowlists and API key injection by a host-side broker.
*   **Encryption:** End-to-end encryption is available.

## 🚀 Availability
*   **Deployment:** Options include an agent deployment framework with SDK decorators and one-click configuration.
*   **Hosting:** Solutions can be hosted on kosa8 Cloud, your own hosts, or locally on Mac, Linux, or Windows machines.
*   **Access:** SSH-accessible Linux boxes and full cloud VMs are available.
