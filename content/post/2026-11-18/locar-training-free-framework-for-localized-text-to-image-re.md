# LoCaR: Training-Free Framework for Localized Text-to-Image Retrieval

LoCaR, a training-free framework for localized text-to-image retrieval, has been introduced. It utilizes frozen vision-language models to construct and utilize independent proposals focusing on objects, providing a more localized representation that independently encodes each region using the frozen visual encoder. The framework also studies paired-support adaptation as an optional residual that uses matched text region exemplars without updating the underlying encoders. A new benchmark, LOCFG, has been introduced to evaluate localized retrieval for smaller and more challenging referents. The results show that improving the region representation itself is the main source of gain across several vision-language backbones.
