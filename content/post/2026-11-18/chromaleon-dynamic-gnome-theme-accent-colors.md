# ChromaLeon: Dynamic GNOME Theme Accent Colors

ChromaLeon is a GNOME extension that dynamically changes accent colors based on your wallpaper. It's a project maintained in spare time, with support for native GNOME accent colors and seamless application across GNOME Shell and GTK apps.

## 🔍 Overview
- Change your GNOME Shell and GTK accent colors dynamically based on your wallpaper.
- Change your GNOME Shell, Adwaita, adw-gtk3, and app/folder icons accent colors dynamically based on your wallpaper.
- ChromaLeon was created within the context of the Adwaita theme.

## 🧩 How it works
- Dynamic Extraction: Automatically extracts accent colors from your current wallpaper.
- Applies accent colors seamlessly across GNOME Shell and GTK 3.0 / 4.0 apps.
- Theme the Shell and all your LibAdwaita and GTK3 applications with Adw-GTK3.
- Applies the accent color to the folders.
- Applies the accent color to some app icons.
- Includes a wallpaper selector for user wallpapers and GNOME dynamic wallpapers.
- Allow applying custom CSS to the shell, with support for ChromaLeon's accent color.
- Hot Reload for GTK4 applications with support for ChromaLeon colors (works natively for GNOME colors).
- Syncs color variables so your sandboxed Flatpak applications match the rest of the system.

## ⚙️ Key details
- ChromaLeon **conflicts DIRECTLY** with the [User Theme](https://extensions.gnome.org/extension/19/user-themes/) extension. If you have this extension installed, please **REMOVE or DISABLE it** to avoid any errors.
- If you are experiencing any issues customizing applications or GNOME Shell, please ensure you are using the Adwaita theme before opening an issue.
- A special thanks to [PakoVM](https://github.com/pakovm-git) for the inspiration behind the **tinted style**. The implementation in **ChromaLeon** was based on an idea from his [Tint My GNOME](https://github.com/pakovm-git/Tint-my-Gnome) extension.
