# Azure Databricks Genie Plugin Integrates Governed Business Context into Microsoft Copilot and Office Suite

Azure Databricks has launched the Genie plugin for Microsoft Copilot and Copilot Cowork, extending governed business context from Azure Databricks into Microsoft's productivity tools including Teams, Excel, and Copilot Studio. This integration enables users to query enterprise data using natural language while maintaining data governance through Unity Catalog and leveraging enterprise context via Genie Ontology.

## 🎯 What’s New

- Azure Databricks Genie plugin brings governed Azure Databricks context to Microsoft Copilot and Microsoft Copilot Cowork
- Genie is now generally available in Microsoft Teams, Microsoft Excel, and Microsoft Copilot Studio
- The Databricks Genie app for Microsoft Teams is generally available for direct messaging and channel interactions

## 🔍 How It Works

- Genie Ontology combines business semantics teams explicitly define with context learned from everyday work to ground answers in full business understanding
- Unity Catalog enforces each user's data permissions, while Unity Gateway provides admins with traces, MCP policies, and budget controls for AI management
- Genie pulls usage, spend, and account trends from Azure Databricks and reads recent customer emails through the Microsoft 365 connector

## ⚙️ Key Features

| Capability | Description |
|------------|-------------|
| Microsoft Teams Integration | Users can send direct messages to Genie or mention @Databricks Genie in channels for answers grounded in governance data |
| Natural Language Queries | Analysts can ask questions in plain English through the Azure Databricks Excel Add-in to get answers from governed data without SQL |
| Citation Tracking | Every answer includes citations showing data sources for verification |
| Copilot Studio Integration | Builders can connect Genie Agents to Microsoft Copilot Studio using the Azure Databricks connector for Power Platform |
| Automated Document Generation | Cowork transforms insights into Word docs, Excel sheets with charts, and client-ready presentations |

## 🚀 Availability

- Azure Databricks Genie is generally available across Microsoft tools
- Genie Ontology is now generally available as the enterprise context layer
- Genie pulls certified metric definitions and reads customer emails via Microsoft 365 connector

## 💡 Why It Matters

The integration brings essential context and governance directly into Microsoft tools teams already use, allowing work to happen where questions were originally asked. For example, a sales manager can query open leads over $100K needing follow-up and receive matching leads with activity history and source links—all grounded in Unity Catalog-enforced governance and Genie Ontology's business context understanding.
