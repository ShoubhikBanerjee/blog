# Hugging Face Deep Reinforcement Learning Course Status Update

The Hugging Face Deep Reinforcement Learning Course, authored by Thomas Simonini and Omar Sanseviero, remains an accessible resource for learning the theory and practical aspects of the field, despite transitioning to a low-maintenance state.

## ⚙️ Key Details
- The repository contains mdx files and notebooks covering the full curriculum.
- Theoretical content and practical exercises remain fully functional for students.
- Community support is available via the repository's issue section for troubleshooting hands-on exercises.

## ⚠️ Current Status of Features
| Feature | Status |
| :--- | :--- |
| Unit 7 (AI vs AI) | Non-functional |
| Soccer Agent Training | Functional |
| Leaderboard | No longer operational |
