# JamAI Base: Open-source RAG platform with built-in LLM capabilities

JamAI Base is an open-source RAG backend platform that integrates an embedded database and vector database with managed memory and RAG capabilities.

## 🔍 Overview
- Open-source RAG backend platform
- Integrates embedded database (SQLite) and vector database (LanceDB)
- Features built-in LLM, vector embeddings, and reranker orchestration
- Accessible through a spreadsheet-like UI and REST API

## 🧩 How it works
- Transform static database tables into dynamic, AI-enhanced entities
- Automatically populate columns with relevant data generated by LLMs
- Built-in REST API endpoint for streamlining AI integration
- Facilitate real-time interactions between frontend and LLM backend
- Eliminate manual backend management of user inputs and outputs
- Enable sophisticated LLM workflows
- Act as repositories for structured data and documents
- Enhance LLM's contextual understanding
- Upload and synchronize documents and data
- Simplify creation and management of intelligent chatbot applications
- Integrate with RAG to utilize content from any Knowledge Table
- Store, manage, query, and retrieve embeddings on large-scale multi-modal data
- Ensure optimal performance and seamless scalability

## ⚙️ Key details
- Focus on defining 'what' you want to achieve rather than 'how'
- Allow users to define relationships and desired outcomes
- Eliminate the need to write procedures
- Built on LanceDB, an open-source vector database for AI workloads
- Serverless design for optimal performance and scalability
- Supports any LLMs, including OpenAI GPT-4, Anthropic Claude 3, and Meta Llama3
- Built-in RAG features, no need to build the RAG pipeline yourself
- Combines keyword-based search, structured search, and vector search
- Automatically determines the best way to chunk your data
- Leverages multi-lingual, multi-functional, and multi-granular text embeddings for free

## 🚀 Availability
- Sign up for a free account
- Get free LLM tokens
- Build a basic chatbot without any backend setup
