# Lite.Ai.ToolKit provides a C++ framework for deploying AI models

Lite.Ai.ToolKit is a lightweight C++ AI toolkit designed for user-friendly deployment of numerous AI models. The project supports over 300 C++ model implementations and provides access to more than 500 model weights.

## ⚙️ Key details

*   **Ease of Use**: Features a consistent, simplified syntax following the structure `lite::cv::Type::Class`.
*   **Dependencies**: Requires only OpenCV and ONNXRuntime by default.
*   **Platform Support**: Tested on Ubuntu 20.04.6 LTS with build support for Linux.
*   **Maintenance**: Primarily maintained by @wangzijian1010.

## 🧩 Capabilities

The toolkit supports a wide variety of AI tasks, including:

| Task Type | Examples |
| :--- | :--- |
| Detection | Object Detection, Face Detection |
| Recognition | Face Recognition |
| Segmentation | Segmentation, Matting |

## 🚀 Availability

Users can access the library by downloading the prebuilt version from the v0.2.0 release tag or by building from source using the provided build script. The toolkit integrates with multiple model hubs:

*   ONNX Hub
*   MNN Hub
*   TNN Hub
*   NCNN Hub
