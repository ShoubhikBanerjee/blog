# Archify: free open‑source tool turning AI agent output into interactive HTML

Archify, a free and open‑source tool, lets developers describe a concept to an AI agent and receive an interactive HTML page that can be explored, customized, and shared.

## 🔍 Overview
Archify turns natural‑language descriptions into interactive HTML visualizations that can be edited and shared without needing a code repository.

## 🛠️ Integrations
- Works with Cursor
- Works with Claude Code
- Works with Codex CLI
- Works with OpenCode

## 📐 Features
- Free and open‑source
- No repository required; start from a description or have the agent read a repo
- Generates architecture diagrams (e.g., web request flow: browser → API → Redis → PostgreSQL cache miss)
- Interactive controls such as “Add authentication”, “Highlight the cache‑miss path”, or “Switch to the light theme”
- Builds explainer pages: conclusion first, then one panel per question with tables, steps, charts, code, and validated diagrams
- Steps appear beside the diagram and light the relevant parts as you read

## 🚀 Availability
Archify is available at no cost as an open‑source project.

## 💡 Why it matters
Provides rapid, visual feedback for AI‑generated designs, supports iterative refinement, and lowers the barrier to creating shareable architecture documentation.
