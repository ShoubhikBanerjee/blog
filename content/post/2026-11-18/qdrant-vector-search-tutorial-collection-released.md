# Qdrant Vector Search Tutorial Collection Released

A new collection of examples and tutorials has been released for the Qdrant vector search engine. The repository contains a curated set of tutorials, demos, and how-to guides focused on Qdrant and adjacent technologies.

## 🧩 How it works
The tutorials cover a range of data types and use cases, including:
* **Text Data:** Introduction to the intersection of vector databases and natural language processing.
* **Image Data:** Use of semantic search for accurate skin cancer image comparison with Qdrant and CLIP.
* **Audio Data:** Introduction to audio embeddings, audio data, and music recommendation systems.
* **Agentic RAG:** Building a vector-search-powered agentic workflow to extract insights from meeting recordings using Qdrant and CrewAI.

## ⚙️ Key details
Specific guides within the collection include:
* "Qdrant 101 - Getting Started": Introduction to semantic search and the recommendation API of Qdrant.
* "Build a Semantic Search Engine in 5 Minutes": A quick starter tutorial that builds a semantic search engine for science-fiction books.
* "Semantic Search for Sci-Fi Books": A demonstration of semantic search over a top-100 set of science-fiction books.
* "Build a Semantic Search API": A guide to searching startup descriptions by meaning with Qdrant Cloud Inference, filtering by city, and serving results through FastAPI.
* "Language Model QA with Qdrant": A tutorial on document retrieval with Vision Language Models and binary quantization.
* "AI Getting Started Demo": A sample menu dataset and pre-written script used by the "Start building on Qdrant" agent prompt in the Qdrant docs to demo local semantic search.

## 💡 Why it matters
The collection provides structured learning paths for developers, covering foundational concepts such as the recommendation API and advanced implementations like agentic workflows and visual document retrieval.
