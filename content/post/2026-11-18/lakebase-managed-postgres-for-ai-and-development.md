# Lakebase: Managed Postgres for AI and Development

Lakebase, a fully managed Postgres solution, enables developers to build applications with ease, as it allows any developer familiar with SQL or ORMs to start immediately. Storage is separated from compute, and the database resides alongside lakehouse data under Unity Catalog governance.

## 🔍 Overview
- Lakebase is a fully managed Postgres solution.
- It allows developers familiar with SQL or ORMs to build applications immediately.
- Storage is separated from compute, and the database lives next to lakehouse data under Unity Catalog governance.

## 🧩 How it works
- Every Lakebase project starts with a production branch.
- Child branches can be created from the production branch for development, testing, or experiments.
- Branches use copy-on-write, making a branch of a large database ready in seconds and only changes taking up new storage.

## ⚙️ Key details
- Lakebase is used in various projects like Jevons Search, Branchflight, and BranchCut.
- Jevons Search uses Lakebase branches to work on support tickets.
- Branchflight provides preview environments for pull requests.
- BranchCut brings Git-style branching and merging to creative work.

## 💡 Why it matters
- Lakebase enables fast and efficient branching for development, testing, and experiments.
- It provides a secure and scalable solution for managing data and applications.
- Lakebase is used in various projects to improve efficiency and productivity.
