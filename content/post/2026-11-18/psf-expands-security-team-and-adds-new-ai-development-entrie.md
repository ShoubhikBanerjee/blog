# PSF Expands Security Team and Adds New AI Development Entries

The Python Software Foundation (PSF) has expanded its Developers in Residence program to include three security developers, while recent entries in AI development include running Datasette in the browser and utilizing local large language models.

## 👥 Security Team Expansion

The PSF operates the Developers in Residence program, which now includes three security developers. One of the new members is Brett Smith. These developers are focused on helping secure Python, PyPI, and the wider ecosystem. The PSF also employs a small staff team to keep operations running, which includes running PyCon US annually and sponsoring core developer sprints.

## 🧩 Recent AI Development Entries

Recent technical entries document various AI and Python-based developments:

* Running the full server-side Datasette Python app in the browser using service workers and Pyodide, noted on 17th November 2026.
* Locating the source of a mysterious beep using Claude, noted on 9th November 2026.
* Hiding slop PR descriptions behind HTML details tags, noted on 9th November 2026.
* Running Qwen 3.8 27B on a laptop to interpret model weights, noted on 3rd November 2026.
