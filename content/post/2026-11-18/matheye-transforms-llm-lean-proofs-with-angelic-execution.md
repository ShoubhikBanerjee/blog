# MathEye Transforms LLM Lean Proofs with Angelic Execution

## 📚 Introduction

Large language models (LLMs) can now generate Lean proof scripts that capture the high-level structure of many mathematical arguments. However, these scripts frequently fail on complex theorems due to issues like missing side conditions or misapplied lemmas.

## 🔍 Overview

MathEye is a framework that converts imperfect LLM-generated proof scripts into fully verified Lean proofs by combining symbolic reasoning with minimal human interaction.

## 🧩 How it works

At the core of MathEye is **angelic proof checking**, an optimistic execution model that:

- Replaces failing proof fragments with placeholders while preserving the overall structure of the argument
- Produces an angelic proof that isolates the exact proof obligations that the LLM fails to discharge

Because unresolved obligations are often logically interdependent, MathEye performs **residual analysis** over a proof dependence graph that captures symbol-level data flow in the angelic proof. It then formulates obligation selection as a **MaxSAT optimization problem** to select a minimal-cost set of essential obligations whose resolution suffices to complete the entire proof. Finally, MathEye presents these essential obligations to the mathematician in ordinary mathematical language and uses their answers to automatically reconstruct the complete Lean proof.

## ⚙️ Key details

### System Components

| Component | Description |
|-----------|-------------|
| Angelic proof checking | Optimistic execution model replacing failing proof fragments with placeholders |
| Residual analysis | Analyzes proof dependence graph capturing symbol-level data flow |
| MaxSAT optimization | Selects minimal-cost set of essential proof obligations |

### Performance Results

- Solved **93.3%** of problems in experiments on 30 real-world benchmarks across analysis and algebra
- Reduced required user interactions by **55%**

## 💡 Why it matters

MathEye bridges the gap between LLM-generated mathematical reasoning and fully verified proofs, making formal verification more accessible by significantly reducing the human effort required to complete proofs generated by large language models.
