# Database of Extracted AI System Prompts Reveals Hidden Rules for Major Chatbots

A repository of extracted system prompts from prominent AI developers has documented the verbatim instructions and rules that chatbots receive before interacting with users. This collection includes prompts for models from Anthropic, OpenAI, Google, xAI, Meta, and others, providing insights into the pre-configured parameters governing these systems.

## 🔍 Overview

The repository contains leaked and extracted system prompts that reveal the "hidden rules behind AI." These files have been utilized by external organizations to analyze AI behavior. For example, The Washington Post built an interactive story based on these prompts, and CEPS' AI World developed a live data dashboard using the repository's files to illustrate the instructions chatbots receive before a user's first message.

## ⚙️ Key details

The collection spans several major AI platforms and specific model variants:

*   **Anthropic:** Includes Claude Fable 5.1, Opus 5, Claude Science, and Claude Design. The Claude Design prompt is noted for including 53 tools, 22 skills, and 10 starter components.
*   **OpenAI:** Features ChatGPT GPT-6-Astra, Codex, and GPT-5.6 (Sol variant) prompts.
*   **Google:** Contains prompts for Gemini 3.8 Flash, 3.7 Flash, 3.1 Pro, and Antigravity.
*   **xAI:** Documents Grok 4.6, 4.5, and Grok Bot.
*   **Specialized Tools:** Includes coding-specific prompts such as Meta's Muse Code CLI, Claude Code, and Perplexity Deep Research.
