# Hostinger Launches GPU Hosting for AI Development

Hostinger has introduced GPU Hosting, providing direct access to NVIDIA GPUs with a deployment process designed to be simpler than traditional hyperscalers.

## ⚙️ Key details
Users maintain control of the server environment through full root, terminal, and SSH access. To streamline setup, the service allows for the launch of preconfigured AI applications that include necessary drivers, containers, and dependencies.

Management and usage monitoring are handled via the Hostinger dashboard, and live availability is displayed before deployment.

## 💰 Pricing and Billing
Hostinger uses an hourly credit model that meters GPU usage per minute with no long-term commitment. Key billing details include:
* **Continuous Billing:** Charges continue as long as the instance exists, including during idle periods.
* **Stopping Charges:** Destroying the instance is currently the only way to stop compute charges.
* **Data Transfer:** There are no egress charges for transferring generated data out of the instance.

## 🚀 Availability
There are currently six instance options across five GPU models:

| GPU Model | VRAM | Price per Hour |
| :--- | :--- | :--- |
| RTX 4090 | 24GB | $0.38 |
| RTX PRO 6000 Server | 96GB | $0.60 |
| L40S | 48GB | $0.92 |
| A100 80GB PCIe | 80GB | $1.43 |
| B200 | 192GB | $4.50 |
| B200 Dedicated | 192GB | $7.08 |

## 💡 Why it matters
Different GPU options support various AI workloads:
* **RTX 4090:** The most accessible starting point for workloads requiring 24GB of VRAM.
* **A100:** Provides 80GB of VRAM for memory-intensive inference and training.
* **B200:** Offers 192GB of VRAM for large-model inference and training at scale.
