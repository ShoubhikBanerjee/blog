# Claude Opus 5.5 Generates Vanilla JS WebGL 3D Code Without Three.js

On 9 November 2026 I asked Claude (Opus 5.5 Medium running in regular Claude Chat) to port a Three.js Nudibranch‑themed Fabergé egg example to pure Vanilla JS/WebGL. Claude produced a working version, showing that the model can create 3D code without relying on Three.js.

## 🔍 Overview
- Claude Opus 5.5 Medium was prompted to rewrite a Three.js scene in Vanilla JS.
- The original Three.js egg file is 77 KB; the generated Vanilla JS version is 98 KB.
- Claude’s output is not identical to the Three.js code, and the transcript notes a difference.
- The author finds the Three.js version slightly easier to read but considers the difference minor.

## 🧩 How it worked
- Prompt: *“Port that to Vanilla JS, in the same thread where it had built it.”*
- Result: Claude returned a complete Vanilla JS/WebGL implementation (link provided in the evidence).
- The transcript (linked) shows Claude’s comments explaining the differences.

## ⚙️ Key details
- Capability confirmed: Claude Opus 5.5 can perform 3D modeling in Vanilla JS + WebGL without Three.js.
- Code size comparison:
  - Three.js version: 77 KB
  - Vanilla JS version: 98 KB
- Readability: Three.js code feels slightly easier to understand, but the author rarely examines the code for such projects.

## 🚀 Availability
- The feature is accessible now in Claude Opus 5.5 Medium via the regular Claude Chat interface.

## 💡 Why it matters
- Demonstrates that a large language model can generate functional WebGL graphics code without external 3D libraries.
- Opens the possibility for developers to obtain lightweight, library‑free 3D demos directly from AI prompts.
