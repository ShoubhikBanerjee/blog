# Claude introduces continuous AI‑assisted code review

Claude Haiku 5.5 brings continuous AI‑assisted code review to the Claude Code team.

## 🔍 Overview

> We think "did a human read the code?" is an imprecise proxy for "what could go wrong with this change, and which check—automated or human—is the right one to catch it?" — Addy Osmani, Morgan Westlee Lunt, and Qing Wang, How the Claude Code team does code review

- "Before, review was a gate at the end of the road: write the code, open a PR, wait for your colleague."
- "Now, review runs continuously, more like spellcheck while you write."
- "Asking that question also changed when review happens."

## 🧩 How it works

- "Most changes have been reviewed and fixed by Claude at least once before a human is asked to look."
- The system decides which check—automated or human—is the right one to catch potential problems.

## 💡 Why it matters

- "This catches most routine mistakes, and saves team attention for higher‑level questions and scrutiny."

## 🚀 Availability

- Claude Haiku 5.5 – 7th October 2026
